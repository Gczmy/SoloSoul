# L7 应用入口与全局系统

> **层级定位**：应用生命周期、全局初始化、跨层协调。这是代码执行的起点，负责协调 L0-L6 各层的启动顺序和运行时行为。
>
> **核心原则**：初始化按优先级分阶段执行，重量级操作后台异步；敏感状态在应用进入后台/系统睡眠时自动清理；全局错误不崩溃应用，而是记录日志并显示友好提示。
>
> **Tauri 迁移方向**：Rust `main()` 作为入口，前端 `main.tsx` 作为渲染入口。生命周期事件通过 Tauri API 转发。

## L7.1 启动引导（Bootstrap）

### 1.1 当前实现

**文件**：`lib/main.dart` → `AppBootstrap` StatefulWidget

```dart
class AppBootstrap extends StatefulWidget {
  @override
  State<AppBootstrap> createState() => _AppBootstrapState();
}

class _AppBootstrapState extends State<AppBootstrap> {
  bool _initialized = false;
  String? _errorMessage;
  
  @override
  void initState() {
    super.initState();
    _initialize();
  }
  
  Future<void> _initialize() async {
    try {
      await LiquidGlassWidgets.initialize();           // Phase 1: Shader 预热
      await _initRustFfi();                             // Phase 2: Rust FFI
      if (Platform.isMacOS) NativeChannelService.initialize(); // Phase 3: 原生通道
      _loadUserGuideIndex();                            // Phase 4: 用户指南（后台）
      _prewarmOcrEngine();                              // Phase 5: OCR 预热（后台）
      _cleanupStaleTempFiles();                         // Phase 6: 临时文件清理（后台）
      setState(() => _initialized = true);
    } catch (e) {
      setState(() => _errorMessage = e.toString());
    }
  }
}
```

### 1.2 初始化阶段详述

| 阶段 | 优先级 | 操作 | 阻塞性 | 失败策略 |
|------|--------|------|--------|---------|
| **1. Shader 预热** | P0 | `LiquidGlassWidgets.initialize()` | ✅ 阻塞 | 启动失败 |
| **2. Rust FFI 初始化** | P0 | `RustLib.init()`，动态库路径解析 | ✅ 阻塞 | 启动失败 |
| **3. 原生通道** | P0 | `NativeChannelService.initialize()`（macOS） | ✅ 阻塞 | 启动失败 |
| **4. 用户指南索引** | P1 | `UserGuideService.loadIndex()` | ❌ 后台 | 静默忽略 |
| **5. OCR 引擎预热** | P1 | `OcrService.initialize()` | ❌ 后台 | 首次使用时重试 |
| **6. 临时文件清理** | P2 | 删除超 1 小时的残留文件 | ❌ 后台 | 静默忽略 |
| **7. 安全设置加载** | P2 | `SecurityService.loadSettings()` | ❌ 后台 | 使用默认值 |
| **8. 生物识别初始化** | P2 | `BiometricCredentialService.initialize()` | ❌ 后台 | 静默忽略 |
| **9. QuickLook 初始化** | P2 | `QuickLookService().initialize()` | ❌ 后台 | 静默忽略 |
| **10. 版本检测** | P2 | `AppVersionTracker.checkVersion()` | ❌ 后台 | 静默忽略 |

## L7.3 生命周期监听

### 3.1 Flutter 生命周期状态

| 状态 | 触发条件 | SoloSoul 处理 |
|------|---------|--------------|
| `resumed` | App 回到前台 | 取消自动锁定计时器；检查是否需要立即锁定 |
| `inactive` | App 失去焦点（如来电、通知中心） | 启动自动锁定倒计时 |
| `paused` | App 进入后台 | 启动自动锁定倒计时 |
| `detached` | App 被系统终止 | 清理剪贴板监控；擦除敏感状态 |
| `hidden` | App 被隐藏（iOS） | 无特殊处理 |

### 3.2 Tauri 生命周期事件

```rust
// Rust 端
use tauri::Manager;

fn main() {
    tauri::Builder::default()
        .on_window_event(|event| {
            match event.event() {
                tauri::WindowEvent::Focused(focused) => {
                    if !focused {
                        // 窗口失去焦点 → 启动自动锁定
                        app.emit("window_blurred", {});
                    }
                }
                tauri::WindowEvent::CloseRequested { .. } => {
                    // 窗口关闭前 → 锁定 Vault
                    app.emit("app_closing", {});
                }
                _ => {}
            }
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

```typescript
// 前端监听
import { listen } from '@tauri-apps/api/event';

});
```

## L7.4 自动锁定系统

### 4.1 配置参数

```typescript
interface SecuritySettings {
  autoLockDelayMinutes: number;      // 1, 5, 15, 30, -1(从不)
  clipboardClearDelaySeconds: number; // 30, 60, 120, -1(从不)
  lockOnWindowBlur: boolean;          // true / false
  biometricsEnabled: boolean;         // true / false
  faceIdEnabled: boolean;             // true / false
  privacyScreenEnabled: boolean;      // true / false
}
```

### 4.2 自动锁定逻辑

```typescript
class AutoLockManager {
  private pausedAt: Date | null = null;
  private timer: Timer | null = null;
  private lastActivityTime = Date.now();
  
  // 用户交互时调用
  recordActivity() {
    this.lastActivityTime = Date.now();
  }
  
  // App 进入后台/失焦时调用
  startAutoLockTimer() {
    if (!securitySettings.lockOnWindowBlur) return;
    if (securitySettings.autoLockDelayMinutes === -1) return; // 从不锁定
    
    this.pausedAt = new Date();
    const delayMs = securitySettings.autoLockDelayMinutes * 60 * 1000;
    const inactiveMs = Date.now() - this.lastActivityTime;
    const remainingMs = Math.max(0, delayMs - inactiveMs);
    
    this.timer = setTimeout(() => {
      this.triggerAutoLock();
    }, remainingMs);
  }
  
  // App 回到前台时调用
  checkAutoLock() {
    if (this.pausedAt === null) return;
    if (securitySettings.autoLockDelayMinutes === -1) return;
    
    const inactiveMs = Date.now() - this.lastActivityTime;
    const delayMs = securitySettings.autoLockDelayMinutes * 60 * 1000;
    
    if (inactiveMs >= delayMs) {
      this.triggerAutoLock();
    }
    this.pausedAt = null;
  }
  
  // 触发锁定
  private triggerAutoLock() {
    wipeSensitiveState();
    lockVault();
  }
  
  // 擦除敏感状态
  private wipeSensitiveState() {
    profileStore.clearProfile();
    fieldHistoriesStore.clearHistories();
    unifiedObjectStore.reset();
    // 强制 GC（尽力而为）
  }
}
```

### 4.3 状态擦除详情

锁定后需要擦除的敏感状态：

| 状态 | 擦除方式 |
|------|---------|
| Profile 数据 | `profileStore.clearProfile()` → state = null |
| 字段历史 | `fieldHistoriesStore.clearHistories()` → empty map |
| Unified Objects | `unifiedObjectStore.reset()` → empty list |
| 搜索索引 | `searchStore.clear()` → empty |
| LLM 消息 | 保留（非敏感），但清除上下文中的 Profile 数据 |
| 剪贴板 | `ClipboardMonitorService.dispose()` |

```dart
FlutterError.onError = (FlutterErrorDetails details) {
  final exception = details.exception.toString();
  
  // 忽略已知的 Flutter 框架 bug
  if (exception.contains('HardwareKeyboard') && 
      exception.contains('KeyDownEvent is dispatched')) {

  ),
);
```

### 5.2 Tauri 错误处理

**前端全局错误**：
```typescript
// React Error Boundary
class ErrorBoundary extends React.Component {
  state = { hasError: false, error: null };
  
  static getDerivedStateFromError(error) {
    return { hasError: true, error };
  }
  
  componentDidCatch(error, errorInfo) {
    console.error('React Error Boundary:', error, errorInfo);
    // 发送到 Rust 日志
    invoke('log_error', { 
      source: 'FRONTEND', 
      message: `${error.message}\n${errorInfo.componentStack}` 
    });
  }
  
  render() {
    if (this.state.hasError) {
      return <ErrorFallback error={this.state.error} />;
    }
    return this.props.children;
  }
}
```

**未捕获 Promise 错误**：
```typescript
window.addEventListener('unhandledrejection', (event) => {
  console.error('Unhandled Promise Rejection:', event.reason);
  invoke('log_error', { 
    source: 'FRONTEND_PROMISE', 
    message: String(event.reason) 
  });
});
```

## L7.6 调试与诊断系统

### 6.1 DebugLogger

**文件**：`lib/core/services/debug_logger.dart`

- 目的：Release 构建下的文件日志（用于用户问题诊断）
- 位置：`/tmp/solosoul_dart.log`
- 格式：`[YYYY-MM-DD HH:mm:ss] [TAG] Message`

**日志级别**：
| 级别 | 方法 | 用途 |
|------|------|------|
| Debug | `logDebug(tag, msg)` | 详细调试信息 |
| Info | `logInfo(tag, msg)` | 重要流程节点 |
| Warning | `logWarning(tag, msg)` | 异常情况但可恢复 |
| Error | `logError(tag, msg)` | 错误，需关注 |

### 6.2 SoloLog

**文件**：`lib/core/utils/solo_log.dart`

- 带标签的分级日志
- 支持计时器：`startTimer(tag, name)` / `endTimer(timer)`
- 开发模式输出到控制台，Release 模式输出到文件

```dart
SoloLog.d('TAG', 'Debug message');
SoloLog.i('TAG', 'Info message');
SoloLog.w('TAG', 'Warning message');
SoloLog.e('TAG', 'Error message', error, stackTrace);

final timer = SoloLog.startTimer('SYNC', 'sync_as_initiator');
// ... 执行同步
SoloLog.endTimer(timer); // 输出耗时
```

### 6.3 Rust 日志

**文件**：`native/src/lib.rs` → `log_to_file()`

- 位置：`/tmp/solosoul_rust.log`
- 线程安全：通过 `Mutex` 保护文件写入
- 格式：`[YYYY-MM-DD HH:mm:ss.sss] Message`

### 6.4 Tauri 日志统一

```rust
// Rust 端使用 tracing
use tracing::{info, warn, error, debug};

#[tauri::command]
fn log_error(source: String, message: String) {
    error!(source = %source, "{}", message);
}
```

```typescript
// 前端通过 invoke 发送日志到 Rust
function log(level: 'debug' | 'info' | 'warn' | 'error', tag: string, message: string) {
  invoke('log_message', { level, tag, message });
}
```

## Tauri 迁移后的架构

```
Rust 入口 (src-tauri/src/main.rs)
    │
    ├──→ 初始化 Tauri App
    │       ├──→ 注册 IPC 命令（L3 服务）
    │       ├──→ 注册菜单项（锁定）
    │       ├──→ 注册窗口事件监听（失焦/关闭）
    │       ├──→ 注册系统事件监听（睡眠）
    │       └──→ 启动前端 WebView
    │
    └──→ 加载前端页面 (index.html)
            │
            └──→ React App (src/main.tsx)
                    │
                    ├──→ 初始化 i18n
                    ├──→ 初始化主题
                    ├──→ 初始化状态管理（Zustand）
                    ├──→ 注册生命周期监听（beforeunload）
                    ├──→ 注册 Tauri 事件监听（vault_state_changed）
                    ├──→ 渲染 Router
                    └──→ 渲染 App 组件
```

## 从零开始实现顺序

1. **Rust 入口**
   - `src-tauri/src/main.rs` — 基础 Tauri 应用启动
   - 注册基本 IPC 命令

2. **前端入口**
   - `src/main.tsx` — React 应用挂载
   - 初始化 ThemeProvider、I18nProvider

3. **Bootstrap 页面**
   - 加载动画
   - 分阶段初始化（Rust 后端已就绪，无需 FFI 初始化）
   - OCR 预热（后台）

4. **生命周期管理**
   - 前端：`beforeunload`、`visibilitychange` 事件
   - Tauri 事件：`window_blurred`、`app_closing`
   - 系统事件：macOS 睡眠监听（Rust）

5. **自动锁定**
   - 配置加载
   - 计时器管理
   - 状态擦除

6. **错误处理**
   - React Error Boundary
   - 全局错误监听
   - 日志系统（Rust `tracing` + 前端 IPC）

7. **路由系统**
   - React Router 配置
   - 路由守卫（解锁检查 + 敏感验证）
