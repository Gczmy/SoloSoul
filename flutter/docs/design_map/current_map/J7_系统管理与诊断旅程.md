# J7 系统管理与诊断旅程

> **旅程定位**：用户管理应用系统级配置、查看运行状态、诊断问题的完整流程。这是面向"高级用户"或"问题排查"场景的旅程。
>
> **核心目标**：提供应用运行的透明度，让用户了解数据存储状态、版本信息、操作历史，以及在遇到问题时能够自助诊断。
>
> **涉及页面**：Settings（应用信息/调试）→ 版本检测 → 调试日志 → 法律文档
>
> **状态依赖**：L0 包信息、L3 版本追踪、L3 调试日志

### 1.3 删除账户

**流程**：
```
用户点击"删除当前账户"
    │
    ▼
显示 PasswordVerificationDialog
    │
    ▼
密码验证成功
    │
    ▼
显示确认对话框：
"确定要删除账户 'Personal' 吗？
此操作将删除该账户的所有数据，且不可撤销。
建议在删除前先创建备份。"
    │
    ├──→ 用户取消 → 无操作
    └──→ 用户确认
        │
        ▼
    调用 deleteAccount(accountId, password)
        │
        ├──→ 删除 Vault 目录
        ├──→ 删除附件目录
        ├──→ 删除备份目录
        ├──→ 更新 accounts.json
        └──→ 记录操作日志
        │
        ▼
    如果删除的是当前账户：
        ├──→ 锁定 Vault
        ├──→ 擦除敏感状态
        └──→ 跳转到 LoginPage
    如果还有其他账户：
        └──→ 切换到默认账户或第一个账户
```

## 模块 2：版本与更新

### 2.1 版本检测

**数据来源**：GitHub Releases API

```typescript
async function checkLatestVersion(): Promise<string | null> {
  try {
    const response = await fetch(
      'https://api.github.com/repos/Gczmy/SoloSoul/releases/latest',
      {
        headers: {
          'Accept': 'application/vnd.github.v3+json',
          'User-Agent': 'SoloSoul-App',
        },
      }
    );
    
    if (response.status === 200) {
      const data = await response.json();
      const tagName = data.tag_name as string;
      return tagName.startsWith('v') ? tagName.substring(1) : tagName;
    }
    return null;
  } catch {
    return null;
  }
}
```

## 模块 4：法律文档

### 4.1 隐私政策

**内容要点**：
- 数据本地存储，不上传云端
- 零知识架构：开发者无法解密用户数据
- 生物识别数据仅用于本地认证
- 第三方服务使用（LLM API 等）
- 数据删除权利

### 4.2 服务条款

**内容要点**：
- 使用许可
- 免责声明
- 责任限制
- 法律适用

### 4.3 展示方式

- 首次使用：强制弹窗，必须同意
- 设置页：可重新查看
- 多语言：根据当前 Locale 显示

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 版本检测网络失败 | 提示"无法检查更新，请检查网络连接" |
| GitHub API 限流 | 提示"更新检查过于频繁，请稍后再试" |
| 调试日志文件过大 | 自动轮转，保留最近 7 天日志 |
| 日志导出失败 | 提示"导出失败"，提供复制到剪贴板选项 |
| 删除账户时密码错误 | 显示错误提示，不执行删除 |
| 切换账户时 Vault 锁定失败 | 提示"切换失败"，保持当前账户 |
| 法律文档加载失败 | 显示内嵌简化版 |
