# J3 数据安全与隐私旅程

> **旅程定位**：用户配置和管理应用安全策略的完整流程。这是 SoloSoul "零知识安全模型"的核心体现，所有敏感操作都围绕"用户完全掌控自己的数据"这一理念展开。
>
> **核心目标**：让用户理解并配置适合自己使用场景的安全策略，包括自动锁定、敏感数据分级、密码修改、生物识别等。
>
> **涉及页面**：Settings → SecuritySettings → SensitivitySettings → PasswordVerificationDialog（贯穿多个页面）
>
> **状态依赖**：L2 加密层、L3 SecurityService、L4 敏感度状态、L0 平台安全存储

### 1.4 版本检测

```typescript
// 检查 GitHub Releases API
async function checkUpdate(): Promise<string | null> {
  const response = await fetch(
    'https://api.github.com/repos/Gczmy/SoloSoul/releases/latest',
    { headers: { 'User-Agent': 'SoloSoul-App' } }
  );
  const data = await response.json();
  const latestVersion = data.tag_name.replace('v', '');
  const currentVersion = appVersion;
  
  if (compareVersions(latestVersion, currentVersion) > 0) {
    return latestVersion;
  }
  return null;
}
```

### 2.3 自动锁定

**配置选项**：
| 选项 | 延迟时间 | 适用场景 |
|------|---------|---------|
| 立即 | 0ms | 最高安全，每次离开都锁定 |
| 1 分钟 | 60,000ms | 短暂离开 |
| 5 分钟 | 300,000ms | 推荐默认值 |
| 15 分钟 | 900,000ms | 办公环境 |
| 30 分钟 | 1,800,000ms | 低安全需求 |
| 从不 | -1 | 关闭自动锁定 |

**实现逻辑**（见 L7.4）：
```typescript
// 用户交互时重置计时器
onUserInteraction = () => {
  lastActivityTime = Date.now();
};

// 窗口失焦/后台时启动计时器
onAppBackground = () => {
  if (!securitySettings.lockOnWindowBlur) return;
  const delay = securitySettings.autoLockDelayMinutes * 60 * 1000;
  const inactiveMs = Date.now() - lastActivityTime;
  const remainingMs = Math.max(0, delay - inactiveMs);
  
  autoLockTimer = setTimeout(() => {
    lockVault();
    wipeSensitiveState();
  }, remainingMs);
};
```

### 2.4 剪贴板清理

**触发时机**：用户复制了敏感度 ≥ `internal` 的字段值

**实现逻辑**：
```typescript
onCopySensitiveField = (value: string) => {
  // 写入剪贴板
  navigator.clipboard.writeText(value);
  
  // 如果配置了自动清理
  if (securitySettings.clipboardClearDelaySeconds > 0) {
    setTimeout(() => {
      navigator.clipboard.writeText('');
    }, securitySettings.clipboardClearDelaySeconds * 1000);
  }
};
```

### 3.4 敏感度下拉选项

每个字段旁的下拉菜单提供 6 个级别：
```
[Public]      — 公开，任何人可见
[Internal]    — 内部，自动模糊显示
[Private]     — 私有，自动模糊显示
[Sensitive]   — 敏感，查看需密码验证
[Restricted]  — 受限，查看需密码验证
[Critical]    — 关键，查看需密码验证
```

**选择后的行为**：
- 选择非默认值 → 存入 `accountStyleProvider`（账户级覆盖）
- 选择"恢复默认" → 从 `accountStyleProvider` 删除该字段的覆盖

### 3.5 搜索过滤

```typescript
function filterFields(query: string): FieldSensitivity[] {
  const registry = getFieldRegistry();
  const accountStyle = getAccountStyle();
  
  return Object.values(registry)
    .filter(field => 
      field.fieldName.toLowerCase().includes(query.toLowerCase()) ||
      field.fieldSection.toLowerCase().includes(query.toLowerCase())
    )
    .map(field => ({
      ...field,
      effectiveLevel: accountStyle[field.fieldId] || field.level
    }))
    .sort((a, b) => {
      const sec = a.fieldSection.localeCompare(b.fieldSection);
      return sec !== 0 ? sec : a.fieldName.localeCompare(b.fieldName);
    });
}
```

### 4.3 验证缓存

```typescript
// 验证成功后，1 分钟内无需再次验证
const SENSITIVE_ACCESS_TTL_MS = 60 * 1000;

function verifyPassword(password: string): Promise<boolean> {
  return new Promise((resolve) => {
    invoke('verify_password', { password }).then((valid) => {
      if (valid) {
        sensitiveAccessStore.grantAccess();
        // 1 分钟后自动过期
        setTimeout(() => {
          sensitiveAccessStore.revokeAccess();
        }, SENSITIVE_ACCESS_TTL_MS);
      }
      resolve(valid);
    });
  });
}
```

## 安全策略配置矩阵

用户可根据使用场景选择预设的安全策略组合：

| 配置项 | 高安全模式 | 日常模式 | 便捷模式 |
|--------|-----------|---------|---------|
| **自动锁定** | 立即 | 5 分钟 | 30 分钟 |
| **剪贴板清理** | 30 秒 | 60 秒 | 从不 |
| **窗口失焦锁定** | 开启 | 开启 | 关闭 |
| **隐私屏幕** | 开启 | 开启 | 关闭 |
| **生物识别** | 开启 | 开启 | 开启 |
| **敏感字段默认级别** | 提高一级 | 默认 | 降低一级 |

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 密码验证连续失败 3 次 | 提示"密码错误，请重试"，不锁定账户（本地应用无暴力破解风险） |
| 生物识别硬件临时不可用 | 提示"生物识别不可用，请使用密码"，自动降级到密码验证 |
| 修改密码时旧密码错误 | 显示错误提示，不中断流程 |
| 新密码与旧密码相同 | 提示"新密码不能与旧密码相同" |
| 敏感度设置保存失败 | 提示"设置未保存"，保留用户选择，允许重试 |
| 安全存储写入失败 | 提示"安全设置保存失败"，使用内存缓存，下次启动重试 |

## 从零实现顺序

1. **PasswordVerificationDialog（最高优先级）**
   - 密码输入框（显隐切换）
   - 验证调用（invoke）
   - 错误状态
   - 1 分钟缓存逻辑
   - 动画过渡

2. **SecuritySettingsPage**
   - 自动锁定选择器
   - 剪贴板清理选择器
   - 开关组件（窗口失焦、隐私屏幕、生物识别）
   - 生物识别可用性检测
   - 设置持久化

3. **SensitivitySettingsPage**
   - 字段注册表展示
   - 按分类分组
   - 敏感度下拉选择
   - 搜索过滤
   - 账户覆盖标记
   - 进入前密码验证

4. **SettingsPage**
   - 分类 SettingsTile 列表
   - 版本检测逻辑
   - 更新提示弹窗
   - 法律文档弹窗
   - 调试日志查看
   - 各设置项跳转

5. **安全策略应用**
   - 自动锁定计时器（全局）
   - 剪贴板监控与清理
   - 隐私屏幕 API 调用
   - 敏感字段访问控制（与 ObjectEditor 集成）
