## 多平台打包

### macOS

```bash
# 开发构建
npm run tauri dev

# Release 构建（自动签名如果配置了）
npm run tauri build

# 输出
src-tauri/target/release/bundle/macos/SoloSoul.app
src-tauri/target/release/bundle/dmg/SoloSoul_2.0.0_x64.dmg
```

### Windows

```bash
# Release 构建
npm run tauri build -- --target x86_64-pc-windows-msvc

# 输出
src-tauri/target/release/bundle/msi/SoloSoul_2.0.0_x64_en-US.msi
src-tauri/target/release/bundle/nsis/SoloSoul_2.0.0_x64-setup.exe
```

### Linux

```bash
# Release 构建
npm run tauri build -- --target x86_64-unknown-linux-gnu

# 输出
src-tauri/target/release/bundle/appimage/solo-soul_2.0.0_amd64.AppImage
src-tauri/target/release/bundle/deb/solo-soul_2.0.0_amd64.deb
```

### 构建脚本

```bash
#!/bin/bash
# scripts/build.sh

set -e

TARGET=${1:-"all"}
VERSION=$(grep '^version' Cargo.toml | head -1 | cut -d'"' -f2)

echo "Building SoloSoul v${VERSION}..."

# 前端构建
echo "Building frontend..."
npm run build

# 平台构建
case $TARGET in
  macos)
    echo "Building for macOS..."
    cargo tauri build --target universal-apple-darwin
    ;;
  windows)
    echo "Building for Windows..."
    cargo tauri build --target x86_64-pc-windows-msvc
    ;;
  linux)
    echo "Building for Linux..."
    cargo tauri build --target x86_64-unknown-linux-gnu
    ;;
  all)
    echo "Building for all platforms..."
    cargo tauri build
    ;;
  *)
    echo "Unknown target: $TARGET"
    echo "Usage: $0 [macos|windows|linux|all]"
    exit 1
    ;;
esac

echo "Build complete!"
```

## 代码签名

### macOS 签名

```bash
# 设置签名证书
export APPLE_CERTIFICATE=$(cat certificate.p12 | base64)
export APPLE_CERTIFICATE_PASSWORD="password"
export APPLE_SIGNING_IDENTITY="Developer ID Application: Your Name"

# 构建（自动签名）
npm run tauri build

# 公证（Notarization）
export APPLE_ID="your@email.com"
export APPLE_PASSWORD="app-specific-password"
export APPLE_TEAM_ID="TEAM_ID"

xcrun notarytool submit \
  src-tauri/target/release/bundle/dmg/SoloSoul_*.dmg \
  --apple-id "$APPLE_ID" \
  --password "$APPLE_PASSWORD" \
  --team-id "$APPLE_TEAM_ID" \
  --wait
```

### Windows 签名

```bash
# 使用 signtool
signtool sign \
  /f certificate.pfx \
  /p password \
  /tr http://timestamp.digicert.com \
  /td sha256 \
  /fd sha256 \
  src-tauri/target/release/bundle/msi/SoloSoul_*.msi
```

## 自动更新

### 使用 Tauri 更新器

```json
// tauri.conf.json
{
  "plugins": {
    "updater": {
      "active": true,
      "endpoints": [
        "https://api.github.com/repos/Gczmy/SoloSoul/releases/latest"
      ],
      "dialog": true,
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

### 更新检查实现

```typescript
// src/lib/updater.ts
import { check } from '@tauri-apps/plugin-updater';
import { ask, message } from '@tauri-apps/plugin-dialog';

export async function checkForUpdates() {
  try {
    const update = await check();
    
    if (update) {
      const yes = await ask(
        `发现新版本 ${update.version}，是否更新？`,
        {
          title: '更新可用',
          kind: 'info',
        }
      );
      
      if (yes) {
        await update.downloadAndInstall();
        await message('更新完成，应用将重启', { title: '更新成功' });
      }
    }
  } catch (error) {
    console.error('更新检查失败:', error);
  }
}
```

## 发布流程

### GitHub Actions 发布

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build-macos:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - uses: Swatinem/rust-cache@v2
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run tauri build
        env:
          APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
          APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
          APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: macos-artifacts
          path: src-tauri/target/release/bundle/

  build-windows:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - uses: Swatinem/rust-cache@v2
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run tauri build
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: windows-artifacts
          path: src-tauri/target/release/bundle/

  create-release:
    needs: [build-macos, build-windows]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Download artifacts
        uses: actions/download-artifact@v4
        with:
          path: artifacts
      - name: Create Release
        uses: softprops/action-gh-release@v2
        with:
          draft: true
          files: |
            artifacts/macos-artifacts/**/*.dmg
            artifacts/windows-artifacts/**/*.msi
            artifacts/windows-artifacts/**/*.exe
```

## 与 Flutter 的对比

| 方面 | Flutter | Tauri |
|------|---------|-------|
| 构建命令 | `flutter build macos` | `npm run tauri build` |
| 包大小 | ~50MB+ | ~5-10MB |
| 签名 | `codesign` 手动 | 自动（配置后） |
| 自动更新 | 需自建 | Tauri 内置 |
| 多平台 | 一套代码 | 需分别构建 |
| 构建时间 | 5-10 min | 2-5 min |
| 依赖 | Xcode + Flutter SDK | Rust + Node.js |
