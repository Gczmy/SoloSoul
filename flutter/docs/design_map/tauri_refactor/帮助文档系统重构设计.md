### 现有实现的局限性

| 局限 | 说明 | 影响 |
|------|------|------|
| 无全文搜索 | 用户只能浏览目录，不能搜索内容 | 找文档困难 |
| 无代码复制 | 代码块只能手动选中复制 | 体验差 |
| 无步骤指示器 | 操作指南是一堆文字，步骤不清晰 | 学习成本高 |
| 无交互演示 | 无法内嵌"点击这里"的模拟操作 | 抽象难理解 |
| 无搜索高亮 | 搜索结果不展示匹配位置 | 定位慢 |
| 样式有限 | Markdown 渲染能力天花板低 | 视觉单调 |

## 方案选择：Markdown + React 组件渲染

### 核心决策

**保留 Markdown 源文件，用 React 组件增强渲染**。

```
源文件（维护层）                    渲染层（展示层）
─────────────────────────────────────────────────────────
assets/docs/guides/                  src/components/guide/
├── index.json    ───────────────→   GuideIndex.tsx（指南目录）
├── objects.md    ───────────────→   GuideRenderer.tsx（富交互渲染）
├── security.md   ───────────────→   GuideSearch.tsx（全文搜索）
├── plugins.md                       GuideStepper.tsx（步骤指示器）
└── ...                              GuideCodeBlock.tsx（代码复制）
        ↑
        └──────────────────────→   AI 检索（纯文本提取）
```

### 为什么不选其他方案？

| 方案 | 分析 | 结论 |
|------|------|------|
| **纯 Markdown（保持现状）** | 维护简单、AI 友好，但交互体验天花板低 | ❌ 不采纳，体验差距明显 |
| **纯 HTML/WebView** | 交互最强，但维护困难、体积大、AI 不友好 | ❌ 不采纳，维护成本不可接受 |
| **静态站点生成器（VitePress/Docusaurus）** | 专业文档体验，但包体积大、与 App 风格割裂 | ❌ 不采纳，过度设计 |
| **Markdown + React 组件渲染** | 兼顾维护和交互，源文件不变，渲染层增强 | ✅ **采纳** |

### 决策理由

1. **Markdown 是最佳源格式**
   - 技术人员和非技术人员都能写
   - 版本控制友好（diff 可读）
   - AI 可直接读取纯文本做检索
   - 多语言只需复制文件（`xxx.md` / `xxx_zh.md`）

2. **React 组件提供无限渲染可能**
   - Tauri 前端就是 React，不引入新技术栈
   - `react-markdown` 支持自定义组件映射
   - 可以复用 App 现有的 UI 组件（按钮、卡片、标签）

3. **分层解耦**
   - 内容层（Markdown）和展示层（React）完全分离
   - 改内容不需要改代码，改展示不需要改内容
   - 未来如果换技术栈，只需替换渲染层

```typescript
// src/components/guide/GuideStepper.tsx
import { useState } from 'react';

interface GuideStepperProps {
  children: React.ReactNode;  // li 列表项
}

export function GuideStepper({ children }: GuideStepperProps) {
  const [currentStep, setCurrentStep] = useState(0);
  const steps = extractSteps(children);
  
  return (
    <div className="guide-stepper">
      {/* 步骤进度条 */}
      <div className="guide-stepper-progress">
        {steps.map((_, i) => (
          <div
            key={i}
            className={`guide-stepper-dot ${i <= currentStep ? 'active' : ''}`}
          />
        ))}
      </div>
      
      {/* 当前步骤内容 */}
      <div className="guide-stepper-content">
        <div className="guide-stepper-badge">
          步骤 {currentStep + 1} / {steps.length}
        </div>
        <div className="guide-stepper-text">
          {steps[currentStep]}
        </div>
      </div>
      
      {/* 导航按钮 */}
      <div className="guide-stepper-nav">
        <button
          disabled={currentStep === 0}
          onClick={() => setCurrentStep(i => i - 1)}
        >
          上一步
        </button>
        <button
          disabled={currentStep === steps.length - 1}
          onClick={() => setCurrentStep(i => i + 1)}
        >
          {currentStep === steps.length - 1 ? '完成' : '下一步'}
        </button>
      </div>
    </div>
  );
}
```

#### GuideCodeBlock（代码块，带复制）

```typescript
// src/components/guide/GuideCodeBlock.tsx
import { useState } from 'react';

interface GuideCodeBlockProps {
  children: string;
  language?: string;
}

export function GuideCodeBlock({ children, language }: GuideCodeBlockProps) {
  const [copied, setCopied] = useState(false);
  
  const handleCopy = async () => {
    await navigator.clipboard.writeText(children);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };
  
  return (
    <div className="guide-codeblock">
      <div className="guide-codeblock-header">
        {language && <span className="guide-codeblock-lang">{language}</span>}
        <button onClick={handleCopy}>
          {copied ? '✅ 已复制' : '📋 复制'}
        </button>
      </div>
      <pre>
        <code>{children}</code>
      </pre>
    </div>
  );
}
```

#### GuideSearch（全文搜索）

```typescript
// src/components/guide/GuideSearch.tsx
import { useState, useMemo } from 'react';

interface GuideSearchProps {
  guides: GuideIndexEntry[];
  onSelect: (guideId: string, anchor?: string) => void;
}

export function GuideSearch({ guides, onSelect }: GuideSearchProps) {
  const [query, setQuery] = useState('');
  
  const results = useMemo(() => {
    if (!query.trim()) return [];
    return searchGuides(guides, query);  // 本地索引搜索
  }, [query, guides]);
  
  return (
    <div className="guide-search">
      <input
        type="text"
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="搜索帮助文档..."
        className="guide-search-input"
      />
      {results.length > 0 && (
        <div className="guide-search-dropdown">
          {results.map(r => (
            <button
              key={r.id}
              className="guide-search-result"
              onClick={() => onSelect(r.id, r.anchor)}
            >
              <div className="guide-search-result-title">{r.title}</div>
              <div
                className="guide-search-result-snippet"
                dangerouslySetInnerHTML={{
                  __html: highlightMatches(r.snippet, query),
                }}
              />
            </button>
          ))}
        </div>
      )}
    </div>
  );
}
```

## Rust IPC 接口设计

### 接口清单

```rust
// src-tauri/src/commands/guide.rs

use crate::core::guide::{GuideIndex, GuideEntry, GuideSearchResult};
use crate::core::utils::error::AppError;
use tauri::State;

/// 加载指南索引
#[tauri::command]
async fn guide_load_index(lang: String) -> Result<GuideIndex, String> {
    let index = GuideService::load_index(&lang).await
        .map_err(|e| e.to_string())?;
    Ok(index)
}

/// 加载单篇指南内容（Markdown 原文）
#[tauri::command]
async fn guide_load_content(guide_id: String, lang: String) -> Result<String, String> {
    let content = GuideService::load_content(&guide_id, &lang).await
        .map_err(|e| e.to_string())?;
    Ok(content)
}

/// 全文搜索
#[tauri::command]
async fn guide_search(query: String, lang: String) -> Result<Vec<GuideSearchResult>, String> {
    let results = GuideService::search(&query, &lang).await
        .map_err(|e| e.to_string())?;
```

### 服务实现

```rust
// src-tauri/src/core/guide/service.rs

use std::collections::HashMap;
use std::path::Path;
use serde::{Deserialize, Serialize};
use tokio::fs;

pub struct GuideService;

impl GuideService {
    /// 指南资源目录（打包后位于应用资源内）
    const GUIDES_DIR: &'static str = "resources/docs/guides";
    const LEGAL_DIR: &'static str = "resources/docs/legal";
    
    /// 加载索引
    pub async fn load_index(lang: &str) -> Result<GuideIndex, AppError> {
        let index_path = format!("{}/index.json", Self::GUIDES_DIR);
        let content = fs::read_to_string(&index_path).await?;
        let raw: GuideIndexRaw = serde_json::from_str(&content)?;
        
        // 过滤当前语言可用的指南
        let entries: Vec<GuideEntry> = raw.guides.into_iter()
            .filter(|g| g.files.contains_key(lang) || g.files.contains_key("en"))
            .map(|g| GuideEntry {
                id: g.id,
                title: g.get_title(lang),
                description: g.get_description(lang),
            })
            .collect();
        
        Ok(GuideIndex { entries })
    }
    
    /// 加载指南内容
    pub async fn load_content(guide_id: &str, lang: &str) -> Result<String, AppError> {
        let index = Self::load_raw_index().await?;
        let guide = index.guides.iter()
            .find(|g| g.id == guide_id)
            .ok_or(AppError::NotFound)?;
        
        let file_path = guide.files.get(lang)
            .or_else(|| guide.files.get("en"))
            .ok_or(AppError::NotFound)?;
        
        let content = fs::read_to_string(&format!("{}/{}", Self::GUIDES_DIR, file_path)).await?;
        Ok(content)
    }
    
    /// 全文搜索（本地索引）
    pub async fn search(query: &str, lang: &str) -> Result<Vec<GuideSearchResult>, AppError> {
        let index = Self::load_raw_index().await?;
        let mut results = Vec::new();
        
        for guide in &index.guides {
            let file_path = guide.files.get(lang)
                .or_else(|| guide.files.get("en"))
                .ok_or(AppError::NotFound)?;
            
            let content = fs::read_to_string(&format!("{}/{}", Self::GUIDES_DIR, file_path)).await?;
            
            // 简单关键词匹配（可替换为更高效的搜索算法）
            let query_lower = query.to_lowercase();
            let score = Self::calculate_score(&content, &guide.keywords, &query_lower);
            
            if score > 0 {
                let snippet = Self::extract_snippet(&content, &query_lower);
                results.push(GuideSearchResult {
                    id: guide.id.clone(),
                    title: guide.get_title(lang),
                    snippet,
                    score,
                });
            }
        }
        
        // 按得分排序
        results.sort_by(|a, b| b.score.cmp(&a.score));
        results.truncate(10);  // 最多返回 10 条
        
        Ok(results)
    }
    
    /// 为 AI 检索最相关指南（纯文本，截断至 800 字符）
    pub async fn find_relevant(query: &str, lang: &str) -> Result<Option<GuideAiMatch>, AppError> {
        let index = Self::load_raw_index().await?;
        
        let mut best_match: Option<&GuideIndexEntry> = None;
        let mut best_score = 0;
        
        for guide in &index.guides {
            let score = Self::calculate_ai_score(guide, query);
            if score > best_score {
                best_score = score;
                best_match = Some(guide);
            }
        }
        
        if best_score < 2 {
            return Ok(None);  // 得分过低，不返回
        }
        
        let guide = best_match.unwrap();
        let content = Self::load_content(&guide.id, lang).await?;
        let trimmed = Self::trim_for_ai(&content, 800);
        
        Ok(Some(GuideAiMatch {
            id: guide.id.clone(),
            title: guide.get_title(lang),
            content: trimmed,
        }))
    }
    
    // --- 辅助方法 ---
    
    fn calculate_score(content: &str, keywords: &[String], query: &str) -> i32 {
        let mut score = 0;
        let content_lower = content.to_lowercase();
        
        // 关键词匹配
        for kw in keywords {
            if query.contains(&kw.to_lowercase()) || kw.to_lowercase().contains(query) {
                score += 1;
            }
        }
        
        // 内容匹配
        if content_lower.contains(query) {
            score += 2;
        }
        
        score
    }
    
    fn calculate_ai_score(guide: &GuideIndexEntry, query: &str) -> i32 {
        let mut score = 0;
        let query_lower = query.to_lowercase();
        
        // 关键词匹配
        for kw in &guide.keywords {
            if query_lower.contains(&kw.to_lowercase()) {
                score += 1;
            }
        }
        
        // 标题匹配（权重更高）
        if guide.title.to_lowercase().contains(&query_lower)
            || guide.title_en.to_lowercase().contains(&query_lower) {
            score += 3;
        }
        
        score
    }
    
    fn extract_snippet(content: &str, query: &str) -> String {
        let content_lower = content.to_lowercase();
        if let Some(pos) = content_lower.find(query) {
            let start = pos.saturating_sub(40);
            let end = (pos + query.len() + 100).min(content.len());
            let snippet = &content[start..end];
            return snippet.to_string();
        }
        content.chars().take(150).collect::<String>() + "..."
    }
    
    fn trim_for_ai(content: &str, max_chars: usize) -> String {
        if content.len() <= max_chars {
            return content.to_string();
        }
        // 尝试在段落边界截断
        let cutoff = content[..max_chars].rfind("\n\n").unwrap_or(max_chars);
        if cutoff > max_chars / 2 {
            return format!("{}\n\n（内容已截断）", &content[..cutoff]);
        }
        format!("{}...", &content[..max_chars])
    }
}
```
