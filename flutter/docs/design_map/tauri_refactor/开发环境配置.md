## 工具链安装

### 1. Rust

```bash
# 安装 Rust（使用 rustup）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# 验证
rustc --version  # rustc 1.82.0

# 安装 clippy 和 rustfmt
rustup component add clippy rustfmt
```

### 2. Node.js

```bash
# 使用 nvm 安装
nvm install 20
nvm use 20

# 验证
node --version  # v20.x.x
npm --version   # 10.x.x
```

### 3. Tauri CLI

```bash
# 全局安装 Tauri CLI
cargo install tauri-cli

# 或使用 npx（推荐）
npx tauri --version
```

### 4. 平台依赖

**macOS**:
```bash
# Xcode Command Line Tools
xcode-select --install

# 无需额外依赖
```

**Windows**:
```bash
# 安装 Visual Studio Build Tools
# 或 Visual Studio Community（勾选 C++ 桌面开发）

# WebView2 Runtime（Windows 10/11 通常已预装）
```

**Linux**:
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install libgtk-3-dev libwebkit2gtk-4.0-dev libappindicator3-dev librsvg2-dev patchelf
```

## 项目初始化

### 1. 克隆仓库

```bash
git clone https://github.com/Gczmy/SoloSoul.git
cd SoloSoul
```

### 2. 安装前端依赖

```bash
npm install
# 或
pnpm install
```

### 3. 安装 Rust 依赖

```bash
cd src-tauri
cargo fetch
cd ..
```

### 4. 验证环境

```bash
# 检查 Tauri
npx tauri --version

# 检查 Rust
cargo --version

# 检查前端
npm run dev
# 访问 http://localhost:1420，应看到基础页面
```

## IDE 配置

### VS Code（推荐）

**必需插件**:
- `rust-lang.rust-analyzer` — Rust 语言支持
- `bradlc.vscode-tailwindcss` — CSS 支持
- `dbaeumer.vscode-eslint` — ESLint
- `esbenp.prettier-vscode` — Prettier
- `formulahendry.auto-rename-tag` — HTML/JSX 标签自动重命名

**推荐配置** (`.vscode/settings.json`):
```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer",
    "editor.formatOnSave": true
  },
  "rust-analyzer.checkOnSave.command": "clippy",
  "rust-analyzer.cargo.features": "all",
  "typescript.preferences.importModuleSpecifier": "non-relative",
  "eslint.workingDirectories": ["."],
}
```

### RustRover / IntelliJ IDEA

**插件**:
- Rust 插件（内置）

**配置**:
- 设置 Rust toolchain
- 启用 Clippy 检查
- 配置 Cargo features

## 开发工作流

### 启动开发服务器

```bash
# 同时启动前端 dev server 和 Tauri 应用
npm run tauri dev

# 前端独立开发（不启动 Tauri）
npm run dev
# 访问 http://localhost:1420
```

### 代码检查

```bash
# Rust 格式化
cargo fmt

# Rust 静态检查
cargo clippy -- -D warnings

# TypeScript 类型检查
npx tsc --noEmit

# ESLint
npm run lint

# 全部检查（CI 前执行）
npm run check-all
```

### 测试

```bash
# Rust 测试
cargo test --workspace

# 前端单元测试
npx vitest

# E2E 测试
npx playwright test

# 全部测试
npm run test-all
```

### 构建

```bash
# 开发构建
npm run tauri build -- --debug

# Release 构建
npm run tauri build
```

## 常见问题

### Q: `cargo tauri dev` 启动很慢？

A: 首次编译 Rust 依赖需要时间（5-10 分钟）。后续使用 `cargo` 缓存会快很多。

### Q: 前端热重载不工作？

A: 确保 `vite.config.ts` 中配置了 HMR：
```typescript
export default defineConfig({
  server: {
    hmr: true,
  },
});
```

### Q: Rust 代码修改后 Tauri 没有重新编译？

A: `cargo tauri dev` 会自动监视 Rust 代码变化。如果没有，尝试：
```bash
# 手动触发重建
cd src-tauri && cargo build
```

### Q: `clippy` 报错太多？

A: 可以暂时放宽检查：
```bash
cargo clippy -- -A clippy::all
```

### Q: Playwright E2E 测试失败？

A: 确保先构建应用：
```bash
npm run tauri build -- --debug
npx playwright test
```
