## 3. 多平台构建

```bash
# macOS
npm run tauri build
# 输出: src-tauri/target/release/bundle/macos/SoloSoul.app
#       src-tauri/target/release/bundle/dmg/SoloSoul_2.0.0_x64.dmg

# Windows
npm run tauri build -- --target x86_64-pc-windows-msvc
# 输出: .msi + .exe

# Linux
npm run tauri build -- --target x86_64-unknown-linux-gnu
# 输出: .AppImage + .deb
```

### 构建脚本

```bash
#!/bin/bash
# scripts/build.sh
set -e
TARGET=${1:-"all"}
VERSION=$(grep '^version' Cargo.toml | head -1 | cut -d'"' -f2)
echo "Building SoloSoul v${VERSION}..."

npm run build
case $TARGET in
  macos)   cargo tauri build --target universal-apple-darwin ;;
  windows) cargo tauri build --target x86_64-pc-windows-msvc ;;
  linux)   cargo tauri build --target x86_64-unknown-linux-gnu ;;
  all)     cargo tauri build ;;
esac
```

## 4. 代码签名

### macOS

```bash
export APPLE_CERTIFICATE=$(cat certificate.p12 | base64)
export APPLE_SIGNING_IDENTITY="Developer ID Application: Your Name"

npm run tauri build

# 公证（Notarization）
xcrun notarytool submit \
  src-tauri/target/release/bundle/dmg/SoloSoul_*.dmg \
  --apple-id "$APPLE_ID" --password "$APPLE_PASSWORD" \
  --team-id "$APPLE_TEAM_ID" --wait
```

### Windows

```bash
signtool sign /f certificate.pfx /p password \
  /tr http://timestamp.digicert.com /td sha256 /fd sha256 \
  src-tauri/target/release/bundle/msi/SoloSoul_*.msi
```

## 5. 自动更新

```json
// tauri.conf.json → plugins.updater
{
  "plugins": {
    "updater": {
      "active": true,
      "endpoints": ["https://api.github.com/repos/Gczmy/SoloSoul/releases/latest"],
      "dialog": true,
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

```typescript
// src/lib/updater.ts
import { check } from '@tauri-apps/plugin-updater';

export async function checkForUpdates() {
  const update = await check();
  if (update) {
    const yes = await ask(`发现新版本 ${update.version}，是否更新？`);
    if (yes) {
      await update.downloadAndInstall();
    }
  }
}
```

## 6. GitHub Actions 发布

```yaml
# .github/workflows/release.yml
on:
  push:
    tags: ['v*']

jobs:
  build-macos:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: actions/setup-node@v4
      - run: npm ci && npm run tauri build
      - uses: actions/upload-artifact@v4

  build-windows:
    runs-on: windows-latest
    # 同上...

  create-release:
    needs: [build-macos, build-windows]
    runs-on: ubuntu-latest
    steps:
      - uses: softprops/action-gh-release@v2
        with:
          draft: true
          files: |
            artifacts/macos-artifacts/**/*.dmg
            artifacts/windows-artifacts/**/*.msi
```

## 7. 与 Flutter 构建的对比

| 方面 | Flutter | Tauri |
|------|---------|-------|
| 构建命令 | `flutter build macos` | `npm run tauri build` |
| 包大小 | ~50MB+ | **~5-10MB** |
| 签名 | `codesign` 手动 | 自动（配置后） |
| 自动更新 | 需自建 | Tauri 内置 |
| 构建时间 | 5-10 min | 2-5 min |
| 依赖 | Xcode + Flutter SDK | Rust + Node.js |
