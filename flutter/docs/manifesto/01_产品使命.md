# 01 产品使命

> *"独奏生命数据，重塑数字原点。"*

---

## 我们为什么存在

### 问题：你的数据，不是你的

今天的数字生活有一个悖论：**你创造了海量的个人数据，但你几乎不拥有它们。**

- 你的通讯录存在微信里——导出来是一堆混乱的格式。
- 你的旅行记录分散在携程、飞猪、航旅纵横里——没有一份完整的"你去过哪里"。
- 你的银行流水在各家银行 App 里——没有统一的视图告诉你"你的财务状况"。
- 你的护照、身份证、驾照——它们在抽屉里，也在各个需要实名认证的网站上，但你不知道谁看过它们。
- 你的职业履历在 LinkedIn、Boss 直聘、猎聘上——每一家都只有片段。

更可怕的是，这些数据被**割裂**、被**锁定**、被**监控**。

**割裂**：没有统一的标准来定义"你"。每个应用都有自己的数据模型，互不兼容。  
**锁定**：数据一旦进入某个平台，就再也拿不出来，或者拿出来也无法使用。  
**监控**：你的每一次点击、每一次搜索、每一次交易，都被记录、分析、变现——而你不参与分成，甚至不知情。

### 愿景：个人数据的文艺复兴

SoloSoul 相信，未来的个人数据管理应该像文艺复兴时期的个人图书馆：

- **你在自己的书房里拥有所有书籍**（本地存储）
- **你自己决定谁可以进来看**（访问控制）
- **你可以把书带到任何地方**（可迁移）
- **没有人可以在你不知情时翻你的书架**（隐私保护）

这不是技术问题，这是**主权问题**。

## 使命陈述

### 核心使命

> **让每个人都能完全掌控自己的数字身份和个人数据，
> 不受平台、厂商或云服务的束缚。**

### 三层含义

#### 第一层：数据统一（Unification）

建立**集中式的 Schema 定义**，将碎片化的个人数据统一到一个连贯的模型中：

```
┌─────────────────────────────────────────────────────────┐
│                    你的数字身份                            │
├─────────────┬─────────────┬─────────────┬───────────────┤
│   身份档案   │   旅行记录   │   财务状况   │   职业履历    │
├─────────────┼─────────────┼─────────────┼───────────────┤
│ 姓名         │ 护照         │ 银行账户     │ 工作经历      │
│ 国籍         │ 签证         │ 投资记录     │ 教育背景      │
│ 身份证号     │ 飞行历史     │ 保险         │ 技能证书      │
│ 联系方式     │ 酒店预订     │ 税务         │ 项目成果      │
│ 地址         │ 行程规划     │ 资产清单     │ 推荐信        │
└─────────────┴─────────────┴─────────────┴───────────────┘
        ↑
   统一的 Schema 定义：每个字段都有标准语义
```

这不是"又一个笔记应用"。SoloSoul 管理的是**结构化数据**——每个字段都有类型、有验证规则、有敏感度分级。

#### 第二层：数据主权（Sovereignty）

**去中心化的数据存储**意味着：

- 数据只存在于**你的设备**上
- 同步发生在**你的设备之间**，不经过第三方服务器
- 加密发生在**数据离开你的手指之前**
- 解密发生在**数据进入你的眼睛之前**

没有任何公司、任何政府、任何黑客可以在你不知情的情况下访问你的原始数据。

#### 第三层：数据自由（Freedom）

掌控不只是"锁起来"。真正的掌控意味着：

- **可迁移**：你的数据可以随时完整导出，带到任何其他工具中
- **可复用**：填写一次护照信息，任何需要它的场景都可以引用
- **可遗忘**：删除就是删除，没有云端备份在你不知情的情况下保留副本
- **可继承**：你的数字身份可以作为遗产，按照你的意愿移交

## 不是什么

明确使命也意味着明确**我们不做什么**：

| 我们不是 | 为什么不是 |
|---|---|
| **云端笔记工具**（Notion/Obsidian） | 我们不管理"文档"，我们管理"你" |
| **密码管理器**（1Password/Bitwarden） | 密码只是你身份数据的一个子集 |
| **个人财务管理软件**（随手记/YNAB） | 财务只是你身份数据的一个维度 |
| **网盘/同步盘**（iCloud/Dropbox） | 我们不存储文件，我们存储结构化的身份数据 |
| **区块链身份**（DID/Self-Sovereign Identity） | 我们不依赖区块链，不发行代币，不做全球共识 |

SoloSoul 是**个人数字孪生**——一个完整、结构化、可迁移、由你完全控制的数字自我。

## 成功标准

我们如何知道自己成功了？

### 用户层面的成功

1. **一个用户可以在 5 分钟内找到自己的任何个人数据**（护照号码、某次航班、某笔交易）
2. **更换手机时，用户可以在不依赖任何云服务的情况下完整迁移所有数据**
3. **用户知道自己的数据在哪里、谁在访问、如何被保护**

### 技术层面的成功

1. **零知识**：即使 SoloSoul 的开发者也无法解密任何用户的数据
2. **本地优先**：100% 的核心功能在无网络环境下可用
3. **Schema 开放**：个人数据的 Schema 定义是公开的、标准的、可扩展的

### 社会层面的成功

1. **用户开始要求其他应用支持"SoloSoul 导出格式"**
2. **个人数据管理从"多个 App 的重复劳动"变成"一次录入，随处使用"**
3. **"我的数据在我设备上"成为默认预期，而不是奢侈选项**

- 航空公司接受 SoloSoul 格式的护照信息自动填充

**数据的主权回归个人**，这是 SoloSoul 的终极使命。
