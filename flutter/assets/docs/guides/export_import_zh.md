# 导入与导出

---

## 功能概述

SoloSoul 支持将你的账户数据导出为 `.solosoul` 加密包文件，用于备份或迁移到其他设备。你也可以从 `.solosoul` 文件将数据导入到当前账户。

> **注意**：导入导出功能与「本地备份」不同。备份是针对整个 Vault 的快照，而 `.solosoul` 导入导出是针对单个账户的数据包，支持选择性导入。

---

## 导出数据

### 操作步骤

1. 进入 **设置 → 数据管理 → 导出 / 导入**。
2. 切换到 **导出** 标签页。
3. 确认当前要导出的账户信息。
4. 点击 **导出** 按钮。
5. 在弹出的密码验证对话框中输入你的 **主密码**。
6. 选择保存位置，默认文件名为 `{账户名}_{账户ID}.solosoul`。
7. 等待导出完成，系统将显示导出成功提示。

> **提示**：`.solosoul` 文件包含你的账户数据、档案对象、自定义类型和附件，全部经过加密。只有知道主密码的人才能解密该文件。

---

## 导入数据

### 操作步骤

1. 进入 **设置 → 数据管理 → 导出 / 导入**。
2. 切换到 **导入** 标签页。
3. 点击 **选择文件**，选取要导入的 `.solosoul` 文件。
4. 系统将显示该文件包含的对象数量和附件数量。
5. 输入导出时使用的 **主密码**，点击 **预览**。
6. 在导入预览界面中选择要导入的集合，并确认目标页面映射。
7. 点击 **确认导入**，等待导入完成。

> **警告**：导入操作会在开始前自动创建当前账户的静默备份，以便在需要时恢复。但建议你在导入前手动创建一次备份。

---

## 导入预览

在确认导入前，系统会显示导入预览界面，帮助你了解即将导入的数据内容：

### 集合列表

每个集合代表一组相关对象（如旅行记录、财务账户等）。你可以：

- **勾选/取消** 单个集合，决定哪些数据需要导入
- 查看每个集合的 **对象数量**
- 查看集合中数据的 **最高敏感度等级**：
  - 🟢 绿色 = 公开
  - 🟡 黄色 = 内部
  - 🟠 橙色 = 敏感
  - 🔴 红色 = 关键

### 关系属性警告

如果集合中包含关系属性（指向其他对象的链接），预览界面会显示：

- **关系属性总数**：该集合中所有对象包含的关系字段数量
- **跨分区关系数**：指向当前账户中不存在的对象的关系数量（这些关系在导入后将失效）

> **提示**：跨分区关系不会阻止导入，但导入后这些关系字段将变为空值。如需保留完整关系链，请确保所有相关对象都已存在于当前账户中，或一并导入。

### 目标页面映射

对于每个选中的集合，你可以指定导入后数据应归属的 **目标页面**（如个人档案、旅行、财务、职业等）。如果未指定，系统将根据数据类型自动分配。

## 安全说明

### 加密方式

`.solosoul` 文件使用以下加密方案：

| 组件 | 技术 | 说明 |
|------|------|------|
| 密钥派生 | Argon2id | 从主密码派生加密密钥 |
| 数据加密 | AES-256-GCM | 军事级加密标准 |
| 完整性校验 | SHA-256 | 防止文件被篡改 |

### 密码验证

- 导出和导入时都需要验证主密码
- 密码仅在内存中使用，不会存储到文件中
- 导入时如果密码错误，系统会提示「密码错误」，无法解密数据

### 文件安全建议

| 场景 | 建议 |
|------|------|
| 本地备份 | 将 `.solosoul` 文件存储在加密磁盘或外部硬盘中 |
| 跨设备传输 | 使用 Signal、加密 U 盘等端到端加密渠道传输 |
| 云存储 | 如需上传云端，建议先对 `.solosoul` 文件进行二次加密 |

## 常见问题

**Q: 导入导出与本地备份有什么区别？**

本地备份（`.solobackup`）是整个 Vault 的完整快照，包含所有账户数据，恢复时会覆盖当前所有数据。而 `.solosoul` 导入导出是针对单个账户的数据包，支持选择性导入，且可以跨账户迁移数据。

**Q: 我可以将数据导入到另一个账户吗？**

可以。`.solosoul` 文件与账户无关，只要知道主密码，就可以将其导入到任何 SoloSoul 账户中。导入时系统会自动处理 ID 重映射，避免与现有数据冲突。

**Q: 密码错误怎么办？**

`.solosoul` 文件使用导出时设置的主密码加密。如果忘记密码，文件将无法解密。建议在导出时记录密码提示，或将密码妥善保存在密码管理器中。

**Q: 导入后数据在哪里？**

导入的对象会按照你在预览界面中指定的 **目标页面** 进行归类。如果没有指定目标页面，系统会根据数据类型自动分配到个人档案、旅行、财务或职业页面中。

**Q: 导入会删除现有数据吗？**

不会。导入操作只会 **新增** 数据，不会删除或覆盖现有对象。如果导入的对象类型与现有自定义类型同名，系统会智能合并类型定义。

**Q: 附件也会被导入吗？**

是的。`.solosoul` 文件包含所有附件数据。导入时附件会被重新加密并存储到当前账户的附件池中。
