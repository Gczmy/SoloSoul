# AI Chat

---

## Starting a New Conversation

1. Tap the **New Chat** button in the sidebar.
2. A temporary conversation opens immediately — no session is created yet.
3. Type your first message and send it.
4. SoloSoul automatically creates a formal session after your first message.

> **Tip**: Temporary conversations keep your session list clean. Only sessions with at least one message are saved.

---

## Sending Messages

1. Click the input box at the bottom of the chat panel.
2. Type your question or prompt.
3. Press `Enter` or tap the **Send** button.
4. The AI responds in real time with a streaming reply.

> **Note**: Please wait for the current AI response to finish before switching to another session.

---

## Multiple Conversation Windows

You can maintain several conversations at the same time.

| Feature | Behavior |
|---------|----------|
| Session list | Sorted by most recent activity |
| Switch session | Tap any item in the sidebar |
| Active indicator | The selected session is highlighted |

## Soft Delete & Trash

### Deleting a Session

1. Find the session in the sidebar.
2. Tap the **More Options** menu on the right side of the session row.
3. Select **Delete**.
4. The session moves to the Trash.

### Restoring a Session

1. Scroll to the bottom of the sidebar.
2. Expand the **Trash** section.
3. Find the session you want to restore.
4. Tap the **Restore** button.

> **Tip**: Restored sessions return to the main list with their original update time preserved.

### Permanently Deleting a Session

1. In the Trash section, find the target session.
2. Tap the **Delete Forever** button.
3. Confirm in the dialog.

> **Warning**: Permanent deletion cannot be undone. All messages in that session are lost.

### Emptying the Trash

1. Expand the Trash section in the sidebar.
2. Tap the **Empty Trash** icon in the Trash header.
3. Confirm the action.

> **Warning**: This deletes all trashed sessions permanently.

| Operation | Result | Recoverable |
|-----------|--------|-------------|
| Soft delete | Moved to Trash | Yes, within 30 days |
| Permanent delete | Completely removed | No |
| Empty Trash | All trashed sessions removed | No |

## Message Timestamps

Every message displays a timestamp below its bubble.

| Time range | Display format |
|------------|----------------|
| Today | `HH:MM` (e.g., `14:32`) |
| Yesterday | `Yesterday HH:MM` |
| Same year | `M/D HH:MM` |
| Different year | `YYYY/M/D HH:MM` |

---

## Useful Shortcuts

- **Clear current chat**: Tap the **Clear** button to reset the conversation content without deleting the session.
- **Switch during streaming**: Blocked — wait for the reply to finish.
