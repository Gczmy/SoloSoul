# AI 对话功能

---

## 创建新对话

1. 点击侧边栏的**新对话**按钮。
2. 立即开启一个临时对话——此时还不会创建正式会话。
3. 输入并发送你的第一条消息。
4. 发送后，系统会自动创建一个正式会话。

> **提示**：临时对话不会出现在会话列表中，这样可以保持列表整洁。只有发送过消息的对话才会被保存。

---

## 发送消息

1. 点击聊天面板底部的输入框。
2. 输入你的问题或提示词。
3. 按 `回车键` 或点击**发送**按钮。
4. AI 会实时流式输出回复。

> **注意**：请等待当前 AI 回复完成后再切换到其他会话。

---

## 多对话窗口

你可以同时维护多个对话。

| 特性 | 行为 |
|------|------|
| 会话列表 | 按最近活动时间排序 |
| 切换会话 | 点击侧边栏中的任意会话 |
| 当前指示 | 选中的会话会高亮显示 |

---

## 软删除与回收站

### 删除会话

1. 在侧边栏找到目标会话。
2. 点击会话行右侧的**更多选项**菜单。
3. 选择**删除**。
4. 该会话会被移入回收站。

### 恢复会话

1. 滚动到侧边栏底部。
2. 展开**回收站**区域。
3. 找到要恢复的会话。
4. 点击**恢复**按钮。

> **提示**：恢复后的会话会回到主列表，原来的更新时间保持不变。

### 永久删除会话

1. 在回收站区域找到目标会话。
2. 点击**永久删除**按钮。
3. 在对话框中确认操作。

> **警告**：永久删除不可撤销。该会话的所有消息将永久丢失。

### 清空回收站

1. 在侧边栏展开回收站区域。
2. 点击回收站标题栏的**清空回收站**图标。
3. 确认操作。

> **警告**：这会永久删除回收站中的所有会话。

| 操作 | 结果 | 是否可恢复 |
|------|------|-----------|
| 软删除 | 移入回收站 | 是，30 天内 |
| 永久删除 | 彻底移除 | 否 |
| 清空回收站 | 全部彻底移除 | 否 |

## 消息时间戳

每条消息气泡下方都会显示时间戳。

| 时间范围 | 显示格式 |
|---------|---------|
| 当天 | `HH:MM`（如 `14:32`） |
| 昨天 | `昨天 HH:MM` |
| 同一年 | `M/D HH:MM` |
| 跨年 | `YYYY/M/D HH:MM` |

---

## 实用操作

- **清除当前对话**：点击**清除**按钮可以重置对话内容，但不会删除会话本身。
- **流式输出期间切换**：被阻止——请等待回复完成后再切换。
