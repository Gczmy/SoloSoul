# 同步与备份

---

## 本地备份

SoloSoul 将所有数据本地存储。你可以随时创建加密备份。

1. 进入**设置 → 数据管理 → 创建备份**。
2. 选择目标文件夹。
3. 生成带时间戳的 `.solobackup` 文件。

> **提示**：建议将备份存储在外部硬盘或加密存储中，以提高安全性。

---

## 从备份恢复

1. 进入**设置 → 数据管理 → 从备份恢复**。
2. 选择 `.solobackup` 文件。
3. 输入备份创建时使用的保险库密码。
4. 备份内容将替换当前保险库数据。

> **警告**：恢复备份会覆盖所有当前数据。建议先为当前状态创建一个新备份。

---

## 导入与导出

SoloSoul 支持将账户数据导出为加密的 `.solosoul` 包文件以进行备份或迁移，也支持从此类文件导入数据到当前账户。

### 导出

1. 进入**设置 → 数据管理 → 导出 / 导入**。
2. 切换到**导出**标签页。
3. 点击**导出**按钮并验证主密码。
4. 选择保存位置，默认文件名为 `{账户名}_{账户ID}.solosoul`。

### 导入

1. 进入**设置 → 数据管理 → 导出 / 导入**。
2. 切换到**导入**标签页。
3. 选择 `.solosoul` 文件并输入导出密码。
4. 查看导入预览（选择集合、映射目标页面）。
5. 确认完成导入。

> **注意**：详细操作步骤请参阅**导入与导出**指南。`.solosoul` 格式采用 Argon2id + AES-256-GCM 加密，支持选择性导入和附件迁移。

---

## 无云端同步

SoloSoul 不提供内置云端同步功能。如需跨设备同步，请通过你信任的安全渠道手动传输备份文件。

> **提示**：推荐的加密传输方式包括加密 U 盘、Signal 或其他端到端加密渠道。
