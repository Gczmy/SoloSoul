# 同步与备份

---

## 本地备份

SoloSoul 将所有数据本地存储。你可以随时创建加密备份。

1. 进入**设置 → 数据管理 → 创建备份**。
2. 选择目标文件夹。
3. 生成带时间戳的 `.solobackup` 文件。

> **提示**：建议将备份存储在外部硬盘或加密存储中，以提高安全性。

---

## 从备份恢复

1. 进入**设置 → 数据管理 → 从备份恢复**。
2. 选择 `.solobackup` 文件。
3. 输入备份创建时使用的保险库密码。
4. 备份内容将替换当前保险库数据。

> **警告**：恢复备份会覆盖所有当前数据。建议先为当前状态创建一个新备份。

---

## 导出

单个对象或整个分区可以导出为 JSON。

1. 打开要导出的对象或分区。
2. 点击**导出**按钮。
3. 选择是否为导出文件设置密码加密。
4. 选择目标文件夹。

| 导出选项 | 是否加密 | 使用场景 |
|---------|---------|---------|
| 带密码 | 是 | 安全传输到另一台设备 |
| 不带密码 | 否 | 快速本地拷贝或打印 |

---

## 导入

从其他来源或之前的 SoloSoul 导出文件导入 JSON。

1. 进入**设置 → 数据管理 → 导入**。
2. 选择 JSON 文件。
3. 导入期间，将字段映射到现有对象类型或创建新类型。
4. 确认前查看导入摘要。

---

## 无云端同步

SoloSoul 不提供内置云端同步功能。如需跨设备同步，请通过你信任的安全渠道手动传输备份文件。

> **提示**：推荐的加密传输方式包括加密 U 盘、Signal 或其他端到端加密渠道。
