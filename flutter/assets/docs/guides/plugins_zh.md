# 插件功能

---

## 什么是插件？

**插件**是基于 WebAssembly（Wasm）的扩展模块，用于为 SoloSoul 增加新能力。插件在安全的 Wasmtime 沙盒中运行，通过插件市场分发。

> **注意**：插件与对象是两个不同的概念。对象是保险库中的结构化记录（如护照、银行账户），插件是处理或增强数据的功能扩展。

| 概念 | 是什么 | 示例 |
|------|--------|------|
| 插件 | Wasm 扩展模块 | OCR 扫描器、数据格式化器 |
| 对象 | 结构化个人记录 | 护照、联系人、地址 |
| 页面 | 对象的 UI 分组 | 旅行、财务、职业 |

---

## 插件的工作原理

### 安全模型

插件在严格的安全模型下运行：

1. **Wasm 沙盒**：每个插件在隔离的 Wasmtime 沙盒中运行，无法直接访问你的文件或网络。
2. **SHA-256 校验**：每个插件在加载前都经过校验和验证。
3. **字段级授权**：插件必须声明需要访问哪些数据字段，你需要逐个批准。
4. **可撤销访问**：你可以随时撤销插件的权限。

### 插件生命周期

```
发现 → 安装 → 授权 → 使用 → 更新/卸载
```

## 安装插件

1. 从侧边栏或主页快捷操作进入**插件**。
2. 在市场标签页浏览可用插件。
3. 点击插件查看详情、版本和所需权限。
4. 点击**安装**下载插件。
5. 安装完成后，插件会出现在**已安装**标签页。

> **提示**：插件通过 CDN 从官方插件市场下载，不依赖外部服务器。

---

## 授权插件

当插件请求访问你的数据时：

1. 同意对话框会显示插件想要访问的字段。
2. 查看每个字段及其敏感度级别。
3. 点击**允许**授予访问权限，或点击**拒绝**阻止访问。
4. 如有需要，你可以为单个字段覆盖敏感度级别。

> **警告**：只授权你信任的插件。获得敏感字段访问权限的插件可以在沙盒内读取该数据。

---

## 管理已安装插件

1. 进入**插件**页面，切换到**已安装**标签页。
2. 对于每个插件，你可以：
   - **运行**：执行插件的主功能。
   - **更新**：如果有新版本，升级到最新版本。
   - **卸载**：完全移除插件。
3. 要查看或更改权限，点击插件并选择**权限**。

---

## 插件市场

插件市场是一个公开的 GitHub 仓库，作为分发源：

- **零服务器成本**：插件通过 jsDelivr CDN 分发，GitHub Raw 作为兜底。
- **社区贡献**：第三方开发者可以遵循 SDK 指南发布插件。
- **版本管理**：每个插件都有语义化版本号，SoloSoul 在安装前会检查兼容性。

> **提示**：如果插件加载失败，请检查你的应用版本是否满足插件的最低版本要求。

---

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| 插件安装失败 | 检查网络连接和应用版本兼容性 |
| 插件显示"未授权" | 重新打开插件并授予请求的字段权限 |
| 插件崩溃 | 卸载后重新安装插件；检查是否有更新 |
| 插件运行缓慢 | 大型 Wasm 文件可能需要时间加载；尝试重启应用 |
