# Objects & Profiles

---

## What is an Object?

An **Object** is a structured record in your personal vault. SoloSoul uses the Unified Object Model — each object has a type and a set of typed properties.

| Concept | Description |
|---------|-------------|
| Object | A single structured record (e.g., one passport, one bank account) |
| Type | Defines what kind of object it is (Travel, Finance, etc.) |
| Property | A field within the object (name, number, date, etc.) |
| Sensitivity | Controls visibility: Public / Internal / Sensitive / Critical |

---

## Creating an Object

1. From the home page, tap the **Create** button or select a section.
2. Choose a template (e.g., Travel Document, Bank Account) or start from scratch.
3. Fill in the properties. Each field has a sensitivity level — choose the appropriate level for your data.
4. Tap **Save**.

> **Tip**: Templates provide pre-configured fields for common use cases. You can customize any template after creation.

---

## Editing an Object

1. Tap any object card to open the editor.
2. Modify fields, add attachments, or change sensitivity levels.
3. Tap **Save** to persist changes.

> **Note**: All edits are encrypted locally. No data leaves your device.

---

## Built-in Object Types

| Type | Typical Use |
|------|-------------|
| Travel | Passports, visas, itineraries |
| Finance | Bank accounts, investments, insurance |
| Professional | Resumes, certifications, work contacts |
| Personal | Identity documents, health records |

---

## Sensitivity Levels

SoloSoul provides four sensitivity levels for every property:

| Level | Visibility | Use Case |
|-------|------------|----------|
| Public | Always visible | Names, general info |
| Internal | Blurred by default | Addresses, phone numbers |
| Sensitive | Requires password verification | ID numbers, account details |
| Critical | Highest protection | Passwords, secret keys |

> **Tip**: You can change the sensitivity level of any field at any time. Higher sensitivity means more protection but also more friction when viewing.
