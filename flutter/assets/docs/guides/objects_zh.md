# 档案与对象管理

---

## 什么是对象？

**对象**是你个人保险库中的结构化记录。SoloSoul 采用统一对象模型——每个对象有一个类型和一组类型化属性。

| 概念 | 说明 |
|------|------|
| 对象 | 一条结构化记录（如一本护照、一个银行账户） |
| 类型 | 定义对象的种类（旅行、财务等） |
| 属性 | 对象内的字段（姓名、号码、日期等） |
| 敏感度 | 控制可见性：公开 / 内部 / 敏感 / 关键 |

---

## 创建对象

1. 在主页点击**创建**按钮或选择一个分区。
2. 选择模板（如旅行证件、银行账户）或从零开始。
3. 填写属性。每个字段有敏感度级别——根据数据性质选择合适的级别。
4. 点击**保存**。

> **提示**：模板为常见场景提供预配置字段。创建后你可以随时自定义任何模板。

---

## 编辑对象

1. 点击任意对象卡片打开编辑器。
2. 修改字段、添加附件或调整敏感度级别。
3. 点击**保存**持久化更改。

> **注意**：所有编辑均在本地加密存储，不会有任何数据离开你的设备。

---

## 内置对象类型

| 类型 | 典型用途 |
|------|---------|
| 旅行 | 护照、签证、行程 |
| 财务 | 银行账户、投资、保险 |
| 职业 | 简历、证书、工作联系人 |
| 个人 | 身份证件、健康记录 |

---

## 敏感度级别

SoloSoul 为每个属性提供四个敏感度级别：

| 级别 | 可见性 | 使用场景 |
|------|--------|---------|
| 公开 | 始终可见 | 姓名、一般信息 |
| 内部 | 默认模糊显示 | 地址、电话号码 |
| 敏感 | 需要密码验证 | 证件号码、账户详情 |
| 关键 | 最高保护 | 密码、密钥 |

> **提示**：你可以随时更改任何字段的敏感度级别。敏感度越高，保护越强，但查看时也会需要更多的验证步骤。
