# Windows 界面材质与层级

2026-09-18 按 `previews/windows-material-review.html` 方案落地。保留账户选择的配色，
不将预览里的演示色板强制应用给所有用户。

- **窗口底层**：系统标题栏和导航透出同一层 DWM Mica。系统继续负责窗口按钮、Snap、
  DPI 和失焦时的材质回退，不另造标题栏。关闭系统透明效果或系统不支持 Mica 时，
  导航使用略带明度差的实色。
- **内容层**：AppBar、通知槽和正文使用同一实色表面。取消侧栏分隔线、AppBar 和正文的
  重复内描边；外侧和底部保留 8px 留白与圆角。支持左、右、上、下四种导航位置。
- **卡片层**：共享 Card（首页、对象及设置卡片）以主题表面、轻阴影和间距区分。
  悬停变色但不移动内容，键盘焦点保留清晰轮廓。
- **操作层**：主按钮保留强调色填充，次按钮轻填色，工具栏和指南常态平面；危险操作
  使用红字和淡红悬停。已明确要求常态淡红的“忘记设备”按钮仍保留其状态。
- **浮层**：紧凑菜单使用一层 WebView 内的局部模糊，接近 Acrylic 的视觉效果；这不是
  另一个系统级 Acrylic 窗口。对象详情、搜索结果、指南等正文面板保持实色。

实现入口为 `tauri/src/styles/windows-material.css`、`desktop-controls.css` 和布局/Card
CSS Modules。沿用现有 `data-macos-glass` 作为跨平台浮层用途标记，不引入重复标记。
输入框、分割信息的必要线条、选中状态、通知状态色和键盘焦点不作全局去边框处理。

辅助功能：原生 `solid`、`highContrast`、`reduceMotion` 状态及浏览器的减少透明度、
强制配色、减少动态效果偏好分别控制材质回退、必要轮廓与动画。关闭透明度不改变布局。

验证覆盖四种导航位置、深浅主题、窄/宽窗口按钮、菜单展开与折叠、危险/主要操作语义及
辅助功能回退。macOS 上的浏览器测试模拟 Windows 平台回传值，无法验收真实 DWM
壁纸取色与窗口失焦合成；这部分须在 Windows 客户端确认。
