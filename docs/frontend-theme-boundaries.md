# 前端主题的改变边界

2026-10-08：macOS、Windows、Android、iOS 共用。主题色板只负责表面，不负责正文和功能文字的颜色。

| 维度 | 谁控制 | 边界 |
| --- | --- | --- |
| 正文、标题、字段值、字段名 | 浅色/深色模式 | 浅色 `#111111`，深色 `#ffffff`；不随暖石、深海等色板变化 |
| 说明、导航文字、辅助文字 | 浅色/深色模式 | 中性黑白灰，说明 `#202020` / `#f5f5f5`，辅助 `#303030` / `#ededed`；不再使用主题中的低对比褐灰文字 |
| 背景、卡片、悬停和选中表面、边框 | 主题色板 | 保留不同主题的冷暖倾向，不能在色板内加入文字变量 |
| 强调色及填色主按钮 | 独立强调色设置 | 保留独立选择；填色按钮的黑白前景按实际填色对比度派生。普通正文不能借用强调色变量 |
| 错误、警告、成功、危险操作、敏感等级 | 业务语义 | 保留红/黄/绿及分级标识，不由装饰主题覆盖 |
| 玻璃、模糊、阴影、透明度 | 平台材质与辅助功能 | 不给文字叠加滤镜或额外透明度；高对比/强制颜色优先使用系统颜色 |
| 图标与品牌资源 | 图标语义或品牌 | 导航图标继承中性文字色，危险图标保留语义色；Windows一体顶栏不显示品牌图标，左侧导航展开时显示名称；导航列表与移动顶部不显示品牌标志，登录卡片/关于保留 |

实现上，`themeSchemes.ts` 的内部 `SurfaceScheme` 仅允许背景和边框 token，20个对外色板统一生成明暗文字与预览文字。`applyScheme` 清理旧版残留的 `--text-accent` / `--text-warm` 行内覆盖；这些装饰语义变量回归独立强调色，不用于正文。默认 CSS 和启动层采用相同文字边界，旧启动缓存只恢复背景，不能恢复偏色文字。账户和主题偏好仍按原有路径保存，不修改用户对象或字段数据。

普通启用态文字在全部20个色板的基础、卡片、卡片悬停、悬停和选中表面按普通字号4.5:1检查。玻璃下的原生最终合成仍须单独验证，不能将声明颜色对比度当成全部原生画面的证明。

macOS登录前后外壳统一采用90%填色，浅色沿用主题基础色，深色基底混入12%白色；侧栏、顶部栏与对应登录背景一致。浅色正文面使用纯白，深色正文面沿用原主题基础色。登录额外底板已删除，登录卡片按最新反馈改为普通实色，宽度缩为原来的80%。展开侧栏由232px缩至186px（约80%），交通灯下限继续生效。

2026-10-13：Windows显式安装原生窗框后使用52px一体顶栏，保留DWM的最小化、最大化和关闭按钮，网页按实际按钮区域避让。页面标题与业务操作同处这一行，正文另有12px圆角的实色表面；侧栏展开186px、折叠96px。侧栏开关在导航顶部、52px系统操作带下方，随左右侧栏设置定位于对应窗口外边缘，展开/收起坐标保持。Mica顶栏和导航直接透出原生材质，不再叠加主题或明度tint；实色回退使用主题基础色。原生窗框启用失败时撤除并保留旧AppBar布局。认证页和附件预览同步避让原生按钮，预览覆盖时不绘制其下方的旧顶栏；强制颜色交给Canvas/CanvasText。

2026-10-14：Windows 对象新建/编辑表单的取消、保存放在顶栏常显操作区，随正文滚动仍可使用，并避让系统窗口按钮。现有对象加载完成或新对象选择模板后才显示操作；保存请求期间禁用保存。其他平台保留原有随表单滚动的底部操作。

Windows 原生窗框支持完整遮罩时，对象详情和通用 Dialog 的背景由一个原生子窗口统一合成，包含顶部缩放细条、DWM 三按钮区域及正文；颜色继续来自 `--bg-overlay`。卡片圆角、上层弹窗与浮动控件保持前景，关闭时先释放原生遮罩再卸载卡片。网页只保留点击遮罩，不叠加第二份底色或模糊；不支持完整遮罩的窗框及其他平台使用原 DOM 遮罩。

Windows 侧栏使用 Segoe UI Variable Text / Segoe UI，中文回退 Microsoft YaHei UI，按钮显式继承系统字体；展开标签 14px，折叠标签 12px，普通字重 400、选中 500。其他平台保留各自字体。名称仍按原有溢出测量滚动，不缩小图标或改变按钮命中区。

系统媒体查询或原生窗口回传要求减少动态效果时，CSS transition 完全禁用；不能给所有元素设置非零 transition-duration，否则默认 transition-property: all 会让侧栏宽度、内边距和标签字号产生额外过渡。侧栏尺寸和图文布局须同次更新，Portal 几何只在实际卸载时释放。公开原生夹具必须加载与正式入口相同的全局样式，包含辅助功能动画规则。

Tools 动画启用时，竖向菜单的透明度、菜单裁剪和主导航避让裁剪共用 420ms 与同一缓动曲线；横向工具区的透明度与宽度共用 180ms。淡入淡出覆盖完整展开/收起过程，快速反向悬停从当前进度继续；关闭时立即退出点击及 Tab 顺序，竖向菜单延迟隐藏至淡出结束。系统、原生窗口或应用内任一减少动态效果设置启用时，竖向和横向 Tools 均立即展开/收起。

2026-10-16：恢复接收和二维码扫码/显示的浮动卡片统一限制为 `min(85vh, calc(100vh - 32px))`，超长内容在卡片内自然滚动。页首关闭与末尾操作须能分别滚动到达并命中，滚动不能丢失表单值；扫码视图也不能省略这项保护。高度使用视口单位，避免父级动画容器高度为 auto 时百分比约束失效。平台无关表面标记、平台材质映射和业务状态机保持。
