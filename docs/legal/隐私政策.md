# 隐私政策

**最后更新：2026-09-28（AI 数据流说明）**

## 数据存储

SoloSoul 是一款**本地优先**的应用，保险库数据保存在设备的数据目录中。使用您配置的 AI 服务时，请求内容会发送到该服务；本地存储不代表所有 AI 请求都在本机处理。

## 我们收集的数据

- SoloSoul 不将保险库内容作为分析或广告数据收集。您使用 AI 功能时向所选服务发送的数据范围见下文，不能概括为“从不传输任何个人数据”。
- 本地分析数据（如应用崩溃日志）仅存储于您的设备，绝不对外发送。

## 第三方服务

- 您可以配置本机、远程或自托管 AI 服务。请求的数据去向取决于实际地址以及该服务是否继续转发；服务名称或“本地”标签不是严格离线的保证。
- 发送聊天消息时，请求包含本轮输入及对话中的用户/助手历史。手动输入、粘贴或历史中的敏感文本不会按对象字段敏感度自动脱敏。
- 开启自动上下文后，请求还可包含候选公开对象的名称、类型和公开字段、部分偏好设置、软件版本/平台/语言及检索到的帮助片段。内部、敏感、关键及未知等级的对象字段不会自动附加；关闭此选项仍会发送您输入的消息和历史。
- 帮助文档的 Embedding 请求可能向配置的服务发送查询原文；重建索引可能发送内置帮助片段。启用“优先使用本地 Embedding”但未选中已安装模型时，可能回退到配置的服务。该设置不改变聊天的目的地。
- API 密钥保存在本地加密配置中，需要认证时随请求交给所选服务。连接测试、在线检查和 Embedding 支持检查也可能访问配置的服务。
- 首次启用的风险告知不是每条消息的二次确认。自动附加内容可随用户发起的请求一起发送；所选服务如何处理、保存或删除数据，以该服务的政策和配置为准，SoloSoul 不承诺其保留期限或不用于训练。
- 不包含任何第三方分析、遥测或广告 SDK。

## 检查更新与下载中转

- 当应用检查更新或下载安装包时，默认**优先直连** GitHub。
- 在直连不可达（例如部分网络环境无法访问 GitHub）时，应用会自动回退到第三方加速代理进行中转。此类代理会对连接进行 TLS 终止转发，因此**您的 IP 地址、正在使用 SoloSoul 的事实以及目标版本号可能会暴露给该第三方代理服务商**。
- 下载内容无论来自直连还是代理，均会经过加密签名与哈希校验，代理无法篡改安装包；中转仅影响传输通道，不影响数据完整性。
- 代理可能返回陈旧或失真的更新元数据（如旧版本信息），导致您无法及时获知新版本；此类情况不影响安装包完整性（签名与哈希校验仍生效），仅可能延迟更新通知。
- 如需完全禁用应用自身下载通道中的代理中转（仅使用直连），您可以通过环境变量 `SOLOSOUL_PROXY_PREFIXES` 将其置空——该变量覆盖应用自建的 GitHub API 元数据与安装包下载中转路径。
- **注意**：桌面端内置的更新检查通道（updater 插件）在编译期内置直连与多个代理回退端点，**不受该环境变量控制**；当直连不可达时仍会尝试内置代理端点，此行为无法通过环境变量关闭（Android 端全流程均受该变量控制，但移动端难以设置环境变量）。

## 安全性

- 您的保险库使用 AES-256-GCM 加密，密钥通过您的主密码推导（Argon2id）。
- 主密码从不存储——仅在会话期间存在于内存中。

## 您的权利

您可以导出、删除或修改本地保险库数据。关闭 AI 功能、关闭自动上下文或删除本地对话，不会撤回已发送内容，也不代表所选服务的副本已删除；远端数据处理需通过该服务提供的方式办理。
