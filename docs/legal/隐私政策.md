# 隐私政策

**最后更新：2026-06-01**

## 数据存储

SoloSoul 是一款**本地优先**的应用。您的所有数据仅存储在您的设备上的 `~/.solosoul/` 目录中。不会上传任何数据到云端。

## 我们收集的数据

- **无。** SoloSoul 不收集、传输或分享任何个人数据。
- 本地分析数据（如应用崩溃日志）仅存储于您的设备，绝不对外发送。

## 第三方服务

- SoloSoul 可能会连接到您自行配置的本地或自托管 LLM 服务。这些连接完全由您控制。
- 不包含任何第三方分析、遥测或广告 SDK。

## 检查更新与下载中转

- 当应用检查更新或下载安装包时，默认**优先直连** GitHub。
- 在直连不可达（例如部分网络环境无法访问 GitHub）时，应用会自动回退到第三方加速代理进行中转。此类代理会对连接进行 TLS 终止转发，因此**您的 IP 地址、正在使用 SoloSoul 的事实以及目标版本号可能会暴露给该第三方代理服务商**。
- 下载内容无论来自直连还是代理，均会经过加密签名与哈希校验，代理无法篡改安装包；中转仅影响传输通道，不影响数据完整性。
- 代理可能返回陈旧或失真的更新元数据（如旧版本信息），导致您无法及时获知新版本；此类情况不影响安装包完整性（签名与哈希校验仍生效），仅可能延迟更新通知。
- 如需完全禁用应用自身下载通道中的代理中转（仅使用直连），您可以通过环境变量 `SOLOSOUL_PROXY_PREFIXES` 将其置空——该变量覆盖应用自建的 GitHub API 元数据与安装包下载中转路径。
- **注意**：桌面端内置的更新检查通道（updater 插件）在编译期内置直连与多个代理回退端点，**不受该环境变量控制**；当直连不可达时仍会尝试内置代理端点，此行为无法通过环境变量关闭（Android 端全流程均受该变量控制，但移动端难以设置环境变量）。

## 安全性

- 您的保险库使用 AES-256-GCM 加密，密钥通过您的主密码推导（Argon2id）。
- 主密码从不存储——仅在会话期间存在于内存中。

## 您的权利

由于所有数据都是本地的，您拥有完全控制权：随时导出、删除或修改您的数据。
