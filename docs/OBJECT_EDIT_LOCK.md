保护标记为加密对象 properties 中的 `__editLocked`，沿用保留元数据规则，不作为用户字段展示。已有对象缺少标记视为可编辑。非 false 的异常保护值按锁定处理。锁定不改变字段敏感度、查看与揭示规则。

实现约定：

- 普通单项/批量写入、删除、附件增删与属性修改、模板同步及历史恢复统一检查最新落库状态；失败时不提交部分数据库修改。表单保存保留内部元数据及最新附件列表。
- 显式锁定/解锁只更新保护标记、版本、时间和同步时钟，并记录审计；不创建字段历史快照。新对象首次保存后提供锁定操作。
- 锁定有未保存修改的对象时，先执行现有字段校验并保存，成功后再锁定；失败保留草稿。普通“保存”仍沿用当前返回行为，队列中的保存后停留/即时历史刷新未恢复。
- 备份和导出保留标记。设备同步按既有 HLC/冲突规则复制完整状态，可传播另一设备的显式解锁。同一受控导入可完成来源中已经锁定对象的附件恢复；导入开始后新增的本地锁定阻止待完成的附件修改。清理器继续严格检查导入日志字段及类型。
- 入口共用状态展示，包括桌面对象树、悬停预览、卡片、详情、搜索、右侧资料面板、安卓列表和全局附件分组。查看、揭示、复制、历史浏览、附件预览和下载保持可用。
