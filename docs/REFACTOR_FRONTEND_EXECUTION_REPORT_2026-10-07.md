## 1. 目标与范围

本轮主要重构 React / TypeScript / CSS 前端，先完成 macOS 导航着色、圆角实色工作区、固定顶栏开关与登录页材质，再统一移动端的主题来源、表面和材质输入。目标是清晰的表面层级、稳定的布局和可维护的样式职责。设计依据为[桌面布局研究](CHATGPT_DESKTOP_LAYOUT_RESEARCH_2026-10-07.md)和[移动端统一方案](platform-mobile/MOBILE_VISUAL_ALIGNMENT_PROPOSAL_2026-10-07.md)。

本报告是新一轮执行台账，不覆盖[第一轮报告](REFACTOR_EXECUTION_REPORT_2026-09-25.md)，也不是已完成的全前端审计。沿用[代码审查流程](review_code_process.md)的逐项分析、验证、记录方式；任务登记、HTML 预览与客户端实现分别记录，不能以预览通过代替生产验收。

- 优先处理 macOS 前端；公共组件变更必须检查 Windows / Android 是否受到影响。
- 原生层只允许与本轮材质目标直接相关的必要适配，不扩大为 Rust 核心、加密、存储、同步或插件架构重构。
- 登录页是本轮明确的局部玻璃面板；不据此把所有内容卡片、业务弹窗和按钮改成玻璃。
- 不改变认证请求生命周期、掩码与揭示、自动锁定、账户偏好保存、导航返回等既有业务约定。
- 用户已授权开始 macOS 与移动端前端重构，按 macOS 在先的顺序执行；不含提交推送或发布。

### 1.1 已取得的设计反馈

用户提出两条材质方向：加深 macOS 侧边栏与顶部栏的颜色，降低过度透明；登录页使用较深的半透明玻璃底板，承托较浅的玻璃登录卡片。

已制作[登录页 HTML 预览](previews/macos-login-glass-review.html)，包含“高透明对照”“加深底色”“双层玻璃”三种方案，支持主题、填色强度、登录方式与减少透明度切换。用户反馈：**背景 90%、卡片 80% 好像还可以**。预览已将这两个值设为默认，作为实施起点，不表述为最终原生验收通过。

| 层级                 | 本轮设计基准                                     | 实施边界                                                          |
| -------------------- | ------------------------------------------------ | ----------------------------------------------------------------- |
| 窗口环境底色、导航区 | 填色强度 90%，保留少量环境透色                   | 模糊与玻璃由现有原生材质提供；不设置整层 `opacity: .9`            |
| 登录页底层面板       | 比登录卡片更深的半透明底色，完整圆角与四周留白   | 与窗口底色是两个独立图层，不将多个 alpha 合成后称为“总透明度 90%” |
| 登录卡片             | 填色强度 80%，较浅，保留局部玻璃、柔和边缘与阴影 | 文字与控件保持不透明；参数限定在登录面板，不全局改写内容 Card     |
| 按钮与输入区         | 清晰的平面反馈，焦点、禁用和错误可辨认           | 不逐个增加滤镜、高光或玻璃按钮                                    |

这些百分比指 HTML 中背景色的 alpha，**不是玻璃折射强度，也不是容器或文字透明度**。浅深主题需分别校准，沿用应用色板；预览中的颜色不自动成为全局主题色。HTML 的 CSS 模糊不能证明 NSGlassEffectView 的真实合成表现。

- `tauri/src-tauri/src/commands/window/macos.rs` 提供原生玻璃 / vibrancy，并保留透明窗口背景 alpha `0.001` 的恢复闪黑修复。加深视觉底色不等于更改此原生背景参数。

建立报告时存在本地 Android 插件资源修改、错误报告 ZIP、Python 缓存和 Apple 生成资源等未提交内容；本轮 HTML 预览也尚未提交。实施前重新读取 `git status`，核对归属；不自动清理或把无关文件并入当前任务。

保护要求：

- 保留窗口原有圆角、交通灯按钮、统一拖拽高度、按钮命中区与折叠侧栏最小宽度。
- 保留 Dock / 台前调度恢复的防闪黑修复，不引入恢复时重新创建材质层的无依据方案。
- 登录页卡片上、下沿均留出距离；小窗口允许内容滚动，不能裁掉圆角、解锁按钮或恢复入口。
- 内容正文保持稳定表面；顶栏玻璃不延伸为正文玻璃，不使用覆盖内容的全窗口遮罩。
- 文件、照片集、照片查看器的整条顶部栏与主窗口材质协调，防止只留下交通灯附近一小块玻璃。
- 滤镜仅施于绘制表面的层，不把 Portal / fixed 子浮层置于新的含滤镜或 transform 的定位祖先中。
- 系统减少透明度、高对比与减少动态效果保留；旧系统继续使用已支持的材质回退。
