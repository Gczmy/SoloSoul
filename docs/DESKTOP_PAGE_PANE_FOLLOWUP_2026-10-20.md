## PREP：当前源码的隔离验收入口

夹具使用正式 AppShell、顶栏、图标侧栏、页面树、调宽及动画模块；业务内容为 48 个公开示例对象、一个长名称页面和内存中新建页面。原生宿主不注册账户或 Vault 业务命令，并使用独立 WebView2 数据目录。

验证：Vite 自包含夹具构建通过；121 个打包来源与当前源码哈希一致。Chrome 启动检查确认对象导航、区域开关和浮动创建页面可用，无页面脚本错误。动态效果开关的启停及系统限制状态检查通过。11 个原生窗框源文件与当前生产源码逐字一致，隔离宿主构建通过。Windows 实际窗口已显示新页面树与原生一体顶栏。

用户随后明确要求桌面动画独立于系统，此要求由 DP-01 替代此前遵循系统减少动态效果的桌面规则。布局整体原生人工验收尚未完成，不将打开窗口或单项状态核验计作整体通过。

原始日志、程序、公开夹具运行数据及截图不入库。

## DP-01：桌面动画独立于系统

新增统一动效策略：Windows、macOS、Linux 使用应用自身的减少动态效果设置；原生系统偏好单独记录，不再禁用桌面 CSS 动画、页面树过渡、长名称滚动和标尺平滑滚动。启动页同步采用该策略。移动端继续遵循系统设置，高对比与无动画 API 的静态名称回退保留。

验证：类型检查通过；Lint 退出 0，仅保留原 syncStore 未使用参数警告；33 项直接相关单测通过；Node 270 通过、1 原跳过；15 项页面树与长名称浏览器回归通过（其中两项初次登录准备超时，独立重跑通过）；两组系统/原生减少动态效果受控浏览器检查通过。公开隔离夹具构建通过，实际桌面过渡为 320ms，应用内关闭动画仍有效。全量前端单测在后台续跑，最终结果另记，不以启动或部分输出充当通过。
