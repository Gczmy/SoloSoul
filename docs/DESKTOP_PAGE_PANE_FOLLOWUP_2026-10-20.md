## PREP：当前源码的隔离验收入口

夹具使用正式 AppShell、顶栏、图标侧栏、页面树、调宽及动画模块；业务内容为 48 个公开示例对象、一个长名称页面和内存中新建页面。原生宿主不注册账户或 Vault 业务命令，并使用独立 WebView2 数据目录。

验证：Vite 自包含夹具构建通过；121 个打包来源与当前源码哈希一致。Chrome 启动检查确认对象导航、区域开关和浮动创建页面可用，无页面脚本错误。动态效果开关的启停及系统限制状态检查通过。11 个原生窗框源文件与当前生产源码逐字一致，隔离宿主构建通过。Windows 实际窗口已显示新页面树与原生一体顶栏。

用户随后明确要求桌面动画独立于系统，此要求由 DP-01 替代此前遵循系统减少动态效果的桌面规则。布局整体原生人工验收尚未完成，不将打开窗口或单项状态核验计作整体通过。

原始日志、程序、公开夹具运行数据及截图不入库。

## DP-01：桌面动画独立于系统

新增统一动效策略：Windows、macOS、Linux 使用应用自身的减少动态效果设置；原生系统偏好单独记录，不再禁用桌面 CSS 动画、页面树过渡、长名称滚动和标尺平滑滚动。启动页同步采用该策略。移动端继续遵循系统设置，高对比与无动画 API 的静态名称回退保留。

验证：类型检查通过；Lint 退出 0，仅保留原 syncStore 未使用参数警告；33 项直接相关单测通过；Node 270 通过、1 原跳过；15 项页面树与长名称浏览器回归通过（其中两项初次登录准备超时，独立重跑通过）；两组系统/原生减少动态效果受控浏览器检查通过。公开隔离夹具构建通过，实际桌面过渡为 320ms，应用内关闭动画仍有效。全量前端单测在后台续跑，最终结果另记，不以启动或部分输出充当通过。

## DP-02：页面和对象悬停详情

页面卡片展示完整名称、描述和对象数量；对象卡片直接复用 ObjectRulerPreview 的外观与字段掩码，最多显示三个字段，并提供编辑入口。详情通过短暂悬停后的一次只读请求加载，仅留在当前卡片组件中；不扩大常驻页面索引的数据范围。账户、对象 ID、删除状态、会话代次均校验，退出或锁定后旧响应不进入界面。

同一时刻只保留一张页面树详情卡，Portal 避免滚动容器裁剪；位置受窗口边界约束。支持鼠标移入卡片、键盘焦点、Esc 返回触发行、列表滚动清理和折叠立即关闭，保留原名称滚动交互。

验证：类型检查和改动 Lint 通过；22 项相关单测通过，含六项新增的掩码与请求归属边界；18 项浏览器回归通过（17 项整组加一项焦点滚动补验）；最终公开原生夹具构建通过。另，DP-01 续跑的完整前端基线已收尾：270 个文件、2433 项单测通过。该基线不冒充 DP-02 新增用例的全量执行；新增用例已由本项专项覆盖。

## DP-03：顶栏按钮名称提示与最终收尾

复用现有导航名称卡片样式，在顶栏页面树按钮悬停或键盘聚焦时显示当前动作。展开时为“收起页面与对象”，收起时为“展开页面与对象”；提示保持在窗口内，支持 Esc 和失焦关闭，不改变原生拖动与按钮命中区域。

最终验证：271 个文件、2439 项前端单测通过；类型检查和全量 Lint 通过（仅原 syncStore 警告）；生产前端和公开隔离夹具构建通过。相关浏览器用例共 19 项分批通过，其中本项验证提示随状态更新、边缘避让、键盘焦点及 Esc。134 个夹具来源哈希与最终源码一致，11 个原生窗框源文件与隔离宿主的生产来源一致。

Windows 实机将系统动画临时关闭，原生与媒体查询均报告减少动态效果，应用策略仍为独立控制；实际观察到页面树展开、收起的中间帧及完成状态。浅深主题的页面和对象详情卡片、公开字段与敏感字段掩码、Esc 关闭和顶栏名称提示均已核对。系统动画已恢复开启并核对保存状态。整体布局人工验收继续由用户完成，其他任务继续暂停。见去标识验证摘要 `docs/verification/desktop-page-pane-followup-2026-10-20.json`。

## DP-04：标题跟随正文边界

顶栏当前页面标题改为位于主内容区上方，与正文左侧留白对齐。页面树宽度提升到外壳共同作用域；标题、正文和分隔线共用宽度及过渡参数。拖动时即时更新，展开收起时同步过渡，保留 macOS 交通灯与顶栏开关的安全距离。没有改变原生窗框或移动端布局。

验证：10 项页面树浏览器回归通过，覆盖拖动中的对齐、上下限、键盘调宽、刷新持久化、最小桌面窗口及快速反转逐帧对齐；14 项外壳与操作栏单测、类型检查、改动文件 Lint 通过。初版复用尺寸监听修改顶栏引出了循环通知，已改为共享布局宽度，最终运行无该错误。首次定向运行的一项登录准备超时已由最终整组通过覆盖。单测首次受沙箱缓存重命名权限影响，改用 D 盘临时目录后复验通过。

## DP-05：固定开关提示

按用户新要求，顶栏按钮悬停或聚焦时统一显示“显示/隐藏侧边栏”，展开和收起时不切换文案；英文同步为“Show/hide sidebar”。保留明确的当前动作无障碍名称和 aria-expanded 状态。此项替代 DP-03 的动态提示文案，提示卡片交互保持不变。

验证：浏览器专项通过，覆盖两种状态下固定提示、窗口边界、键盘聚焦、Esc 和失焦关闭；格式检查通过。

## DP-06：对象预览入口图标

对象预览的入口统一使用 14px 向右箭头，与页面详情中的“打开页面”一致。页面树复用的标尺预览也同步更新；按钮文字、编辑跳转及字段掩码均保持原行为。

验证：6 项页面树对象预览单测通过。此项为图标替换，不新增复述实现的测试；最终原生公开夹具中复核外观。

## DP-07：功能图标栏与顶栏等宽等高

按用户最终选择，以较小的顶栏高度为准，页面树布局中的功能图标栏共用同一尺寸源。当前 Windows 为 52px × 52px，未接入原生一体窗框时的 Windows 回退高度也保持 52px；移动端保留原导航。macOS 顶栏控件继续单独避让交通灯，不再扩大整条图标栏。

用户实机指出仍有视觉差异后，核实是 Windows 内容面顶部另有 8px 间距，已去除。最终原生记录确认：顶栏高 52px、图标栏宽 52px、内容面左上角为 (52, 52)，浅深主题一致；内容边框与圆角保留。真实拖动分隔线由 264px 增至 344px 时，顶栏标题与正文同步移动，复位可用。公开窗口已替换为最终夹具，保留供用户继续验收。

验证：61 项浏览器场景分批通过（最终整组 58 项通过，三项首次登录准备超时后独立重跑通过），覆盖 Windows 原生命中区、macOS 交通灯/全屏几何、页面树、快捷卡片、主题、图标居中及 Android/iOS 导航隔离；24 项相关单测、类型和改动文件 Lint 通过。初轮的旧宽度与居中断言已随本项更新，并纠正了一项此前未同步 DP-01 策略的旧动效断言。最终夹具构建成功，134 个前端来源及 11 个原生窗框来源与当前源码一致。

Windows 实机同时核对了固定中文开关提示、页面与对象的向右箭头、敏感字段掩码以及展开收起。macOS 本项仅有浏览器与源码验证，仍待真实 macOS 设备验收。整体布局的用户人工验收继续保留待确认，其他任务继续暂停。见 `docs/verification/desktop-page-pane-alignment-2026-10-20.json`；原始日志、截图、程序和本机路径不入库。

## DP-08：统一 Windows 应用按钮与留白

顶栏和功能栏的应用按钮共用 36px 尺寸、20px 图标、8px 圆角；52px 顶栏上下和功能栏左右各留 8px。文字操作统一为 36px 高，指南等带文字的图标按钮保留内容宽度，更多菜单仍可按实际可用宽度收纳。功能栏相邻按钮统一为 8px 间隔，工具菜单双侧预留滚动条空间以保持图标居中，锁定与设置区不再占用透明分隔线的额外 1px。

36px 控件位于顶栏 y=8..44，避开 Windows 顶部 8px 原生缩放边缘。顶栏焦点描边改为内描，与功能栏一致，不被原生裁剪。右上三个窗口按钮仍由 Windows 绘制，保留原有大小及原生命中和 Snap 行为；本项没有修改原生窗框。规则仅在 Windows 桌面页面树布局生效，macOS 和移动端保持现有尺寸。

验证：58 项不同浏览器场景分批通过（18 项外壳/原生命中区场景和 40 项页面树、编辑器、工具区、主题及平台隔离场景）；收尾焦点与分组间距调整后的 8 项相关场景复验通过；14 项外壳/操作栏单测、类型检查、改动文件 Lint 通过。四项编辑器用例起初被旧的全局对象定位阻塞：它选中页面树对象行后直接进入编辑页，却继续等待详情弹窗。已将测试入口限定为主内容区卡片，原有详情→编辑→保存/取消、对比度和命中断言均保留并通过。

最终公开夹具构建成功，134 个前端来源与当前源码哈希一致，复用宿主的 11 个原生窗框来源仍与生产源码一致。Windows 实机浅深主题确认：顶栏与功能栏均为 52px；应用按钮高 36px，图标按钮宽 36px；顶栏按钮 y=8，功能栏按钮 x=8，图标为 20px；第一行和底部设置按钮均保留 8px 外侧留白。已观察完整键盘焦点描边，并在按钮顶部附近 y=9 实际点击成功收起页面树。
