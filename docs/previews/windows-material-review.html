01 / 结构

只保留一道窗口边缘

去掉侧边栏与内容区重复描边，AppBar 和正文使用同一内容面。导航靠空间与选中底色区分，卡片靠明度与间距区分。

02 / 操作

按钮按重要性分层

主要操作使用强调色；次要操作使用浅填色；工具和指南常态平面，悬停再显底色。危险操作保留红字，悬停淡红背景，不堆叠反光边线。

03 / 状态

将深度留给浮层

菜单使用克制的 Acrylic 示意和软阴影，普通按钮不叠玻璃。键盘焦点保留清晰描边；高对比度恢复必要边界，减少动态效果时关闭过渡。

评审范围：SideNavigation、AppShell、AppBar 与 Windows 专属按钮样式。正式实现需要在 Windows 11 的原生 Mica 窗口中验收；本 HTML 用颜色模拟 Mica，不代表浏览器能调用系统材质。上方“现有”模式仅按当前代码重现线条关系，不是 Windows 实机截图。
参考：Microsoft · Mica 分层建议 · Microsoft · Layering and elevation。本方案依据这些建议减少重复轮廓，并保留必要的交互和辅助功能边界。
