# SoloSoul Cli 终端版本预研
solosoul终端版本，通过指令来登录账户、创建页面、创建对象等操作。
参考开源软件:

OpenCode:https://github.com/anomalyco/opencode
以及其他好用的TUI开源软件:https://github.com/rothgar/awesome-tuis

# 打开软件
打开方式：直接在终端运行 solosoul
支持运行 solosoul upgrade更新软件

如果用户是下载后第一次打开软件（即没有任何账户），则提示用户进行账户创建并提供创建指导：1.输入账户名，2.设置主密码，3.二次输入主密码，4.输入主密码提示词（可选）。
然后提醒用户主密码不会被保存，需用户牢记，不可找回，丢失无法登录账户，所有数据无法找回。
完成创建过程后，进入首页。

如果用户不是第一次打开软件，则进入登录流程。
登录流程仅提供部分命令可用：
/login 登录账户
/account_list 列出当前账户列表
/exit 退出cli软件
/doctor 检查软件依赖等问题
/update 检查软件版本是否有可用更新，如果有则更新，没有则显示当前已经是最新版本


# 登录流程
/login 命令登录账户，显示账户列表,支持光标向下滚动选择，回车选中:
-[] account_1
-[] account_2
...

选择后显示登录方式（选项指纹识别和面容识别只有当账户开启对应功能后才出现）：
-[] 主密码登录
-[] 指纹识别(Touch ID)
-[] 面容识别(Face ID)

如果选择主密码登录选项，则让用户输入主密码，如果选择指纹识别则弹出系统的指纹识别系统验证，面容识别同理。

登录成功后进入首页，显示登录欢迎词，接着在这里用户就可以进行各种账户内操作了:
/newpage [page name] : 根据页面名创建页面，如果填入页面名，则直接根据页面名创建页面，如果没有填入页面名，则提示用户输入页面名。如果页面名重复则报错，如果页面名不重复则显示创建成功。
/newobject [page name]：进入创建对象流程，如果填入页面名，则在该页面创建对象，如果没写页面名，则流程询问在哪个页面创建对象：
(没输入页面名显示)
-[] “你正在创建对象流程中，请选择该对象的所属页面：（type here）”
-[] 进入页面列表选择
用户可以输入页面名或者进入下方的页面列表选项。如果用户输入的页面名不存在，则返回信息“页面名不存在，请输入正确的页面名”，如果页面名存在，则进入创建对象流程2
如果用户选择-[] 进入页面列表选择，则显示所有页面名：
-[] 身份
-[] 旅行
-[] 财务
-[] 职业
-[] 自定义页面1
-[] 自定义页面2
...
-[] 返回
用户选择了页面后，进入创建对象流程2

流程2：
1.让用户输入创建对象的对象名称
2.给出对象模板选项：
-[] 对象模板1
-[] 对象模板2
...
-[] 返回

完成后进入流程3
流程3：对象字段属性填写，根据选择的对象模板，显示模板里的字段属性卡片等（这里需要一种好的显示效果）
-[] [文本] 字段1名称 [公开] 
-[] [时间日期] 字段2名称 [内部] 
-[] [单选] 字段3名称 [敏感] 
...
-[] 保存
用户填写字段数据，然后选择保存

创建对象流程结束，对象被成功创建
