# 顶栏指南直接显示

2026-10-23 已完成源码修复。安卓顶栏只有指南这一项次要操作时，直接显示指南按钮；锁定保险库及账户按钮保留。Windows/macOS 的单指南操作在左侧页面区域展开、隐藏和宽度变化时保持直接可见。真正包含多个次要操作的页面继续使用原有宽度收纳与键盘逻辑。

验证：15 项组件回归通过；9 项浏览器场景通过，覆盖 Android 320/390px、Windows/macOS 800/1100px、左侧区域往返、指南打开/关闭及焦点恢复、多操作菜单与 macOS 材质/高对比度回退。Windows 800px 对象工作区补验通过，验证嵌套的指南和新建操作同时可用。类型、改动源码 Lint 和格式检查通过，三平台公开夹具截图已检查。旧测试沿用的 14px 字体/40px 高度断言改为现有 13px 字体及实际顶栏边界；本项不调整产品字体或顶栏尺寸。

浏览器控制台在区域动画期间仍观察到 `ResizeObserver loop completed with undelivered notifications`；部分公开夹具未提供更新/AI 配置响应时也有相应警告。交互与几何断言通过不代表零告警或原生验收。本次未重新构建安装包，模拟器仍是此前的审核版本，发布构建及其他任务保持暂停。
