## 第七项：文本滚动连续性

- 用户反馈原生窗口的文字滚动有卡顿。旧实现在等待、前进、末尾停留、返回、起点停留之间取消并重新创建动画；这次将整个往返合并成一条无限循环的 `translate3d` 合成时间轴，阶段切换不再交接动画实例。
