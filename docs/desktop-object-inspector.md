## 第二项行为

- 面板和编辑区是同一内容面的独立网格列，复用主题色与普通字重；保持顶栏 52px、功能栏 56px。开关采用已有布局动画机制，关闭后立即卸载资料与预览。
- 右栏状态跟随当前编辑对象；新对象尚未就绪时不显示上一个对象的名称、记录或附件。对象加载失败时显示错误，不停留在加载状态。
- 切对象、切账户、锁定/重新解锁、关闭右栏或切换页签时，旧请求和解锁结果不能恢复已释放的内容；历史仍经过既有字段保护与验证流程。
- 附件按入库时间倒序列出名称、大小与时间，点击后复用现有预览和外部打开。列表分批显示，不额外加载回收站附件或批量解密快照。
- 窗口宽度低于 1100px 时，打开右栏暂时隐藏左侧页面树，关闭后恢复原偏好；点击左栏开关可返回页面树。该临时布局不覆盖已保存的左栏偏好，也不重建编辑表单。
- 页签支持方向键、Home/End 切换；关闭面板后焦点返回顶栏开关。附件和历史各自滚动，顶部页签与底部排序说明固定。
