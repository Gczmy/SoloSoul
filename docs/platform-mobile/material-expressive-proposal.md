# SoloSoul Android · Material 3 Expressive 设计细化

日期：2026-09-15。状态：已按本提案接入 Android 客户端，见 [实施记录](material-expressive-implementation.md)。下文保留原型与设计决策。

## 设计方向

以“有温度的秩序”为方向，延续 SoloSoul 的暖灰底色与盾牌标识，用色调层级、分组容器、胶囊选中态和少量形状变化表达 M3 Expressive。颜色帮助识别信息归属，主要动作容易找到，文字与图标保持稳定。

Google 将 M3 Expressive 作为组件、形状、色彩与运动设计的扩展。本方案将这些原则应用到 SoloSoul；下面的颜色、尺寸、文案和动效参数都是项目提案，不是对 Google 官方规范的逐项复刻。[Android 官方 M3 Expressive 示例](https://android-developers.googleblog.com/2025/05/androidify-building-delightful-ui-with-compose.html)

## 可查看的样例

- `material-expressive-demo.html`：完整单文件原型，离线可用，桌面显示设计说明，手机宽度下直接显示应用界面。
- `material-expressive-gallery.html`：三个可交互屏幕并排展示：首页、对象列表、深色新建弹层。与 demo 文件放在同一目录即可打开。
- `material-expressive-preview.png`：由上述 HTML 实际渲染的静态预览。

支持：首页分类跳转、对象分类筛选、名称/简介搜索、排序、详情查看、示例字段揭示/隐藏、新建与编辑示例对象、新建示例页面、锁定/解锁演示、三套主题色、深浅外观、减少动态效果。扫描、AI、同步等工具提供入口和说明，不执行真实业务。

数据仅在页面内存中，刷新后重置。主题色选择是手动预览，不代表已经读取 Android 壁纸或接入系统动态配色。

## 页面与导航

| 区域 | 设计细化 | 与现有代码的关系 |
| --- | --- | --- |
| 顶部 AppBar | 内容栏 64 CSS px，系统安全区单独叠加；保留盾牌 Logo，右侧 48px 锁定和账户入口 | 当前移动 AppBar 为 48px，可在 Android 主题下调整；保留 `MainActivity` 的 edge-to-edge / 多窗口处理 |
| 首页 | 单个色调概览容器；现有身份、旅行、财务、职业、文档分类以圆角组块展示；最近更新使用紧凑分组列表 | 沿用 `HomePage` 的页面来源；概览统计从现有对象数据派生 |
| 底部主导航 | 四个同级目的地：首页、对象、工具、设置；选中背景为胶囊，图标不移动、不缩放 | 这是导航结构提案。沿用 `/workspace` 的已有汇总查询作为对象入口 |
| 主动作 | 右下角 56px“新建”扩展 FAB；展开后选择新建对象、新建页面、扫描导入 | 复用已有对象编辑器、`AddPageButton` 和 OCR 入口；从主导航中分离操作按钮 |
| 对象列表 | 52px 搜索框、可横向滚动的筛选按钮、分组列表；名称/分类/时间优先，完整字段进入详情 | 当前结果与分类逻辑继续复用；实施时确认 `/workspace` 已支持全部对象查询；本轮新增常驻“全部”筛选与分组列表视图 |
| 对象详情 | 标题与分类标记置顶，字段分组呈现，编辑采用低于 FAB 的强调级别 | 正式接入必须复用 `useRevealState`、`SensitivityBadge`，保留项目敏感度规则 |
| 工具页 | 聚合搜索、扫描、AI、同步、附件、模板、导入导出、插件 | 沿用现有 `useMobileNavActions` 的可用入口与权限，不复制业务逻辑 |
| 设置 | 账户卡、外观分组、资料库分组；主题切换不改变布局尺寸 | 复用现有主题和设置存储；demo 的状态不直接迁入产品 |

Android 官方建议底部导航承载 3–5 个同级目的地，将主要操作交给 FAB，大屏切换导航轨道。四个目的地与独立新建操作基于这一原则；具体取舍仍是 SoloSoul 的设计决策。[官方导航指南](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns)

## 视觉规则

### 色彩与材质

基础方案用不透明的色调表面建立层次。背景、内容分组、选中项分别使用语义色，不依赖大面积模糊。M3 Expressive 原型不要求液态折射；之前调研的局部玻璃可作为后续单独比较的变体。

默认主题选“雾蓝”，可切换“鼠尾草”和“陶土”。保留现有渐变盾牌标识。

| 语义色 | 浅色示例 | 深色示例 | 用途 |
| --- | --- | --- | --- |
| surface | `#F9F9F3` | `#181D1B` | 页面与 AppBar |
| surface-container-low | `#F0F1EA` | `#222925` | 分组列表、底部导航 |
| surface-container-high | `#E7E9E1` | `#303934` | 搜索框、次级状态 |
| primary | `#405F82` | `#AFCBEC` | 主要动作、强调文本 |
| on-primary | `#FFFFFF` | `#153451` | 主要按钮内容 |
| primary-container | `#D9E7F8` | `#2C4560` | 概览、选中胶囊 |
| on-primary-container | `#223E5E` | `#D3E5FA` | 强调容器文字 |
| on-surface | `#20251F` | `#E5E9E0` | 正文 |
| on-surface-variant | `#626B62` | `#B6C1B4` | 辅助文本 |

不以颜色单独表示选中或安全状态：导航同时使用标签字重与胶囊；筛选同时显示勾选图标；字段同时显示敏感度标记。

系统动态配色属于后续可选接入：需从 Android 侧读取调色信息、经现有 IPC 传给前端，再映射语义色。原型中的三套色板是人工设计，不能标成系统自动取色。

### 形状、字号与密度

- 普通容器：16–24px 圆角；重要容器：28px；选中态：胶囊。少量概览容器使用不对称圆角，避免每个元素都争夺注意力。
- 对象组使用连续列表，组内 2px 间隔。避免每个字段重复加入边框、阴影和嵌套卡片。
- AppBar 标题约 19–20px，页面标题 28–32px，对象名称 14–16px，主要辅助文本/导航标签约 12px。
- 主要交互目标至少 48×48 CSS px；视觉图形可以更小，例如开关轨道位于 48px 点击区内部。图标使用固定 24px 容器。
- HTML 数值为 CSS 逻辑像素。原生实现的 dp 与 WebView 实际密度、安全区需要在设备上核对，不能把截图像素直接用作物理像素。
- 示例字体使用系统中文无衬线字体，不加载远程字体。正式版本继续采用现有字体策略；原型不声称使用了 Roboto Flex 的可变字轴能力。

### 动效

| 触发 | 表达 | 原型建议 |
| --- | --- | --- |
| 切换主导航 | 选中背景沿水平方向舒展，旧背景收起 | 约 320ms，图标与标签锚点不变 |
| 选择分类 | 圆角矩形变为胶囊，颜色与勾选同步 | 约 250ms，保持高度与布局稳定 |
| 新建弹层 | 从底部进入，背景增加遮罩 | 约 340ms；关闭后恢复触发控件焦点 |
| FAB 交互 | 圆角更饱满，保持按钮位置 | 约 280ms，仅形状变化 |
| 返回首页 | 直接显示完整内容 | 不对整页添加淡入淡出，不重复播放全卡片入场 |
| 减少动态效果 | 直接更新最终状态 | 关闭过渡和入场动画，保留高亮与可操作性 |

HTML 使用 easing 近似展示弹性节奏。正式版本可用现有 Framer Motion 在需要中断的交互上实现 spring；不在高频滚动中反复写布局尺寸。

## 实施拆分

1. **主题与基础组件。** 新增 Android 的语义色、形状与密度 token，先让 Card、Button、Chip、AppBar、导航共享规则。按平台判定启用，避免仅凭窄视口把桌面版改成 Android 外观。
2. **现有页面改造。** 优先首页、对象列表、工具入口与设置，沿用已有状态和业务命令。四目的地导航/全部对象汇总单独处理，便于与纯视觉变更分开审查。
3. **交互完善。** 主动作弹层、导航状态、焦点恢复、减少动态效果。沿用现有揭示超时与锁定清理机制，原型自己的 JavaScript 只服务于演示。
4. **适配验证。** 真机核对系统栏、手势区、键盘、横屏、分屏、字体放大；平板使用导航轨道与双栏空间。原型当前只演示手机布局，桌面旁栏是设计审阅界面，不是平板客户端方案。

视觉验收重点：主题切换不跳位；导航图标不缩放；返回首页不整页闪烁；弹层不被内容遮挡；底部操作不被键盘/手势区遮挡；受保护字段锁定后不可见。性能、真实触控与 Android 系统栏行为仍需接入客户端后验证。

## 本轮原型验证

Chrome 与 WebKit 均通过：导航图标节点和几何位置保持不变、筛选前后按钮宽度不变、搜索/空结果、新建/编辑对象、新建页面、示例字段显示与隐藏、弹层 Esc 关闭及焦点恢复、锁定/解锁、三套主题色与深浅外观、减少动态效果开关。检查了 320、360、390、430、768、1440px 六档视口，没有页面级横向溢出；浏览器无脚本异常、无 HTTP 外部请求。

已目测桌面审阅布局、320px 手机布局与三屏预览。以上验证针对独立 HTML 原型，不等同于 Android WebView 真机、系统栏或安全业务验证。
