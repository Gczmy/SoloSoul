## UI-01：模板列表操作按钮

修复前，桌面编辑按钮为 42×34px，删除按钮为 28×28px，中心相差 3px。编辑按钮改用与图标删除按钮相同的 BadgeIconButton，统一为 28×28px 命中区、14px 图标；补齐编辑提示与无障碍名称。操作组居中且不收缩，名称区域允许长名称换行，避免挤压按钮。Android 沿用 48px、iOS 沿用 44px 的平台命中区。

验证：公开数据的 8 组浏览器场景通过，覆盖 Windows/macOS/Android/iOS 浅深主题，各检查两个视口、普通及长名称卡片，按钮尺寸一致、中心偏差小于 1px、图标居中且未越界；编辑和删除确认入口独立打开，取消正常。检查了 Windows 浅色和 Android 深色截图。11 项现有组件测试、类型、改动 Lint 和差异空白检查通过；图标按钮单进程复验 1 项通过，不重复累计。初次浏览器操作探针按对话框名称定位失败，改为定位已有标题后整组通过，未改动生产对话框。

所有验证只使用公开夹具；原始日志、截图和临时测量脚本留在本地，不入库。本项不代表 macOS 原生实机验收。

## UI-02：回收站卡片操作按钮

恢复与删除原为 40×34px 普通按钮，详情为 26×29px 原生按钮，详情图标内部纵向偏移 1.5px。三个入口统一使用共享图标按钮：桌面 28×28px、14px 图标，Android 48px、iOS 44px；操作组统一垂直居中且桌面不收缩，危险操作保留红色语义。点击回调和事件传播隔离保持原行为。

验证：8 组四平台浅深主题浏览器场景通过，各检查窄宽视口、按钮尺寸和中心、图标中心及卡片边界。恢复和删除分别进入确认框并可取消，期间不请求详情；详情入口实际请求一次并显示对应对象。已有勾选框/图标对齐的四平台回归全部通过，共 12 组不同浏览器场景；5 项现有组件测试、类型、改动 Lint 和差异检查通过，检查了 Windows 深色截图。初次详情探针使用该面板未提供的 dialog 语义导致定位失败，调整为现有标题与实际请求次数后通过；生产详情面板未变。

只调整卡片操作区，不修改恢复、永久删除、敏感字段或确认流程。原始验证资料保留本地；macOS 原生实机验收仍按原约定暂缓。

## UI-03：Windows 登录卡片与 macOS 共用尺寸

源码和几何测量确认两端原本不同：常规桌面 Windows 上限 392px、解锁区域最小高度 120px，macOS 分别为 313.6px、132px；窄桌面卡片宽度分别为 360px、288px。将现有 macOS 尺寸规则同时应用到 Windows，保持 macOS 基准本身不变。桌面卡片仍按内容自然增高，保留短窗口内部滚动，不固定整张卡片高度；移动平台尺寸不变。

验证：浅深主题、1100px/500px 视口共四组两端对照，逐一切换主密码、PIN 和实际对应的 Touch ID/Windows Hello，24 个状态的宽高、留白和解锁区域基准分别一致，未出现横向溢出。相同四组对照在 Vite 生产构建上复验通过；例如常规视口主密码/PIN 为约 313.6×455px，两端生物识别均为约 313.6×457px，保留内容引起的正常高度差异。已检查生产版 Windows 窄窗口 PIN 截图及两端登录截图。

现有登录长名称、文字放大、键盘焦点和方法切换、PIN 边界、错误提示对比度、macOS 材质回退及小窗口圆角等 32 项浏览器回归全部通过；与上述四组对照合计 36 个不同浏览器场景，生产复验不重复累计。13 项现有组件测试、完整类型检查、全量 Lint（仅 syncStore 的一项既有警告）、Vite 生产构建及差异检查通过。

本项只共享登录卡片的宽度与解锁区域尺寸规则，不修改认证流程。Windows/macOS 使用同一渲染引擎的浏览器测试比较 CSS 布局契约，不冒称两种原生系统均已实机通过；macOS 原生验收仍待设备。三个请求项均已按独立提交完成，其他任务继续暂停。

## CI-01：Playwright 运行器兼容性

PR #16 首次 CI 的前端类型、Lint 和覆盖率门禁通过（272 个测试文件、2439 项测试），随后安装浏览器失败：ubuntu-latest 已选择 Ubuntu 26.04，锁定的 Playwright 1.60.0 不支持该平台。安装包的平台识别代码明确支持 Ubuntu 24.04。将 PR 前端检查、主分支同源前端检查及移动浏览器检查的运行器固定为 ubuntu-24.04；保留依赖锁、全部检查步骤和门禁，其他任务运行器不变。

本地按 YAML 解析前后对照确认，仅上述三个任务的 runs-on 改变；两条工作流及共享前端 action 的检查步骤不变，差异检查通过。该项作为 CI 环境兼容修复独立提交，推送后以新的 PR CI 全量结果作为合并条件。
