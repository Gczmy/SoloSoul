# SoloSoul 指南文档编写规范

> 版本: 1.0.0
> 适用范围: `flutter/assets/docs/guides/` 目录下的所有 Markdown 指南文档

---

## 1. 核心原则

### 1.1 零 Emoji / 特殊符号

- **禁止使用**任何 Unicode emoji（如 `🔒` `⚠️` `✅` `💡`）
- **禁止使用**非标准排版符号（如 `⋮` `↩︎` `✕` `ℹ︎` `▸` `—` 等，但破折号 `—` 在中文文本中允许使用）
- 表达情绪或类型时，使用**纯文字描述**：`**提示**` `**注意**` `**警告**`

### 1.2 结构清晰，层次分明

- 使用 `<!-- version: x.y.z -->` 顶部元数据标记文档版本
- 一级标题 `#` 仅用于文档主标题，二级标题 `##` 用于主要章节
- 避免超过三级标题（`###`），复杂内容拆分为独立文档

### 1.3 语言规范

- **中文文档**: 使用简体中文，技术术语保留英文（如 Vault、Sync、AI Assistant）
- **英文文档**: 使用美式拼写，避免俚语
- **按钮/菜单项**: 用反引号 `` ` `` 包裹（如 `` `设置 → 安全` ``）
- **操作步骤**: 用数字列表 `1. 2. 3.` 表示

---

## 2. Callout 规范

Callout 统一使用 Markdown **引用块** `>` 实现，渲染层通过 `MarkdownStyleSheet` 将其样式化为浅蓝背景 + 左侧蓝色竖线。

### 2.1 三种类型

| 类型 | 前缀写法 | 用途 |
|------|---------|------|
| 提示 Tip | `> **提示**: ...` | 补充建议、最佳实践、可选操作 |
| 注意 Note | `> **注意**: ...` | 重要补充信息、默认行为说明 |
| 警告 Warning | `> **警告**: ...` | 不可逆操作、数据丢失风险、安全警告 |

### 2.2 格式示例

```markdown
> **提示**: 你可以为每个对象设置不同的敏感度级别。

> **注意**: 默认情况下，新对象的敏感度为 **内部**。

> **警告**: 永久删除后，数据无法恢复。
```

### 2.3 规则

- Callout 独占一行，前后各留一个空行
- 禁止嵌套引用块（`> >`）
- 禁止在 Callout 内使用 emoji

## 3. 可视化增强元素

### 3.1 表格（首选）

用于对比、枚举选项、展示映射关系。

```markdown
| 敏感度 | 显示方式 | 使用场景 |
|--------|---------|---------|
| 公开 | 明文显示 | 姓名、公司 |
| 内部 | 轻微模糊 | 电话号码 |
| 关键 | 完全隐藏 | 私钥、密码 |
```

**表格规则**:
- 表头明确，使用 `|` 分隔
- 至少 2 列，不超过 5 列
- 避免在单元格内使用复杂 Markdown（如嵌套列表）

### 3.2 分隔线

用于章节之间的视觉分隔：

```markdown
---
```

**规则**:
- 仅在二级标题章节之间使用
- 文档开头（标题下方）和结尾不加

### 3.3 步骤列表

用于操作流程：

```markdown
1. 打开 **设置 → 安全 → 敏感度偏好**。
2. 选择默认敏感度级别。
3. 点击 **保存**。
```

**规则**:
- 步骤描述简洁，每步一行
- 涉及按钮/路径时用反引号包裹
- 步骤不超过 7 步，超过则拆分为子章节

### 3.4 有序与无序列表

- 步骤用 **有序列表** `1. 2. 3.`
- 并列信息用 **无序列表** `- ` 或 `* `

## 4. 中英双语一致性

### 4.1 同步维护

- 每篇英文指南必须对应一篇中文指南（`_zh.md` 后缀）
- 内容结构、章节顺序、表格行列必须**完全一致**
- 版本号（`<!-- version -->`）必须**相同**

### 4.2 术语对照表

| 英文 | 中文 |
|------|------|
| Vault | 保险库 |
| Object | 对象 |
| Profile | 档案 |
| Sensitivity | 敏感度 |
| AI Assistant | AI 助手 |
| Trash | 回收站 |
| Sync & Backup | 同步与备份 |
| End-to-end encrypted | 端到端加密 |

## 5. 文件命名与目录结构

```
flutter/assets/docs/guides/
├── index.json          # 索引文件，自动读取
├── ai_chat.md          # AI 助手指南（英文）
├── ai_chat_zh.md       # AI 助手指南（中文）
├── trash.md            # 回收站指南（英文）
├── trash_zh.md         # 回收站指南（中文）
├── objects.md          # 对象管理指南（英文）
├── objects_zh.md       # 对象管理指南（中文）
├── security.md         # 安全设置指南（英文）
├── security_zh.md      # 安全设置指南（中文）
├── sync.md             # 同步与备份指南（英文）
└── sync_zh.md          # 同步与备份指南（中文）
```

**规则**:
- 文件名使用蛇形命名法（`snake_case`）
- 英文文档无后缀，中文文档加 `_zh`
- 新增指南时同步更新 `index.json`

---

## 6. 内容禁区

| 禁止项 | 原因 |
|--------|------|
| HTML 标签 | Markdown 渲染器可能不支持 |
| Emoji / 特殊符号 | 跨平台显示不一致，影响专业感 |
| 截图/图片 | 维护成本高，随 UI 迭代失效 |
| 过长段落（超过 4 行） | 影响可读性，拆分为要点列表 |
| 版本号变更日志 | 保留在 `CHANGELOG.md`，不在指南中 |

---

## 7. 新增指南流程

1. 在 `index.json` 中添加中英文条目
2. 同时创建中英文 Markdown 文件
3. 对照本规范自检（emoji、特殊符号、Callout 格式、表格）
4. 运行 `flutter analyze` 确保无问题
5. 提交 PR
