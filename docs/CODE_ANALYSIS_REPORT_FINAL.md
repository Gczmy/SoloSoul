## 复审范围与遗留

对 `tauri/src`、`tauri/src-tauri/src`、`tauri/crates`、`solosoul_cli/src` 做静态/启发式扫描，重点阅读旧未关闭项及其调用链，检查事件生命周期、锁与事务、附件路径和权限、Recovery、WebDAV、敏感字段展示及系统文件对话框。跳过依赖与生成目录。本轮不是对每个源文件逐行审计，也未完成原生 GUI、移动端及跨平台端到端验证。

- **P012（P2，沿用延期决定）**：Recovery 手动路径仍允许不提供主机指纹，且兼容裸 PIN。可信预期指纹缺失时，PIN/nonce/限流不能防御主动中间人。旧报告将强制指纹核验列为交互变更，本轮未收到改变该决定的答复，未标为修复。
- **GUI 验证阻断**：需定位测试程序缺失的 DLL 入口，再补跑完整 `cargo test` / `npm run check-all`。已确认直接运行也失败；未通过猜测修改加密、OCR、运行库依赖或系统配置。
