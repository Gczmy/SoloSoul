# PIN 解锁安全规范（PIN Security Spec）

> 最后更新：2026-08-16
> 关联修复：P022（PIN 凭证离线爆破强度——设计权衡登记 + 最小位数加固）

## 1. 设计目标

PIN 提供**便捷解锁**：用户输入 4-8 位数字即可解锁 Vault，无需重复输入主密码。本规范登记 PIN 的强度模型、威胁模型与设计权衡，明示「启用 PIN ≈ 静态安全降级到 PIN 强度」。

## 2. 实现形态

| 项 | 说明 |
|----|------|
| 凭证存储 | `{vault}/{account_id}/pin_credential`（0600），内含随机盐 + 会话密钥密文 |
| 密钥派生 | Argon2id **强制生产级参数**（`pin_kdf_config()`，64 MiB / 3 iter，~1s/次），**不随 `SOLOSOUL_SECURE` 降级**（P005） |
| 加密 | AES-256-GCM，KEK = KDF(PIN, salt)，密文为 32 字节会话密钥副本 |
| 位数 | 6~8 位纯数字（P022 加固：最小 4→6；前端 `PinSection.PIN_LENGTH` 固定 6 位） |
| 在线锁定 | 连续 5 次错误 → 锁定 30s；10 次 → 5 分钟；之后每次 +5 分钟；强因子（主密码/生物识别）解锁成功可 `reset_attempts` |

## 3. 强度模型（P022 登记）

### 3.1 离线爆破分析

`pin_credential` 连同 salt 落在数据目录，攻击者拿到数据目录副本后可离线穷举：

| PIN 位数 | 空间 | 生产 KDF（~1s/次，单线程）最坏耗时 |
|----------|------|--------------------------------------|
| 4（已禁止） | 10^4 | ~2.8 小时 |
| 5（已禁止） | 10^5 | ~1.2 天 |
| 6 | 10^6 | ~11.6 天 |
| 8 | 10^8 | ~3.2 年 |

**锁定计数对离线攻击无效**——锁定状态与失败计数存于 `config.json`（明文 JSON，攻击者可删除/重置），且离线爆破绕过在线锁定逻辑。

### 3.2 已防御

- 生产级 KDF 将每次派生成本抬到 ~1s，6 位空间约 11.6 天/单线程，多线程/GPU 加速可显著缩短（Argon2id 内存硬约束部分缓解）。
- PIN **不参与主密钥派生**：PIN 仅解密已保存的会话密钥副本，泄露 PIN 凭证≠泄露主密码/主密钥。
- 凭证文件 0600 + vault 目录 0700；修改主密码后 `clear_credential` 强制用户重设 PIN（KEK 依赖旧 PIN 输入）。
- 在线锁定 + `PIN_OP_LOCK` 进程级互斥防并发绕过失败计数。

### 3.3 残余风险与明示

- **启用 PIN ≈ 静态安全降级到 PIN 强度**：主密码（Argon2id 生产参数 + 用户可选高熵）强度远高于 6 位数字 PIN。PIN 是便捷因子，用于低风险高频解锁（如快速查看），不应视为与主密码等效的信任边界。
- 离线爆破窗口（6 位 ~11.6 天）对**持有数据目录副本**的攻击者有效；锁定计数只防护在线交互攻击。

### 3.4 设计权衡

- 最小 6 位（10^6 空间）在「可用性（移动端快速输入）」与「离线爆破成本」间取平衡；若进一步提高最小位数（如 8 位）将显著恶化移动端解锁体验。
- 移动端硬件绑定（复用 `keystore_plugin` 将 PIN 凭证存入系统 Keystore/Keychain 受 TEE 保护）可消除「明文凭证文件可离线爆破」问题，但依赖平台能力且迁移成本高——登记 backlog 未排期。

## 4. 中期强化路线（backlog，未排期）

- **失败 N 次作废凭证文件**：解锁失败达到阈值（如 10 次）直接删除 `pin_credential`，用户须重设——将「无限离线尝试」收敛为「有限凭证生命周期」（对删除计数攻击仍无效，但消除无限窗口）。
- **移动端硬件绑定**：PIN 凭证迁入系统 Keystore/Keychain（经 `keystore_plugin`），TEE 内校验失败计数，离线攻击面归零。

## 5. 测试与验证

- `test_validate_pin_min_length_six`：4/5 位拒绝，6/8 位通过（P022）。
- `test_validate_pin_too_short` / `too_long` / `non_digit` / `ok`：边界全覆盖。
- `test_pin_setup_and_unlock` / `wrong_pin_increments_attempts` / `lockout` / `disable` / `not_configured` / `compute_lockout_seconds`：功能与锁定逻辑回归。
