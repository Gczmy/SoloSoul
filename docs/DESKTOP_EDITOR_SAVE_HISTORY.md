## 边界

- 保存失败保留草稿；切换对象、账户或锁库后拒绝迟到响应。
- 比较使用表单的相同表示，避免未改动的数值/布尔字段仅因转成输入字符串而触发保存；动态组顺序变化仍作为修改。
- 普通保存继续沿用后端的锁定保护、元数据保留与快照创建流程。
- 原生实机效果待下次授权构建时验收，不将浏览器夹具验证描述为原生验收。

## 历史刷新验证（2026-10-23）

- 保存成功才递增当前编辑会话的历史刷新代次；无修改、保存失败、仅锁定/解锁不触发历史读取。有修改的“先保存再锁定”更新历史，迟到保存不更新其他对象或新会话。
- 历史按时间倒序更新。保留时间轴节点、独立滚动位置、已展开记录及其解密缓存；新记录把展开项挤出原分页范围时，仍保留该项。读取失败保留原记录并提供重试，不把成功保存误报为失败。
- 附件页保持当前标签和预览，切回历史时读取最新列表；面板关闭时不强制打开，下次打开读取最新记录。刷新代次变化后隐藏过期的非活动历史计数。
