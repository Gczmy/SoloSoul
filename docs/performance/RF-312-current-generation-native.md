本轮使用通过完整生成验收的新默认 Release APK，在全新 API31 x86_64 独立模拟器完成100／5000对象各十二步界面行程。原生队列、原始控制帧、两档行程后内存、应用与系统恢复及宿主清理均通过。本轮仅为五次固定尝试中的第1次，不代表性能分布或完整RF-312验收。

## 输入与原生证据

使用原2核／2048MiB、SwiftShader、WebView91.0.4472.114配置。Launcher两份截图实际查看，完整38项新启动DropBox无ANR，四份目标／观察器包均未预装；随后才验证MainActivity实际资源并开始公开夹具。新包首页的实际Android布局已查看，截图来自当前默认包，不是浏览器或静态夹具。

两档分别验证启动、密码解锁、首次OCR用户流程、工作区、搜索、附件、图片、文本、两种原生PDF、应用锁定和再次解锁。每档三页PDF由原生图像／正文及物理数字核验，原身份／命中／像素／恢复和45／240秒、512请求限制保持。

每档142项原私有条目及原APK／UID／debug属性恢复一致；完整九项系统设置一致，观察器与临时输入正常移除。终态100项DropBox无ANR，原专用进程／监听清理及保护端点核验通过。原始控制协议回放5911帧，43份原生PNG与回执逐字节绑定；协议帧数不作为应用IPC次数。
