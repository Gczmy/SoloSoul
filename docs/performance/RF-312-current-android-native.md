# RF-312 当前 Android 原生重复行程（2026-10-15）

当前源码的非 debuggable Release 验证 APK 已完成 100/5,000 对象交替五轮，共 10 次行程、120 个阶段，全部通过；每轮原 APK、216 项私有目录记录及被修改设置均恢复。完整样本见[数值记录](rf312-current-android-native-2026-10-15.json)。这仍是带目标进程插桩和早期 IPC observer 的诊断基线，RF-312 保持待验证。

## 环境与口径

- 运行源码为公开提交 `ad93ff0d4d115229aabffae1faaf2de2be520ea7` 的 `tauri/` 内容；当前工作区的后续提交只改文档。1,988 份运行输入及前端资源、APK 全程冻结核验。
- 默认 `custom-protocol` 加非默认 `android-native-perf`，Rust 1.96.0、优化 Release；APK 为 x86_64、非 debuggable、minSdk 28/targetSdk 36，只用内部测试证书。生成 Debug JNI 和原 APK 保持；代码/资源签名前后相同。
- 专用 Android Emulator API 31、软件 SwiftShader GPU，配置 2 个虚拟 CPU、2,048 MiB；WebView 为 `com.android.webview 91.0.4472.114`。主机是 Windows 11 LTSC build 26100、i7-9700/8 核、约 15.8 GiB。没有并发编译，普通后台活动未完全隔离。
- 使用既有固定公开媒体 Vault：100/5,000 对象、公开图片/文本/两类 PDF 和 OCR 图片。原生测试检查预期对象、搜索结果与实际公开输入；每轮依次准备、运行、恢复，再开始下一轮。
- 启动从 Activity launch 到生产密码表单、目标 WebView 焦点及两次提交帧；不包含 runner/进程启动。其他时延包含原生触控就绪、固定等待和诊断开销，首次 OCR 包含选择文件及可见结果的完整行程。它们不是纯后端耗时或默认 APK 的用户响应时间。
- IPC 为每个测量区间内的实际 Tauri 发送尝试差值，不等于成功请求数、某条特定命令调用数或全行程总数。阶段间的操作不分摊到表内。
- 每档 n=5，中位数取中间值，p95 最近秩等于最大样本；不作系统冷启动、真机 GPU 或其他平台的推断。

复跑所依赖的生产代码/固定公开数据约定见[媒体数据契约](RF-312-media-fixture-contract.md)、[早期 IPC 观测](RF-312-android-early-ipc-observer.md)、[既有重复行程](RF-312-android-repeated-merged-journey.md)和[进程内存采集](RF-312-android-process-memory.md)。本轮沿用同一严格测试方法和恢复规则，使用本次重新编译、打包的当前 APK；首个原生失败或恢复无法证实会停止，未放宽预算、删除断言或增加自动重试。

## 内存与视觉补证

采集使用 `dumpsys meminfo --local`，同时校验应用 UID/PID/出生时间和 WebView service/client 归属；每组串行查询后间隔 5 秒。175 次尝试中，84 次进程归属成立，其中 80 次采集时间段完全落在该次原生行程内。其他尝试的原始记录保留，不计入行程 PSS。

每行程“最大观测 PSS”再按五轮统计：100 对象中位约 275.4 MiB、最大约 283.2 MiB；5,000 对象中位约 298.3 MiB、最大约 312.9 MiB。它包含目标测试进程开销；查询会扰动被测环境，间隔采样也可能遗漏短峰值，因此不称为精确峰值或无插桩内存。数值记录保留每次有效快照、进程角色汇总、查询成本及缺席/拒绝计数，不发布进程或运行标识。

本轮另复核 100 对象第一轮的两张实际原生截图：[文本 PDF 第二页](rf312-current-android-native-2026-10-15/text-page-two.png)显示公开第二页文字，[扫描页](rf312-current-android-native-2026-10-15/scanned-page.png)显示公开 OCR 测试图。这是单组图像复核，未将原程序的 `pdfRenderingProven=false` 改写为十组自动渲染验收。

## 收尾与下一步

每轮独立对照 216 项原私有记录的内容、链接和权限，并确认 APK 字节/UID/debug 标志、模糊设置及公开输入清理。仅在恢复对照通过后删除该轮本地私有备份，源码和 APK 冻结检查均通过。

队列退出 0 后，首次模拟器收尾确认在 20 秒截止时仍未完成；后续只读核验确认自然退出，无追加关闭或强杀命令。默认入口准备先因收尾回执未就绪被拒，随后因临时生成器字串计数假设错误中止；均未启动默认构建，原件保留后修正。上述工具收尾/准备错误不改写为首轮成功，也不改变此前 120 个原生阶段的结果。

当前另行构建不含 `android-native-perf` 的默认 Release，并准备进程外启动/登录表单控制观测。此控制的 ActivityManager 时间和辅助功能观测上界会分开记录，不与上述两帧口径直接相减。现有数据不足以决定全路由懒加载或分页改造；默认构建、真机、多端及完整 RF-121 仍有未验范围。
