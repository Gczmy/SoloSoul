# RF-312：Android文本预览可见性

本轮确认同一产品APK可显示固定公开文本，没有修改产品样式，也不宣称已定位历史空白截图的唯一原因。RF-312仍待首OCR、搜索与所有媒体合并后的重复完整测量、renderer/全进程内存、进程冷启动、物理设备及其他平台。

旧探针在DOM精确文本出现后立即PixelCopy，绘制等待位于关闭预览后的阶段收尾，因此DOM存在不能证明该张截图已经包含文字。新诊断在截图前使用实际`WebView.postVisualStateCallback`及两帧原生绘制，保持原45秒预算；记录公开文本精确匹配、字号/颜色/可见状态、DOM矩形与原生窗口坐标，并检查对应窗口区域的前景像素。

第一轮100对象对照在立即截图前增加样式和坐标查询，前后均有3547个前景像素；不能将它当作证明绘制等待修复原故障的红绿对照。第二探针保留旧立即捕获点，样式/坐标读取与像素分析放在已保存截图之后；100/5000各一次完整10阶段诊断实际退出0，两张立即与提交后截图均可见、各3547个前景像素。提交后窗口截图人工复核可见全部公开正文和数字，关闭/返回/锁定恢复通过。

历史RF-1135的100截图及RF-1136的100截图曾呈空白，RF-1136的5000截图实际上已有文字。独立像素检查借用了相同视口的新矩形，因为旧探针没有记录自身pre矩形；该区域比较只作辅助，不作为历史根因证据。原件不改，不将空白截图丢弃，也不把本轮立即截图可见当作所有立即截图都可靠。

产品APK、媒体集、生产代码与依赖均未改；只构建独立探针。两轮实际编译、内部测试签名和输入字节验证通过。三轮原生运行结束后原包/UID/完整私有数据/blur恢复，独立探针删除，三对216条目恢复TAR内容/链接/权限独立一致。程序、数据库和私有备份不入库。

[结构化结果](rf312-android-text-visual-2026-10-12.json)和[127成员原件索引](rf312-android-text-visual-2026-10-12/index.json)保留实际源码、命令/退出码、前后图像与完整元数据；原件逐成员长度/SHA核对通过。当前是功能与观测检查点验证，非重复性能基线，没有增加关闭任务数，也没有关闭RF-312或自动推送。
