## 单项修正与回放

新增十项回归，导航相关共十八项、宿主完整套件共 170 项通过。实际完整调用方仅 OCR／Search 两处接入，Journey 类全部方法的 AST 保持，原导航边界函数、精确命中、内容读取、恢复和期限门禁保持。留存原生层级回放中，原被导航覆盖的卡片得到零候选；用同一拒绝诊断记录的当前几何回放得到一个候选。两者都是只读复现，不代替原生运行。

## 本轮连接失败的直接证据

本轮第 65 次 ADB 调用检查观察器 error 文件时，在原 42.72 秒剩余预算内等待约 21.11 秒，返回 10060。原读取器没有把非空传输错误当作文件不存在，也没有重试该操作。三次观察器请求后即退出，尚未完成启动步骤，5000 对象未启动。

十份被动采集都显示守护进程仍拥有监听；其中连续四份快照的同一个失败客户端、同一连接端点保持 `SYN_SENT`，跨度约 15.43 秒，并与失败命令逐项核对。这确认连接在本机 TCP 握手阶段未建立，尚不能确定具体 Windows 驱动、过滤或 SDK 原因。没有修改网络设置或重启受保护服务。

原观察器正常停止回执通过；153 项完整私有记录、原安装包／UID／debug 属性和九项设置恢复，完整 DropBox 59 项无 ANR，自有进程与监听为零。原严格终态审计通过的是失败样本及恢复有效性，明确整档行程仍失败；工具卡片和 PDF 补充读取的原生验收仍未触达。
