## 证据和复跑

五轮保留全部终态、29402份原始控制协议帧及218份原生PNG绑定，30页PDF物理内容核验；控制协议帧数不是应用IPC次数。每档以自己的原始私有状态验证恢复，不能要求五轮原条目数量相同。所有原始路径、PID、日志、截图、程序、签名材料和私有备份留本机，公开文件仅保留通用环境、数值和哈希。

完整生成及原生入口位于[观察器目录](rf312-default-observer/README.md)和[可移植外层入口](RF-312-portable-owner.md)。每轮依次使用`runtime_inputs.py`、`prepare_avd.py`、`owner_inputs.py`准备新输出，再运行`runtime_owner.py`；用`runtime_preflight.py collect/review`绑定实际检查的两张当前图片。每轮必须使用新AVD和新输出，等待完整恢复与原终态／帧／内存审计后再开始下一轮。原阶段45秒、界面240秒、512请求等限制保持；失败保留，不重跑替换失败，来源或协议变化另立系列。

公开输入是这些严格原生回执的去标识投影，离线归约不替代原生审计。复算命令在仓库根目录执行，输出必须不存在：

```text
python -B docs/performance/rf312_repeat_summary.py --input docs/performance/rf312-default-fixed-five-2026-10-17.input.json --output <新summary.json>
python -B -m unittest discover -s docs/performance -p test_rf312_repeat_summary.py -v
```

统计工具拒绝缺失／重复尝试、混合来源、阶段缺口、无效数值、超预算字段及丢失的失败证据；失败或未完整验收的尝试不进入成功分布，原始结果仍保留。命令行回归先真实复现Windows换行问题，再固定LF，并验证原始输入哈希及拒绝覆盖；发布文件与Git索引字节在提交前另行核对。
