RF-1097 仍未验收。旧版 `legacy5000/sample-001` 第二次登录的账户清单权限阶段为 `interrupted`，实际持续 4054.01ms；时间顺序与父子包含关系正确。已有登录调用会忽略账户清单保存错误，因此登录完成不能证明权限命令成功。旧失败组及其全部三个样本保留。

应用启动器按既有隐私约定忽略标准输出，应用日志没有该错误，限定时间段的 Application Error/Windows Error Reporting 查询无记录。这些结果无法还原历史退出码，也不能证明命令没有失败。当前用户的 WMI 进程事件订阅返回 `0x80041003`；未请求管理员权限或更改系统设置。
