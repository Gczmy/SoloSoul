# RF-312：Android 完整行程重复诊断

本轮使用同一主 APK、同一独立手指事件测试 APK、固定夹具与软件模拟器，交替执行 100/5000 对象各 5 次完整 12 阶段行程。10 次原生与外层验收均实际退出 0，失败 0，没有替换或丢弃请求样本。RF-312 尚未完成；当前是包含仪器开销的重复诊断，不能替代全进程内存、操作系统冷启动、物理设备和其他平台。

阶段包括 Activity 启动、两次主密码解锁、真实手指选择器首 OCR、工作区、`needle` 搜索、附件列表、图片/文本/文本 PDF/扫描 PDF、两页切换、关闭返回及锁定恢复。每次使用真实 `TOOL_TYPE_FINGER` DOWN/UP，原窗口/输入/绘制预算及全部严格断言不变。主 APK SHA-256 为 `098c26120fc4ab6954efb10116d62c294f1f4afa5478a4a5cff35adc24ba7f6f`；API31 x86_64、SwiftShader、2048 MiB/2 核、私有 ADB5049及生产 KDF65536 KiB/3/4与[手指验证记录](RF-312-android-native-finger.md)相同，产品源码和依赖没有改动。

最近秩 p95 为排序后 `ceil(0.95*n)-1` 的零起始索引；每组 5 个成功样本时等于最大值，是本组样本尾部，不是稳定总体尾延迟。中位数包括偶数样本通常定义，但本轮每组 5 次。所有阶段与原始运行顺序数值保存在结构化结果，不把两种对象规模混合为一个分布。

原生行程跨度从首阶段 native started 到末阶段 finished，包含阶段间导航；阶段时间包含输入、稳定检查、观察、截图和绘制等待。OCR 指标包含选择器返回、IPC、解码、进程首次 ML Kit 初始化和轮询，不能当作纯引擎时间。Activity 启动排除 runner/进程创建，未清除 OS 页面/模型缓存，不能称为操作系统冷启动。搜索使用生产 50 条显示上限，小夹具显示 5，大夹具实际匹配 250但显示 50。ML Kit 的 100% 仍是置信度占位，本轮不据此判断准确率。

PSS 为主进程串行采样，包含 runner、不含 renderer；单轮最大采样值不是连续峰值。读取自身 MemoryInfo 的记录只反映该采样调用开销，不构成整个仪器/截图/轮询开销的完整归因，也不能称为产品本身内存。下一步必须确认 renderer 归属与全进程范围，再决定是否需要内存优化。

实际 IPC 分类显示 listen/unlisten占主要发送，集中于工作区、打开附件与锁定阶段；例如首对样本各有435次listen、425次unlisten。来源仍需按事件和页面/字段订阅所有者归因，当前不能将发送量直接判为监听泄漏或以此改全路由懒加载。两规模同口径行程/搜索差异与生产显示上限也不足以支持立即重写分页；先完成归因，不制造缺乏证据的优化提交。

每次源码/APK和原包/UID/完整私有数据/blur/唯一公开图片与 MediaStore 索引均严格检查；恢复未证实会停止后续样本。10 对私有恢复各216条目内容/链接/权限独立一致，20个私有TAR已删除。APK、密钥、数据库和私有备份不入库。
