## 结论与后续口径

完整行程配对差值中位为100对象+1091.55ms（配对百分比中位+2.01%）、5000对象+1638.54ms（+2.92%）。每档都有一对负差值；区间分别-949.15～+2821.45ms、-390.63～+3084.38ms。此组不能证明零采集扰动，也不能把全部波动唯一归因于查询函数。当前时延继续注明含采集成本；后续分析UI时延优先采用无外层查询的相同SDK口径，内存另按采样组呈现，保留全部配对原件。

167次外层尝试中85次身份/数值接受，83份在对应真实行程内；79次应用未运行，以及绑定集合变化、一次10秒读取超时、一次命令拒绝均保留并拒绝，不记零值。超时发生在采集器写入完成命令表之前，离线回放最初因此失败；随后仅按原完整超时错误证明严格解析器的下一条请求及10秒预算一致，再复现拒绝。没有补造超时命令输出或内存值，原未处理回放源码也已归档。
