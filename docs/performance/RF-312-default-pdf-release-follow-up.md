## 实际验收与拒绝原因

141 项定向宿主测试通过。默认运行不注入目标 instrumentation 或 JavaScript，实际依次通过启动、主密码解锁、首次 OCR、工作区、搜索、附件、图片预览、文本预览及原生文本 PDF。页码必须具有实际可见几何，且同一截图内 OCR 的精确数字中心位于其控件范围；两页正文也分别核验。图片、文本与文本 PDF 的关闭均限定当前文件并验证附件列表稳定恢复。

扫描 PDF 实际截图已显示公开内容，但宿主 OCR 将连续数字读成 `1 234567890`，原严格检查要求精确 `1234567890`，因此未接受该阶段。随后最后一次 OCR 子进程在原阶段仅剩约 0.151 秒时超时。原 45 秒阶段期限、读取器与输入门禁保持；没有连接数字片段、替换字符、忽略页码或扩大期限。当前证据不能证明产品渲染失败或产品操作耗时超标，下一项应先调查物理 OCR 识别差异。
