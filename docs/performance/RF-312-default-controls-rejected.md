# RF-312 默认 Android APK 控制队列未验收记录

2026-10-15：默认优化 Release APK 的进程外控制观测尚未形成完整基线。三组队列均在首个失败后停止；各组成功子集保持独立，性能分布为空，RF-312 继续待验证。

## 构建与测量边界

- Rust 运行源码基于 `ad93ff0d4d115229aabffae1faaf2de2be520ea7`，前端包含 RF-1161 的原生密码语义修复 `685275862b9592cc6a30ed20603767e26a15b7c2`。默认优化 Release、无额外 feature、非 debuggable；相对 frontendDist 的构建已核对实际嵌入 28 个脚本。
- 独立 API31/x86_64 模拟器，2 个虚拟 CPU、2,048 MiB、SwiftShader，WebView 91.0.4472.114。独立 UiAutomation 观察器先连接，再启动目标 Activity；没有目标进程插桩、JavaScript 注入、密码输入或认证。
- 每组计划 100/5,000 对象交替五轮。原 45 秒表单预算、原生密码标记、公开账户及名称、前台焦点与恢复要求保持；不在失败行程中重试或放宽断言。
- ActivityManager 冷启动回执不等于密码表单可用时间。表单上界包含 ADB、辅助功能轮询和焦点查询；未证明两次提交帧。串行 PSS 仅计应用 UID 及归属成立的隔离渲染器，排除共享 WebView 服务、zygote、系统进程及外部观察器 UID，不能视为原子快照或连续峰值。

## 恢复与独立复核

前 11 次各自独立核对了 216 项原私有内容、链接和权限。最后一次保留原失败回执及备份，先重新确认原 APK 字节、UID、debug 标志和应用私有目录边界，再恢复；26 条恢复命令均退出 0，规范恢复及独立清单比较均确认 216 项一致。两份自有远端暂存及本地私有备份只在核验通过后删除。

12 次尝试的原 APK、修改的设置、观察器卸载及公开 OCR 输入清理均已核对；共 24 份本地私有备份在独立核验后清理。最后一次原失败报告的 SHA 保持，恢复成功另记，不覆盖旧结果。对 10 份实际成功发布的原生观测，另从原始框架回执、控件树和 PSS/UID/进程出生信息重新核对，但不据此发布跨队列统计。
