# RF-1097 Windows 私有权限命令无窗口启动验收

Windows GUI 登录和再次解锁会写入账户清单。前一阶段观察到目录和文件权限调用占账户写入耗时的99.74%～99.83%；本项给两处 `icacls` 添加 `CREATE_NO_WINDOW`。用户名校验、命令参数、标准流继承、退出状态与错误传播保持，Unix、前端和依赖未改。

原第一轮5000对象基线组的文件权限阶段失败，历史未记录退出类别，原因仍未知；该失败及限定诊断完整保留，不计作通过。本轮仅在非默认测试功能中增加固定安全类别和数字状态观测，两版Release使用同一设施。原认证契约、SDK/身份/时限门禁保持。每个完整样本要求两次认证的四次权限命令均实际成功。

100对象按旧→新、5000对象按新→旧，各版本各三次完整六阶段行程，共12个独立root/profile、48次实际权限命令，全部exit 0。辅助结果与同进程同认证阶段绑定，不跨失败组拼接样本。

## 权限、检查与保全

12个GUI样本的Vault目录、账户清单和配置文件共36份完整owner/group/DACL按角色一致。目录及清单保持受保护的当前用户显式FullControl，配置保持原继承；SID/SDDL不入报告。此结论限定隔离样本，不证明清除了所有既存显式ACL。默认生产函数七种真实前后行为、四份完整ACL也已分别通过。
