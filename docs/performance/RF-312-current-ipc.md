# RF-312 当前源码的 Android IPC 原生复验

2026-10-18，包含 RF-1187 优化模式入口保护的当前 104 份来源，通过全新同源诊断库、诊断 APK、独立采集器和全新 AVD 的完整 100→5000 十二阶段验收。独立回放通过；旧默认读取器及六对默认采样分布保持。

## 生成与来源

按 [IPC 运行入口](rf312-ipc-runtime/README.md)执行现有三个公开生产者。全新目标目录的实际 Release 编译仅增加已有 `android-native-perf` 功能；2006 项完整来源、1955 份工作区复制、38 份前端及 13 份官方重生成内容复核通过。产品代码仍与已验收构建来源相同。

诊断 APK 只有核心库改变，其余 740 项负载逐字节一致；采集器只有四项负载，两者使用既有内部测试证书。实际签名、对齐、工具身份及来源审计通过。原默认读取器仍拒绝诊断库／目标插桩，原默认 APK、库和严格读取规则保持。

110 项运行回归、49 项生产者回归与四项 JavaScript 查询回归对应本轮相同源码字节，零重复 Python ID、零跳过；编译及原生前后来源复核保持。启动包装器曾因文件执行方式缺少模块目录而在导入前失败，未启动 SDK 或行程；保留记录后使用文档中的直接 CLI，未改产品或验证源码。

API31／x86_64、2 CPU／2048 MiB／SwiftShader。实际查看完整 Launcher PNG 的三张无缩放分片，并核对全部 38 项健康记录后，在原十分钟窗口内准入。原 240 秒观察器、45 秒阶段、512 请求、3 秒元数据、5 秒状态及恢复／退出期限保持。驱动准备和恢复时间不属于观察器窗口，也不作为产品时延。

两档各恢复 102 项原私有内容／链接／权限、APK／UID 与系统设置，外层完整恢复比对及内部清理通过。自有元数据按原精确摘要清理；SDK 正常退出，原四十五秒内第 8 次严格只读宿主审计归零，随后独立回放确认零进程、零监听。本次启动无 ANR；历史 ANR 根因仍未证明。

## 保留的缺口

本轮只接受当前显式目标插桩版本的一次完整功能／IPC 验收。旧诊断运行保留其原来源和数值，六对默认样本及全部失败前缀逐字节保持；不合并或改标为本轮样本。

默认性能分布之外的应用本体时延、启动两帧呈现、完整且可归因的观察开销、全部归属进程的全程／峰值内存及多端仍待。RF-312 和其余前置未关闭，台账保持 368/377。下一步继续这些缺口，不用本次诊断计数替代它们。
