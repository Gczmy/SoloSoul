# RF-312 Android 固定数据原生行程（部分验收）

接受 API31、x86_64、优化且非调试的内部 Release 上六阶段行程；100/5000 对象各五份全新样本全部通过。真实触摸、密码录入、UI 检查、早期传输计数及完整数据恢复均执行。RF-312 全范围仍待验证。

## 测量口径

专用 AVD 使用 Swiftshader、2 核、2 GiB；不是物理 ARM 或硬件 GPU 结果。主 APK SHA 为 `2a8d110e74f18aca7079c796f787d897d0afa60cccae95049f111af72a729627`，沿用已构建的非默认 `android-native-perf` 入口，未重建或修改生产主 APK、默认功能与依赖。

计时为 Android `elapsedRealtimeNanos`，保留各阶段真实起止值；文档 IPC 时钟单独记录，不混算。启动从 Activity launch 到生产密码表单、目标 WebView 焦点和两帧绘制，不包含进程/runner 启动。阶段总耗时包括测试、轮询、绘制、触摸就绪及正常通知/键盘等待，不能当作纯业务或查询耗时。

每次触摸前要求目标唯一、可用、主文档有焦点，DOM 命中点与原生视口相符；至少三次已提交观察且位置连续稳定 350ms。坐标读取后不先写日志，每个目标仅发送一次原生触摸。密码输入、目标就绪和录入共用原 45 秒预算，不移除焦点检查、不隐藏通知、不自动补点。

固定夹具类型 `note`、分区 `identity`；与 Windows 行程相同，进入身份后再实际选择“全部”，要求首屏恰好 50 张卡片且包含 `Record 00000000`。搜索匹配总数为 5/250，生产页面上限 50，实际显示为 5/50；未伪造 250 张结果。

## 全新重复样本

交错执行两种数据量各五份完整行程；调试、诊断、失败和中断整组均未拼入统计。下表为阶段总耗时的中位数及 nearest-rank P95；每组 n=5，P95 等于最大值，不代表稳定的总体尾延迟。

## 失败、恢复与来源

保留所有原型轮次：账户选择器假设、初始空 WebView、文档/输入焦点、夹具类别以及旧整组误点/焦点失败。旧完整十份行程 5 通过、5 失败，整组拒绝；前一组 6 通过后发生预检失败，亦拒绝。两份只读布局诊断和两份改进开发样本只证明各自行为，不进入分布。

稳定坐标版曾在恢复 chmod 时失去私有 ADB 连接，整组停止；原 APK/UID 已恢复、测试包已移除。用原备份 SHA、专用模拟器精确进程和空私有根核验后，恢复原 216 个条目全部内容、链接及权限，删除自有远端备份；原失败报告保留。原 ADB 服务后来出生时间未变，不能断言进程曾崩溃。仅正常替换专用 5049 服务为持续日志的 nodaemon 进程；全局 5037 和 OS 设置未变。

新整组十份均通过自动恢复。归档独立比较 39 次实际运行的原/恢复 TAR，含上述真实失败及手动恢复；私有 TAR、程序、密钥和构建缓存不入库。源码与实际编译测试包一致；旧元数据字段 `homeTestSourceSha256` 在这些新包中指固定数据测试源码，不能据字段名称作旧首页测试执行。Android 主 APK 原来源 HEAD 及当前冻结文件分别保留，不把 Windows 后续改动冒称为新 Android 构建。
