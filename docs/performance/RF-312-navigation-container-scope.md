# RF-312：正文导航边界定位修正

2026-10-16，验收脚本改用明确的Main navigation原生容器确定正文边界，避免顶部Objects等同名标题误排除记录。131项定向测试通过，默认包实际成功进入详情、附件和图片预览，前七步通过；随后关闭预览时遇到三个Close候选，原唯一命中检查拒绝，完整队列仍失败，5000未启动。

## 定位修正及直接证据

原脚本以Home／Objects／Tools／Settings任一标签的最小y坐标作底部边界，实际误取顶部Objects标题y=115；目标记录虽唯一可见，却被body过滤成0项。

[独立定位组件](rf312-default-observer/body_navigation.py)核对唯一Main navigation容器、包归属、类型、可见／启用状态、四个唯一可点击导航项及其包含边界，得到实际导航顶部y=1569。缺失、重复、其他应用包或越界时保持未就绪，不猜坐标或回退标题。新增八项回归，连同原协议与超时记录共131项通过；实际留存层级只读复现由0项恢复到1项，不派发输入。

本轮默认包实际派发且接受一次目标记录的原生单手指点击，随后附件列表与图片物理内容核验通过。原唯一目标、焦点就绪、输入事件及期限函数逐字节保持，产品与原生观察器复用同一冻结产物，1795项原源件保持。
