# RF-312：绑定原图的 PDF 正文补充 OCR

2026-10-17，扫描 PDF 的离线诊断确认：同一原生截图在原尺寸、75% 和 67% 下均把数字拆成 `1 234567890`，50% 时可精确识别 `1234567890`，但会遗漏页码。因此补充半尺寸读取只用于原生 PDF 正文，页码及首页计数继续使用原图。原严格读取器、数字规则、原生输入和期限保持。

## 实现与独立核验

[scaled_ocr.py](rf312-default-observer/scaled_ocr.py)按实际尺寸向下取整生成固定半尺寸 Lanczos 图。补充读取只在原图正文未就绪时发生；原图读出错误完整数字或无效证据仍直接拒绝。原图、两个原始 OCR 和派生图分别保留；独立审计重新生成并逐像素验证派生关系，再只换算有限词框坐标，识别文字保持原样，未拼接、替换或推测数字。

同一留存原生截图经该映射后，由原样精确正文读取器接受；该图原始页码的实际可见几何和 `1/1` 像素文字也独立核验。缩放图本身不是新的原生截图，不作为行程通过证据。当前 Python 3.14.6、Pillow 12.2.0；调用说明和九项回归见[公开源码说明](rf312-default-observer/README.md)。

150 项定向宿主测试通过，包含原 141 项及新增九项。最初沙箱默认临时目录不可写的拒绝保留；改用专用测试盘后发现一项测试误用浮点精确比较，改为近似断言后通过。调用方 AST 对比确认另 18 个行程方法、原正文循环和全部十二步顺序保持，只给两处原生 PDF 正文增加补充读取标志；原完整错误数字异常仍拒绝。
