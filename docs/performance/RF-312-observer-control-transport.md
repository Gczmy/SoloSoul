## IPv4候选拒绝及准备失败

当前ADB 37.0.1-15733141对服务参数`-L tcp:127.0.0.1:5057`报告`listening on specified hostname currently unsupported`，无法安装监听。该新环境在原启动期限耗尽前未建立Android命令连接，没有安装观察器或产品；不把客户端连接地址与`-L`支持的监听主机名视为同一配置能力。原失败、服务日志及即时宿主拒绝均保留；终端Android ANR清单未能取得，候选不接受。

模拟器经原生控制台核对AVD后正常关闭，没有重启服务或重跑候选。SDK派生的20秒延迟清理及日志辅助进程自然退出后，同一固定身份读取器独立审计确认零自有进程／监听；不以最终宿主清理通过改判原测试。

更早一次诊断因内存预检遗漏CRLF归一化在0观察器安装时拒绝，原ADB内存值未越界；收尾捕获路径缺失的客户端仍拒绝，没有推测其身份。即时宿主拒绝保留，SDK辅助进程自然退出后的独立审计通过。修正版沿用既有驱动的文本归一化；在原启动窗口内只读等待其他ADB客户端缺席才开始观察器安装，未增加原生协议预算。
