## 8. 插件看板页面设计（PluginDashboardPage）

SoloSoul 主软件通过一个独立的看板页面管理插件的生命周期。用户可以在看板中查看所有插件的状态（已安装 / 可安装 / 有更新 / 不兼容），并执行安装、卸载、更新操作。

### 8.1 入口位置

插件看板通过**设置页面 → 插件管理**进入：

```
设置页面 (SettingsPage)
  ├── 账户设置
  ├── 访问设置
  ├── 安全设置
  ├── 同步设置
  ├── LLM 设置
  ├── 【插件管理】  ← 新增入口
  │     └── 导航至 PluginDashboardPage
  └── 应用信息
```

设置页面中的插件入口使用 `SettingsTile` 组件：
- **图标**：`Icons.extension_outlined`
- **标题**："插件管理"
- **副标题**：动态显示已安装插件数量，如 "已安装 3 个插件，1 个可更新"
- **点击行为**：`context.push(AppRoutes.pluginDashboard)`

#### Tab 定义

| Tab | 显示内容 | 数据来源 |
|-----|---------|----------|
| **全部** | 所有在 registry.json 中注册 + 本地已安装的插件 | `registry` ∪ `installed` |
| **已安装** | 当前已安装到 `~/.solosoul/plugins/` 的插件 | `installed.json` + 目录扫描 |
| **可安装** | registry 中有但本地未安装的插件 | `registry` − `installed` |

### 8.3 插件卡片组件（PluginCard）

每张插件卡片包含：

1. **图标区**：插件自定义图标或默认 `Icons.extension`
2. **名称**：`manifest.name`
3. **发布者**：`manifest.publisher`
4. **版本**：`manifest.version`
5. **插件 API 版本**：`manifest.plugin_api_version`
6. **描述**：`manifest.description`（最多两行，溢出省略）
7. **状态徽章**：
   - `已安装`（绿色）
   - `未安装`（灰色）
   - `有更新`（橙色，显示 `current → latest`）
   - `不兼容`（红色，`plugin_api_version` 或 `min/max_app_version` 不匹配）
8. **操作按钮**：根据状态动态显示（见 8.4 节）

### 8.4 操作按钮状态机

| 插件状态 | 显示按钮 | 点击行为 |
|---------|---------|----------|
| 未安装 + 兼容 | **安装** | 调用 `PluginInstallerService.installFromMarket()` |
| 未安装 + 不兼容 | **安装**（置灰）+ 兼容性提示 | 不可点击，提示升级 App 或等待插件更新 |
| 已安装 + 最新 | **运行** + **卸载** | 运行：调用 `PluginService.runPlugin()`；卸载：确认弹窗 → 清理 |
| 已安装 + 有更新 | **更新** + **卸载** | 更新：调用 `PluginInstallerService.installFromMarket()` 覆盖旧版 |
| 运行中 | **停止** + 进度指示器 | 停止：调用 `pluginForceUnload()` |

> **运行状态检测**：Rust 侧维护 `PluginSessionManager`，记录当前活跃 Session 的 `(plugin_id, session_id, started_at)`。Dart 通过 `rustApi.pluginListActiveSessions()` 获取运行中插件列表，用于显示"运行中"状态徽章和"停止"按钮。

### 8.5 安装交互流程

```
用户点击【安装】
       │
       ▼
  ┌──────────────┐
  │ 版本兼容性检查 │
  │ plugin_api_version == PLUGIN_API_VERSION ?
  │ min_app_version <= AppVersion <= max_app_version ?
  └──────┬───────┘
         │
    否 ◄─┘ 是
    │
    ▼
 显示不兼容提示
 （引导用户升级 App 或联系开发者）

是 ──▶ 显示安装进度弹窗（模态底部 Sheet）
       │
       ▼
  ┌──────────────┐
  │ 下载 wasm    │  ← 从 registry.versions[version].download_url
  │ 下载 manifest │
  └──────┬───────┘
         │
         ▼
  ┌──────────────┐
  │ SHA-256 校验  │  ← 与 registry.versions[version].sha256 比对
  └──────┬───────┘
         │
    否 ◄─┘ 是
    │
    ▼
 显示"校验失败，可能存在安全风险"
 终止安装，记录审计日志

是 ──▶ 解压到 ~/.solosoul/plugins/{plugin_id}/
       │
       ▼
  更新 installed.json
       │
       ▼
  显示"安装成功"SnackBar
  刷新看板列表，切换 Tab 至"已安装"
```

### 8.6 卸载交互流程

```
用户点击【卸载】
       │
       ▼
  显示确认弹窗（AlertDialog）：
  "确定卸载插件 'SlotGo'？
   此操作将删除插件文件并撤销所有数据授权，
   但审计日志将保留。"
       │
       ▼
  用户点击【确认卸载】
       │
       ▼
  ┌──────────────┐
  │ 撤销 Session  │  ← Rust 侧 pluginForceUnload(plugin_id)
  │ 清理内存      │  ← Store drop，Wasm 内存清零
  └──────┬───────┘
         │
         ▼
  删除 ~/.solosoul/plugins/{plugin_id}/ 目录
         │
         ▼
  更新 installed.json（标记为 uninstalled）
         │
         ▼
  显示"已卸载"SnackBar
  刷新看板列表
```

### 8.7 搜索与筛选

看板顶部提供搜索栏：
- **按名称搜索**：实时过滤 `manifest.name`，支持模糊匹配
- **按发布者筛选**：下拉选择 "全部发布者" / "SoloSoul Team" / "第三方"
- **按字段权限筛选**：如 "需要护照信息"、"需要身份证"，帮助用户了解插件的数据需求
- **按兼容性筛选**：快速找出"不兼容"或"有更新"的插件

### 8.8 离线/空状态

当用户首次使用或处于离线环境时，看板需显示空状态：

| 场景 | 状态 | UI 表现 |
|------|------|---------|
| 首次使用，无缓存，无已安装 | 全新空状态 | 显示引导插画 + "暂无可用插件，连接网络后自动同步" |
| 离线，有已安装 | 离线可用 | 显示已安装插件列表 + 顶部"离线中，无法获取新插件"横幅 |
| 离线，无已安装 | 完全空状态 | 同全新空状态，但横幅提示"当前离线" |
| 在线，registry 为空 | 市场暂无插件 | "插件市场暂无内容，请稍后重试" |

### 8.9 插件详情页（可选扩展）

点击插件卡片可进入详情页 `PluginDetailPage`，展示：
- 完整描述与使用说明
- 请求字段清单（带敏感度标识：公开/内部/敏感/关键）
- 网络白名单域名列表
- 版本历史（从 registry.json 读取所有可用版本）
- 审计日志入口（该插件的数据访问记录）
- 开发者主页链接
