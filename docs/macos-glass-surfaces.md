# macOS 材质与内容表面

实现入口：`tauri/src/styles/macos-glass.css` 与 `tauri/src/styles/desktop-controls.css`，由 `bootstrapApp.tsx` 加载。

## 设计原则

玻璃用于承载导航和操作的少数表面，内容和普通按钮默认使用平面样式。一个浮层不因“弹出”就需要玻璃；对象详情、历史记录、编辑表单和 AI 正文属于内容层，需要稳定的底色与文字对比。

- 原生侧边栏、交通灯所在窗口区域继续使用 NSGlassEffectView / NSVisualEffectView。
- 文件预览、照片集、照片查看器保留整条透明顶栏，透出同一层原生玻璃；按钮不叠加单独的玻璃表面。
- 工具菜单、紧凑的下拉操作菜单保留一层轻材质，菜单项采用平面的悬停、选中反馈。
- 普通按钮不再自动覆盖为玻璃；主操作使用强调色，次操作使用普通填色，图标和 AppBar 常规操作保持简洁。交互状态由悬停、按压、焦点和选中反馈表达。
- 对象详情、历史记录、模板详情、表单、指南、搜索和 AI 快捷面板采用实色内容表面。通知与提示使用简洁实色，不添加透镜高光。

上述样式只在 `html[data-desktop-platform='macos']` 生效，不改变 Windows、Android 的材质与触控规格。

## 标记与接入

保留原有 `data-macos-glass` 属性作为兼容入口，**属性名称不表示所有值都使用玻璃**。按内容用途选择值，不按弹出位置或组件名称选择。

| 标记                              | 用途与材质                                                                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `data-macos-glass="panel"`        | 内容表面：对象详情、历史记录、模板详情、指南、表单、Dialog、侧栏快捷内容、尺标对象简介。使用主题实色、轻边线与阴影，无背景模糊、无渐变高光 |
| `data-macos-glass="popover"`      | 紧凑的操作或选择浮层：更多操作、下拉选择、日期选择、AI 会话选择。只对外框使用轻模糊，不添加玻璃高光                                        |
| `data-macos-glass="sidebar-menu"` | 侧栏工具菜单，直接透出侧栏共用的原生玻璃，不再添加网页模糊                                                                                 |
| `data-macos-glass="tooltip"`      | 悬停说明、密码提示。实色背景与轻阴影                                                                                                       |
| `data-macos-glass="notification"` | 通知。实色背景与轻阴影，保留原有状态色边框                                                                                                 |
| `data-macos-glass-backdrop`       | 浮层遮罩。取消重复的全屏背景模糊，保留组件自己的遮罩底色                                                                                   |
| `data-macos-glass-section`        | 内容面板内的淡色分区，使用主题工具栏底色                                                                                                   |

通用 `Dialog` 已接入内容表面；使用 `Card` 作为内容浮层外壳时设置 `surface="floating"`。搜索结果和 AI 主外框保持 `panel`，使正文与加载状态使用稳定底色；AI 历史会话下拉属于选择浮层，可以使用 `popover`。

`Button` 的 `glass` 变体仍可供其他平台使用，但 macOS 将其按普通次操作处理；不要为了恢复装饰效果给常规按钮新增局部背景模糊。已移除按钮上的 `data-macos-glass="control"` 标记，不再提供独立玻璃按钮入口。

浮层材质规则只设置表面，不修改定位、尺寸、圆角、滚动或拖拽命中区。普通 macOS 按钮采用 8px 圆角，取消统一胶囊轮廓，原有尺寸保持不变。新增浮层时，把标记放在实际绘制卡片的 DOM 外壳上；二级固定浮层通过 Portal 或兄弟节点呈现，避免带滤镜的父菜单改变定位参照。

## 主题和辅助功能

内容表面直接使用浅色或深色主题的 `--bg-elevated`。轻材质菜单分别采用 90% / 94% 的主题底色与 `blur(16px) saturate(1.1)`，无高光渐变；不支持背景滤镜时自动回退为实色。

原生返回 `solid` / 高对比，或浏览器请求减少透明度 / 强制颜色时，菜单、提示和内容面板都使用实色并清除阴影。窗口原生材质的辅助功能处理仍由原生层管理。

侧栏工具菜单确认 `liquid-glass` / `vibrancy` 后使用透明背景，直接透出导航区域原生材质。菜单展开时，仅裁去主导航中被菜单覆盖的部分；主导航与添加页面按钮保留原有位置。展开和折叠侧栏共用现有可用高度计算与展开/收起动画，减少动态效果偏好继续生效。

## 回归重点

- 深浅主题下，详情、历史、模板、搜索及 AI 正文为不透明内容表面；菜单仍有轻材质但没有渐变高光。
- 主、次、文字和图标按钮保留各自语义，悬停、焦点、禁用状态可辨认。
- Sidebar 工具菜单继续透出原生玻璃，展开/收起动画和按钮位置不变。
- 文件预览、照片集和照片查看器的整条顶栏继续保留原生玻璃。
- `solid`、高对比、减少透明度时清除局部滤镜；Windows 和 Android 样式不受 macOS 选择器影响。
- Playwright 可验证样式、布局和交互；原生玻璃合成仍需在系统 WKWebView 中观察。WebKit 截图曾存在忽略 CSS 滤镜的情况，不能仅凭页面截图判断原生合成结果。
