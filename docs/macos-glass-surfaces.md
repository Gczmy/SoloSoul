# macOS 材质与内容表面

实现入口：`tauri/src/styles/macos-glass.css` 与 `tauri/src/styles/desktop-controls.css`，由 `bootstrapApp.tsx` 加载。

## 设计原则

玻璃用于承载导航和操作的少数表面，内容和普通按钮默认使用平面样式。一个浮层不因“弹出”就需要玻璃；对象详情、历史记录、编辑表单和 AI 正文属于内容层，需要稳定的底色与文字对比。

- 原生侧边栏、交通灯所在窗口区域继续使用 NSGlassEffectView / NSVisualEffectView。
- 文件预览、照片集、照片查看器保留整条透明顶栏，透出同一层原生玻璃；按钮不叠加单独的玻璃表面。
- 工具菜单、紧凑的下拉操作菜单保留一层轻材质，菜单项采用平面的悬停、选中反馈。
- 普通按钮不再自动覆盖为玻璃；填色主操作使用强调色，次操作使用普通填色，AppBar 文字操作使用中性高对比文字；危险操作保留红色语义。交互状态由悬停、按压、焦点和选中反馈表达。
- 对象详情、历史记录、模板详情、表单、指南、搜索和 AI 快捷面板采用实色内容表面。通知与提示使用简洁实色，不添加透镜高光。

上述样式只在 `html[data-desktop-platform='macos']` 生效，不改变 Windows、Android 的材质与触控规格。

## 主窗口与登录面板（2026-10 前端重构）

窗口外壳统一使用 `--mac-shell-fill` 的90%填色强度；浅色沿用主题基础色（`--bg-base`），深色基础色混入12%白色以降低深色程度。登录前后沿用同一外壳颜色与填色强度，绘制在独立 `body::before` 上；侧栏和顶栏不各自重复叠加着色。绘制层没有滤镜或 transform，不改变 Portal / fixed 定位；预览裁剪页面根节点时也保留同一着色层。原生玻璃 / vibrancy 与窗口背景 alpha `0.001` 保持原实现。

桌面 macOS 正文由 `data-shell-surface` 承托，背景不透明，默认外沿 8px、圆角 16px。通知在表面中占位，正文边界继续由 ResizeObserver 发布，供尺标和固定面板读取。只有内容面裁剪圆角，外部 Portal 不受其裁剪。Windows 与移动端的外壳几何不采用这些值。

左 / 右导航的折叠开关位于 52px 顶栏，坐标来自交通灯实际右沿 + 12px，32px 命中区；展开与收起不移动按钮，水平导航不显示该入口。顶栏统一保持平面按钮反馈，开关加入既有原生命中区注册。

按2026-10-08最新反馈，登录页没有额外圆角背景底板；登录卡片改为普通实色 `--bg-elevated`，删除专用玻璃填色和滤镜。macOS卡片宽度为此前的80%：窄窗口最大288px，768px及以上最大313.6px。登录页、解锁后的侧栏与顶部栏共用90%外壳着色，不再按认证状态另加深色。浅色正文面为纯白，深色正文沿用主题基础色；深色外壳混入12%白色提升明度。正文、控件、认证请求及其他平台材质不变。

上述实现的浏览器几何与预览回归已有证据，原生系统合成、恢复和实际辅助功能验证仍以[第二轮台账](REFACTOR_FRONTEND_EXECUTION_REPORT_2026-10-07.md)为准。

2026-10-08 已通过[完整客户端 debug 隔离入口](../tauri/native-regression/macos-client/README.md)补充实际 WKWebView 的浅色登录、真实密码解锁、首页与侧栏收放截图，见[阶段证据](verification/fe2-macos-client-2026-10-08/README.md)。该入口复用生产 UI / IPC，使用独立合成 Vault、日志、插件与非持久 WebView 存储，不启用于正式发布。当前截图被系统共享提示遮住交通灯区域，且 Mac 锁屏后未继续深色 / 完整顶栏 / 浮层 / 恢复验收；这些范围仍待验证，不能据此关闭 FE2-002～005 / 007。

## 标记与接入

保留原有 `data-macos-glass` 属性作为兼容入口，**属性名称不表示所有值都使用玻璃**。按内容用途选择值，不按弹出位置或组件名称选择。

| 标记                              | 用途与材质                                                                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `data-macos-glass="panel"`        | 内容表面：对象详情、历史记录、模板详情、指南、表单、Dialog、侧栏快捷内容、尺标对象简介。使用主题实色、轻边线与阴影，无背景模糊、无渐变高光 |
| `data-macos-glass="popover"`      | 紧凑的操作或选择浮层：更多操作、下拉选择、日期选择、AI 会话选择。只对外框使用轻模糊，不添加玻璃高光                                        |
| `data-macos-glass="sidebar-menu"` | 侧栏工具菜单，直接透出侧栏共用的原生玻璃，不再添加网页模糊                                                                                 |
| `data-macos-glass="tooltip"`      | 悬停说明、密码提示。实色背景与轻阴影                                                                                                       |
| `data-macos-glass="notification"` | 通知。实色背景与轻阴影，保留原有状态色边框                                                                                                 |
| `data-macos-glass-backdrop`       | 浮层遮罩。取消重复的全屏背景模糊，保留组件自己的遮罩底色                                                                                   |
| `data-macos-glass-section`        | 内容面板内的淡色分区，使用主题工具栏底色                                                                                                   |

通用 `Dialog` 已接入内容表面；使用 `Card` 作为内容浮层外壳时设置 `surface="floating"`。搜索结果和 AI 主外框保持 `panel`，使正文与加载状态使用稳定底色；AI 历史会话下拉属于选择浮层，可以使用 `popover`。

`Button` 的 `glass` 变体仍可供其他平台使用，但 macOS 将其按普通次操作处理；不要为了恢复装饰效果给常规按钮新增局部背景模糊。已移除按钮上的 `data-macos-glass="control"` 标记，不再提供独立玻璃按钮入口。

浮层材质规则只设置表面，不修改定位、尺寸、圆角、滚动或拖拽命中区。普通 macOS 按钮采用 8px 圆角，取消统一胶囊轮廓，原有尺寸保持不变。新增浮层时，把标记放在实际绘制卡片的 DOM 外壳上；二级固定浮层通过 Portal 或兄弟节点呈现，避免带滤镜的父菜单改变定位参照。

## 主题和辅助功能

内容表面直接使用浅色或深色主题的 `--bg-elevated`。轻材质菜单分别采用 90% / 94% 的主题底色与 `blur(16px) saturate(1.1)`，无高光渐变；不支持背景滤镜时自动回退为实色。

原生返回 `solid` / 高对比，或浏览器请求减少透明度 / 强制颜色时，菜单、提示和内容面板都使用实色并清除阴影。窗口原生材质的辅助功能处理仍由原生层管理。

侧栏工具菜单确认 `liquid-glass` / `vibrancy` 后使用透明背景，直接透出导航区域原生材质。菜单展开时，仅裁去主导航中被菜单覆盖的部分；主导航与添加页面按钮保留原有位置。展开和折叠侧栏共用可用高度计算与展开/收起动画；没有品牌行时按导航的 padding-top 避让交通灯，减少动态效果偏好继续生效。

## 回归重点

- 深浅主题下，详情、历史、模板、搜索及 AI 正文为不透明内容表面；菜单仍有轻材质但没有渐变高光。
- 主、次、文字和图标按钮保留各自语义，悬停、焦点、禁用状态可辨认。
- Sidebar 工具菜单继续透出原生玻璃，展开/收起动画和按钮位置不变。
- 文件预览、照片集和照片查看器的整条顶栏继续保留原生玻璃。
- `solid`、高对比、减少透明度时清除局部滤镜；Windows 和 Android 样式不受 macOS 选择器影响。
- Playwright 可验证样式、布局和交互；原生玻璃合成仍需在系统 WKWebView 中观察。WebKit 截图曾存在忽略 CSS 滤镜的情况，不能仅凭页面截图判断原生合成结果。

## 2026-10-08 功能文字与品牌标志

全部平台的正文和功能文字使用按明暗模式生成的黑白中性色，不跟随暖石等主题偏色；选中导航的文字保持中性，背景继续表达选择状态。强制颜色使用CanvasText。桌面侧栏和横向导航不再显示SoloSoul品牌图像，展开侧栏保留名称；折叠macOS侧栏不保留空品牌行。Android顶部栏移除品牌图像，保留标题、返回、账户和锁定操作；登录和关于页面的品牌图像保持。

正文和功能文字的全局约束、色板可修改范围及业务语义例外见[主题改变边界](frontend-theme-boundaries.md)。

额外登录底板及其专用着色变量已删除；窗口底色和登录卡片保留。展开侧栏默认186px，保留交通灯宽度下限；内容、AppBar和原生导航区域共用同一宽度。


## 2026-10-08 紧凑登录卡片

品牌图标与名称横排，副标题置于名称下方；图标保留48px。账户下方8px、登录方式下方8px，快捷入口不叠加顶部间距；桌面内边距28px且不强制420px最小高度。宽macOS桌面三种正常登录方式预留132px（卡片收窄后生物识别长文案可能换行），Windows宽桌面预留120px，窄窗口和手机保留144px与现有触控高度；PIN在登录页横排图标与标题，其他密码验证弹窗仍使用纵向标题。错误和长文案允许自然撑开，矮窗口保持滚动与圆角。
