## 1. 核心决策

**保留 Markdown 源文件，用 React 组件增强渲染。**

```
源文件（维护层）                    渲染层（展示层）
tauri/src-tauri/resources/docs/guides/   src/components/guide/
├── index.json    ───────────────→   GuideIndex.tsx（指南目录）
├── objects.md    ───────────────→   GuideRenderer.tsx（富交互渲染）
├── security.md   ───────────────→   GuideSearch.tsx（全文搜索）
└── ...                              GuideCodeBlock.tsx（代码复制）
        ↑
        └──────────────────────→   AI 检索（纯文本提取，注入 LLM 上下文）
```

### 为什么不选其他方案？

| 方案 | 排除理由 |
|------|---------|
| 纯 Markdown 渲染（现有） | 无全文搜索、无交互、样式天花板低 |
| 嵌入 WebView 外部站点 | 违背本地优先（需要网络） |
| 富文本编辑器 | 多人协作不需要，维护成本高 |
| PDF 内嵌 | 不可搜索、不可交互、更新不便 |

### 自定义容器语法（HTML 注释标记）

弃用 `:::` 语法（需自定义 tokenizer，复杂度高），改用 **HTML 注释** 作为零成本的段落标记：

```markdown
## 创建护照对象

<!--STEPPER 创建护照对象-->
1. 点击首页的「+ 新建对象」按钮
2. 选择对象类型「护照」
3. 填写护照号码、签发日期等信息
4. 点击「保存」
<!--/STEPPER-->

<!--TIP-->
护照号码属于敏感数据，查看时需要进行身份验证。
<!--/TIP-->

<!--WARNING-->
删除对象后可在回收站 30 天内恢复，过期将永久删除。
<!--/WARNING-->
```

`react-markdown` 会将 HTML 注释作为 `html` 节点输出，`GuideHtmlComment` 组件通过正则匹配 `<!--TAG-->...<!--/TAG-->` 将其替换为对应 React 组件。

### 代码块复制实现

```tsx
function GuideCodeBlock({ children, className }) {
  const [copied, setCopied] = useState(false);
  const ref = useRef<HTMLElement>(null);

  const handleCopy = async () => {
    const text = String(children).replace(/\n$/, '');
    try {
      await navigator.clipboard.writeText(text);
      setCopied(true);
      setTimeout(() => setCopied(false), 2000);
    } catch {
      // 降级：选中文本
      window.getSelection()?.selectAllChildren(ref.current!);
    }
  };

  return (
    <div className="code-block-wrapper">
      <pre ref={ref} className={className}><code>{children}</code></pre>
      <button onClick={handleCopy}>{copied ? '✓' : '复制'}</button>
    </div>
  );
}
```

## 4. 全文搜索

### 搜索算法优化

指南总量预期 < 30 篇，TF-IDF 在此规模下收益极低且需引入分词库（结巴）。改为**前缀匹配 + 倒排索引**：

```typescript
// src/lib/guide-search.ts

interface SearchResult {
  guideId: string;
  title: string;
  excerpt: string;      // 匹配段落摘要
  highlights: number[]; // 高亮字符位置
}

// 倒排索引（构建时或首次加载时生成 search-index.json）
interface SearchIndex {
  words: Record<string, string[]>;  // word -> guideId[]
  titles: Record<string, { zh: string; en: string }>; // guideId -> title
}

export function searchGuides(query: string, locale: string, index: SearchIndex): SearchResult[] {
  const tokens = query.toLowerCase().split(/\s+/).filter(Boolean);
  if (tokens.length === 0) return [];

  // 命中计数：guideId -> score
  const scores = new Map<string, number>();
  for (const token of tokens) {
    for (const [word, guideIds] of Object.entries(index.words)) {
      if (word.startsWith(token) || token.startsWith(word)) {
        for (const id of guideIds) {
          scores.set(id, (scores.get(id) || 0) + 1);
          // 标题命中加权
          if (index.titles[id]?.[locale as 'zh' | 'en']?.toLowerCase().includes(token)) {
            scores.set(id, (scores.get(id) || 0) + 3);
          }
        }
      }
    }
  }

  const threshold = tokens.length >= 2 ? 2 : 1;
  return Array.from(scores.entries())
    .filter(([, score]) => score >= threshold)
    .sort((a, b) => b[1] - a[1])
    .map(([id]) => ({ guideId: id, title: index.titles[id][locale as 'zh' | 'en'], excerpt: '', highlights: [] }));
}
```

### 索引构建策略

| 模式 | 构建时机 | 产物 |
|------|---------|------|
| 开发模式 | `npm run dev` 启动时，Node 脚本读取全部 Markdown 生成 | `public/search-index.json`（或内存中） |
| 生产模式 | 构建脚本在 `npm run build` 前生成 | 打包进 `resources/` |
| 运行时回退 | 若索引不存在，首次访问帮助页时 Rust 后端扫描生成 | 内存缓存 |

## 5. AI 检索兼容

帮助文档作为 AI 对话的上下文注入。在原规范基础上优化为 **Top-3 + 摘要缓存 + 意图分类**：

```rust
// Rust 端 — tauri/src-tauri/src/commands/llm.rs

pub fn retrieve_relevant_guides(query: &str, locale: &str) -> Vec<String> {
    // 1. 对 query 分词（简单空格 + 标点分割）
    let tokens: Vec<String> = query.to_lowercase()
        .split(|c: char| c.is_whitespace() || c.is_ascii_punctuation())
        .filter(|s| !s.is_empty())
        .map(|s| s.to_string())
        .collect();

    if tokens.is_empty() { return vec![]; }

    // 2. 意图分类（简单规则）
    let is_howto = tokens.iter().any(|t| ["怎么", "如何", "怎样", "how", "步骤"].contains(&t.as_str()));
    let is_concept = tokens.iter().any(|t| ["什么是", "为什么", "what", "why"].contains(&t.as_str()));

    // 3. 加载索引 + 评分
    let index = load_guide_index().ok()?;
    let mut scored: Vec<(GuideIndexEntry, i32)> = vec![];

    for guide in &index.guides {
        let mut score = 0;
        for token in &tokens {
            if guide.keywords.iter().any(|k| k.to_lowercase().contains(token)) {
                score += 1;
            }
            if guide.title.to_lowercase().contains(token) {
                score += 3;
            }
        }
        // 意图加权
        if is_howto && guide.category == "objects" { score += 2; }
        if is_concept && guide.category == "security" { score += 2; }

        let threshold = if tokens.len() >= 2 { 2 } else { 1 };
        if score >= threshold {
            scored.push((guide.clone(), score));
        }
    }

    // 4. 取 Top-3（原规范为 Top-1，扩展为 3 篇互补）
    scored.sort_by_key(|(_, s)| -s);
    scored.into_iter()
        .take(3)
        .filter_map(|(entry, _)| load_guide_content(&entry, locale).ok())
        .map(|g| {
            // 5. 截断至 800 字符（按段落边界）
            let content = if g.content.len() > 800 {
                match g.content[..800].rfind('\n') {
                    Some(i) => g.content[..i].to_string(),
                    None => g.content[..800].to_string(),
                }
            } else { g.content };
            format!("【文档：{}】\n{}\n【文档结束】", g.title, content)
        })
        .collect()
}
```

**摘要缓存**：Rust 端首次加载指南时，提取每篇文档的前 200 字作为 `summary` 缓存到 `GUIDE_INDEX_CACHE`，AI 匹配阶段先用摘要评分，命中后再加载全文。
