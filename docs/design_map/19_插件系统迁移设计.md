## 1. 迁移策略：复用为主，微调为辅

插件系统的 Rust 核心代码（7 个文件，~2200 行）**质量高、架构清晰**，以整体平移为主，仅替换 Tauri 适配层：

| 组件 | 迁移方式 |
|------|---------|
| `PluginManager` | 平移，注册为 Tauri State |
| `WasmSandbox` (wasmtime) | 平移 |
| `SoloHostFunctions` (8 个) | 平移，Rust 逻辑不变 |
| `PluginManifest` | 平移 |
| `PluginSessionManager` | 平移 |
| **事件通道** | `StreamSink` → `tauri::ipc::Channel<PluginEvent>` |
| **全局单例** | `lazy_static!` → Tauri `AppHandle` + State |
| **日志** | 手写文件 → `tracing` |
| **前端 UI** | Flutter Widget → React 组件（重写） |

## 2. 安全模型（已验证，保持不变）

```
Layer 5: 用户控制层 — 随时撤销 Session、卸载插件、查看审计日志
Layer 4: 审计层 — 所有访问写入 plugin_audit.log（加密）
Layer 3: 速率与资源层 — Fuel 10M/Release、10次/分钟/字段、TTL 超时
Layer 2: 权限层 — manifest 声明校验 + 敏感度分级授权 + 网络白名单
Layer 1: 隔离层 — Wasmtime Store 隔离 + 无文件系统 + 无持久存储
```

## 3. Host Functions 一览（8 个，保持不变）

| Host Function | 功能 | 安全限制 |
|--------------|------|---------|
| `solosoul_request_field` | 读取用户数据字段 | manifest 声明 + 敏感度 + Consent + 速率限制 |
| `solosoul_post_data` | HTTP POST | 域名白名单匹配 |
| `solosoul_log` | 记录日志 | 长度限制 |
| `solosoul_result` | 发送结构化结果 | JSON 校验 + 大小 64KB + type 白名单 |
| `solosoul_get_timestamp` | Unix 时间戳 | 无限制 |
| `solosoul_get_data_structure_tree` | 数据结构元数据 | 无限制 |
| `solosoul_show_dialog` | 弹出对话框 | 仅白名单插件 |
| `solosoul_get_param` | 读取初始参数 | 仅字符串 |

**统一错误码**：0=成功, -1=未声明, -2=用户拒绝, -3=TTL过期, -4=缓冲不足, -8=速率限制, -10=域名不在白名单

## 5. 前端事件流

```typescript
async function runPlugin(pluginId: string, params?: object) {
  const channel = new Channel<PluginEvent>();

  channel.onmessage = (event) => {
    switch (event.type) {
      case 'consent_request': showConsentDialog(event); break;
      case 'log': appendLog(event.level, event.message); break;
      case 'result': renderResultCard(JSON.parse(event.json_data)); break;
      case 'progress': updateProgress(event.percent); break;
      case 'completed': showCompletionStatus(event.exit_code); break;
      case 'error': showError(event.message); break;
    }
  };

  await invoke('plugin_run', { pluginId, params: JSON.stringify(params), channel });
}
```
