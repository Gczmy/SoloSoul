# L3 核心业务服务层

> **层级定位**：持有所有业务逻辑，处理数据转换、校验、流程编排。对上层（L4 状态管理层）提供高内聚的服务接口，对下层（L1 数据层、L2 加密层）调用存储与加密能力。这是 SoloSoul 的"大脑"。
>
> **核心原则**：每个服务只负责一个业务域；服务之间通过明确接口通信，禁止直接访问对方内部状态；所有敏感操作必须通过 Vault 解锁状态检查。
>
> **Tauri 迁移方向**：全部下沉到 Rust 后端，每个服务封装为 `tauri::command`。前端仅通过 IPC 调用，不持有任何业务逻辑。

## L3.2 Vault 生命周期服务

**当前实现**：`lib/presentation/providers/auth/auth_notifier.dart`（Dart）+ `native/src/vault/store.rs`（Rust）

### 2.1 职责

- Vault 的初始化、解锁、锁定、密码修改的全生命周期管理
- 解锁后自动加载 Profile
- 状态变更通知

### 2.2 状态机

```
┌─────────────┐    init(password)     ┌────────┐
│ Uninitialized│ ───────────────────→ │ Locked │
└─────────────┘                      └────┬───┘
                                          │
                    unlock(password)      │
                                          ▼
                                       ┌─────────┐
        ┌─────────────────────────────│Unlocked │
        │                             └────┬────┘
        │ lock()                           │
        │                                  │ change_password(old, new)
        ▼                                  │
     ┌────────┐                         ┌─┴────────┐
     │ Locked │ ←──────────────────────│Unlocked  │
     └────────┘                         └──────────┘
```

### 2.3 核心接口

| 方法 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `init_vault` | account_id, password | `Result<(), VaultError>` | 生成 Salt → KDF → 创建验证令牌 → 创建 Vault |
| `unlock_vault` | account_id, password | `Result<UnlockResult, VaultError>` | KDF → 验证令牌 → 打开 SQLCipher → 加载 Profile |
| `lock_vault` | — | `Result<(), VaultError>` | 关闭 SQLCipher → 擦除内存密钥 |
| `change_password` | old_password, new_password | `Result<(), VaultError>` | 旧密码验证 → 用新密码重新加密所有数据 |
| `get_vault_state` | — | `VaultState` | Locked / Unlocked / Uninitialized |

### 2.4 解锁后自动加载

```rust
pub fn unlock_vault(account_id: &str, password: &str) -> Result<UnlockResult, VaultError> {
    // 1. 派生密钥
    let key = derive_key(password, salt)?;
    
    // 2. 验证密码（解密验证令牌）
    verify_password(password, salt, &token)?;
    
    // 3. 打开 Vault
    let store = VaultStore::open(vault_path, account_id, &key)?;
    
    // 4. 加载 Profile
    let profile = store.load_profile(account_id)?;
    let profile_data = serde_json::from_str(&profile)?;
    
    // 5. 更新最后访问时间
    update_last_accessed(account_id)?;
    
    Ok(UnlockResult { profile: profile_data })
}
```

### 2.5 密码修改

```rust
pub fn change_password(
    account_id: &str,
    old_password: &str,
    new_password: &str,
) -> Result<(), VaultError> {
    // 1. 用旧密码解锁
    let old_key = derive_key(old_password, salt)?;
    verify_password(old_password, salt, &token)?;
    
    // 2. 生成新 Salt（可选，安全最佳实践）
    let new_salt = generate_salt();
    let new_key = derive_key(new_password, &new_salt)?;
    let new_token = create_verification_token(&new_key);
    
    // 3. 重新加密 Vault 中所有数据
    let mut store = VaultStore::open(vault_path, account_id, &old_key)?;
    let profiles = store.list_profiles()?;
    for profile in profiles {
        let plaintext = store.load_profile_raw(&profile.id)?;
        // SQLCipher 的 PRAGMA rekey 会自动处理
    }
    store.rekey(&new_key)?;
    
    // 4. 更新 config.json
    save_config(new_salt, new_token)?;
    
    Ok(())
}
```

### 3.6 缓存策略

`UnifiedObjectCache` 预计算索引：
- `objectById: Map<String, UnifiedObject>` — O(1) 按 ID 查找
- `itemChildren: Map<String, List<UnifiedObject>>` — O(1) 按父 ID 查子对象
- `workspaceChildren: Map<String, List<UnifiedObject>>` — 过滤掉 page 类型的子对象
- `rootObjects: List<UnifiedObject>` — 根级对象（排除 page 类型）

缓存重建触发条件：任何对象增删改后，后台异步重建索引。

## L3.5 OCR 引擎服务

**Dart 封装**：`lib/core/services/ocr_service.dart`  
**Rust 实现**：`native/src/ocr/`

### 5.1 引擎架构

```
图像输入 → [预处理] → [检测(det)] → [方向分类(cls)] → [识别(rec)] → [后处理] → 文本结果
                ↑                    ↑                    ↑
         preprocess.rs           inference.rs          postprocess.rs
```

**模型**：PP-OCRv4（PaddleOCR 第四版）
- `ppocrv4_det.onnx` — 文本检测
- `ppocrv4_cls.onnx` — 方向分类
- `ppocrv4_rec.onnx` — 文本识别

### 5.2 初始化

```dart
static Future<void> initialize() async {
  // 1. 从 Flutter asset 加载 ONNX 模型
  final detBytes = await rootBundle.load('assets/models/v1/ppocrv4_det.onnx');
  final clsBytes = await rootBundle.load('assets/models/v1/ppocrv4_cls.onnx');
  final recBytes = await rootBundle.load('assets/models/v1/ppocrv4_rec.onnx');
  
  // 2. 通过 FFI 传递给 Rust
  await frbOcrInitV2(
    detModelBytes: detBytes,
    clsModelBytes: clsBytes,
    recModelBytes: recBytes,
  );
  
  // 3. 验证模型加载状态
  final status = await frbOcrStatus();
  assert(status.recLoaded);
}
```

### 5.3 MRZ 识别

```dart
static Future<MrzResult> extractMrz(Uint8List imageBytes) async {
  // 1. 调用 Rust MRZ 流水线
  final result = await frbExtractMrz(imageBytes: imageBytes)
      .timeout(_mrzTimeout); // 10s
  
  // 2. 解析 MRZ 行
  final mrz = MrzParser.parse(result.lines);
  
  return MrzResult(
    documentType: mrz.documentType,
    documentNumber: mrz.documentNumber,
    nationality: mrz.nationality,
    dateOfBirth: mrz.dateOfBirth,
    gender: mrz.gender,
    expiryDate: mrz.expiryDate,
    names: mrz.names,
    surname: mrz.surname,
    confidence: result.confidence,
  );
}
```

**MRZ 格式支持**：TD1（身份证）、TD2（旧版护照）、TD3（ICAO 护照）

### 5.4 通用 OCR

```dart
static Future<GeneralOcrResult> recognizeImage(Uint8List imageBytes) async {
  final result = await frbRecognizeImage(imageBytes: imageBytes)
      .timeout(_generalTimeout); // 10s
```

### 5.5 错误分级

| 异常 | 触发条件 | 处理建议 |
|------|---------|---------|
| `OcrNotInitializedException` | 引擎未初始化 | 引导用户等待或重试 |
| `OcrTimeoutException` | 10 秒超时 | 建议检查图像质量 |
| `OcrMrzNotFoundException` | 未定位到 MRZ 区域 | 建议调整拍摄角度 |
| `OcrLowConfidenceException` | MRZ 行置信度 < 0.8 | 提示手动核对 |
| `OcrTextNotDetectedException` | 通用 OCR 无文本 | 提示图像过暗或模糊 |

```rust
    Completed { session_id: String, exit_code: i32, result: Option<String> },
    Error { session_id: String, message: String },
    Log { level: String, message: String },
}
```

### 7.5 字段授权（Consent）

1. 插件请求访问字段 → 前端显示 `PluginConsentDialog`
2. 用户授权 → `frbPluginConsentResponse(sessionId, approvedFields)`
3. Rust 更新 Session 授权列表
4. 插件通过 Host Functions 访问已授权字段

### 7.6 限制

- **iOS**：不支持 Wasmtime JIT，插件系统不可用
- **沙盒**：插件无法直接访问文件系统、网络、系统 API
- **TTL**：Session 超时后自动销毁，数据擦除

## L3.9 本地文件扫描服务

**核心实现**：`lib/core/services/scan/`

### 9.1 扫描流程

```
配置扫描参数 ──→ 文件列举 ──→ 内容解析 ──→ 分区检测 ──→ AI 映射 ──→ 导入确认 ──→ 写入 Vault
                │            │            │           │
                ▼            ▼            ▼           ▼

```

### 9.2 扫描配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `paths` | 桌面、文档、下载 | 扫描目标路径 |
| `extensions` | pdf, doc, docx, xls, xlsx, ppt, pptx, jpg, png, txt | 目标扩展名 |
| `scanDepth` | `"fingerprint"` | `"filename"` / `"fingerprint"` / `"full"` |
| `maxFilesPerPath` | 10000 | 单路径最大文件数 |
| `maxFileSizeByExtension` | {pdf: 50MB, ...} | 按类型限制大小 |

### 9.3 文件列举（`ScanFileLister`）

### 9.4 内容解析（`ContentParserService`）

| 文件类型 | 解析方式 |
|---------|---------|
| PDF | `pdf_text_extractor` 或 OCR |
| Word/Excel/PowerPoint | 解压缩 + XML 解析 |
| 图片 | OCR 识别 |
| 文本 | 直接读取 |

### 9.5 分区检测（`ScanSectionDetector`）

基于文件名关键词 + 内容关键词匹配：
- 文件名含 "passport" → `__preset_passport`
- 内容含 "银行账号" → `__preset_bank_account`
- 置信度评分，低于阈值标记为"未确定"

### 9.6 AI 映射（`performAiMapping`）

```dart
Future<void> performAiMapping() async {
  // 1. 检查 LLM 配置
  if (!hasValidLlmConfig) throw LlmConfigError();
  
  // 2. 对每个候选文件，提取文本内容
  for (final candidate in importCandidates) {
    final content = await extractContent(candidate.file);
    
    // 3. 调用 LLM 分析内容，映射到 SoloSoul 字段
    final mapping = await llmService.mapFields(content, candidate.detectedSection);
    
    // 4. 更新候选对象的 properties
    candidate.properties = mapping.fields;
  }
}
```

### 9.7 导入服务（`ScanImportService`）

```dart
Future<ImportResult> doImport(List<ImportCandidate> candidates) async {
  // 1. 检测冲突（与现有对象重复）
  final conflicts = detectConflicts(candidates);
  
  // 2. 对选中的候选创建 UnifiedObject
  for (final candidate in candidates.where((c) => c.isSelected)) {
    await unifiedObjectService.createObject(
      typeId: candidate.targetSection,
      name: candidate.fileName,
      properties: candidate.properties,
    );
  }
  
  // 3. 返回导入统计
  return ImportResult(
    imported: importedCount,
    skipped: skippedCount,
    conflicts: conflicts.length,
    warnings: warnings,
  );
}
```

## L3.12 搜索服务

### 12.1 索引构建

```dart
class SearchIndex {
  // 从所有 UnifiedObject 构建
  static SearchIndex build(List<UnifiedObject> objects) {
    final index = SearchIndex();
    for (final obj in objects) {
      index.addTerm(obj.id, obj.name, weight: 10);
      for (final entry in obj.properties.entries) {
        final value = entry.value.value?.toString() ?? '';
        index.addTerm(obj.id, value, weight: 5, field: entry.key);
      }
    }
    return index;
  }
}
```
