# L2 密码学与安全核心层

> **层级定位**：所有加密、密钥派生、安全内存管理。对上层（L1 数据层、L3 服务层）提供"黑箱"接口：输入密码/数据，输出密文/明文，隐藏算法细节。本层是零知识安全模型的技术根基。
>
> **核心原则**：主密码永不存储；所有密钥仅在内存中存在；敏感数据使用后立即安全擦除；常数时间比较防时序攻击。
>
> **Tauri 迁移方向**：将 `flutter/native/src/crypto/` 中的密码学代码提取为独立 Rust crate `solosoul-crypto`，成为 Tauri 后端的内置模块，无需 FFI 桥接。

## L2.1 密钥派生（KDF）

### 1.1 算法选择

**Argon2id**（密码哈希竞赛 winner）
- 抵抗 GPU/ASIC 暴力破解
- 抵抗侧信道攻击
- OWASP 推荐用于密码哈希

### 1.2 参数配置

| 参数 | 开发模式（默认） | 生产模式 | 切换方式 |
|------|----------------|---------|---------|
| **内存（Memory）** | 8 MiB (8 × 1024 KiB) | 64 MiB (64 × 1024 KiB) | `SOLOSOUL_SECURE=1` |
| **迭代次数（Iterations）** | 2 | 3 | `SOLOSOUL_SECURE=1` |
| **并行度（Parallelism）** | 4 | 4 | 固定 |
| **Salt 长度** | 32 字节 | 32 字节 | 固定 |
| **输出密钥长度** | 32 字节（256 bits） | 32 字节 | 固定 |

**参数选择理由**：
- 开发模式 8MiB/2iter：Apple Silicon 上 64MiB 可能挂起数秒，影响开发体验
- 生产模式 64MiB/3iter：OWASP 2023 推荐最低参数
- 并行度 4：匹配现代 CPU 核心数

### 1.3 当前 Rust 实现

**位置**：`native/src/crypto/argon2.rs`

```rust
use argon2::{Argon2, Algorithm, Version, Params};

pub fn derive_key(password: &[u8], salt: &[u8]) -> Result<Zeroizing<[u8; 32]>, CryptoError> {
    let params = Params::new(memory_kib, iterations, parallelism, Some(32))
        .map_err(|e| CryptoError::InvalidParams(e.to_string()))?;
    let argon2 = Argon2::new(Algorithm::Argon2id, Version::V0x13, params);
    
    let mut key = Zeroizing::new([0u8; 32]);
    argon2.hash_password_into(password, salt, &mut *key)
        .map_err(|e| CryptoError::KdfFailed(e.to_string()))?;
    Ok(key)
}
```

**关键特性**：
- 返回 `Zeroizing<[u8; 32]>` — 离开作用域自动清零
- `Algorithm::Argon2id` — 抵抗 GPU 和侧信道攻击
- `Version::V0x13` — 最新版本

### 1.4 Salt 生成

```rust
use rand::RngCore;

pub fn generate_salt() -> [u8; 32] {
    let mut salt = [0u8; 32];
    rand::thread_rng().fill_bytes(&mut salt);
    salt
}
```

- 使用 `rand::thread_rng()`（密码学安全 CSPRNG）
- Salt 随 Vault 初始化时生成一次，永久存储在 `config.json` 中

### 1.5 FFI 桥接（当前）

**位置**：`src/lib.rs`

通过 C FFI 暴露给 Go：
```rust
#[no_mangle]
pub unsafe extern "C" fn argon2_derive_key(
    password: *const u8, password_len: usize,
    salt: *const u8, salt_len: usize,
    memory_kib: u32, iterations: u32, parallelism: u32,
    output: *mut u8, output_len: usize
) -> i32;
```

**Go 调用**：
```go

// extern int argon2_derive_key(...);

result := C.argon2_derive_key(
    (*C.uint8_t)(unsafe.Pointer(&password[0])), C.size_t(len(password)),
    (*C.uint8_t)(unsafe.Pointer(&salt[0])), C.size_t(len(salt)),
    C.uint32_t(memory), C.uint32_t(iterations), C.uint32_t(parallelism),
    (*C.uint8_t)(unsafe.Pointer(&key[0])), C.size_t(len(key)),
)
```

## L2.2 对称加密

### 2.1 算法选择

**AES-256-GCM**（Galois/Counter Mode）
- 256-bit 密钥（32 字节）
- 128-bit 认证标签（16 字节）
- 96-bit nonce（12 字节），每次加密随机生成
- 提供机密性 + 完整性 + 认证

### 2.2 SOLO Blob 格式

#### v2 格式（小文件，≤50MB）

```
[0..11]    nonce (12 bytes)
[12..N-16] ciphertext
[N-15..N]  auth tag (16 bytes)
```

总大小 = plaintext_len + 28 bytes（12 nonce + 16 tag）

#### v3 格式（大文件流式，>50MB）

```
Header:
  [0..3]     magic: "SOLO" (4 bytes)
  [4]        version: 0x03 (1 byte)
  [5..8]     chunk_size: 1MB (4 bytes, u32 LE)
  [9..24]    reserved (16 bytes)

Chunks (each):
  [0..11]    chunk_nonce (12 bytes)
  [12..N-16] chunk_ciphertext
  [N-15..N]  chunk_tag (16 bytes)
```

每个分块独立加密，使用递增 nonce（base_nonce + chunk_index）。

### 2.3 当前 Rust 实现

**位置**：`native/src/crypto/aes.rs`

```rust
use aes_gcm::{Aes256Gcm, Key, Nonce};
use aes_gcm::aead::{Aead, KeyInit};

pub fn encrypt(plaintext: &[u8], key: &[u8; 32]) -> Result<Vec<u8>, CryptoError> {
    let key = Key::<Aes256Gcm>::from_slice(key);
    let cipher = Aes256Gcm::new(key);
    let nonce = generate_nonce(); // 12 bytes random
    let ciphertext = cipher.encrypt(Nonce::from_slice(&nonce), plaintext)
        .map_err(|e| CryptoError::EncryptFailed(e.to_string()))?;
    
    let mut result = Vec::with_capacity(12 + ciphertext.len());
    result.extend_from_slice(&nonce);
    result.extend_from_slice(&ciphertext);
    Ok(result)
}

pub fn decrypt(ciphertext: &[u8], key: &[u8; 32]) -> Result<Vec<u8>, CryptoError> {
    if ciphertext.len() < 28 {
        return Err(CryptoError::InvalidCiphertext);
    }
    let nonce = Nonce::from_slice(&ciphertext[..12]);
    let encrypted = &ciphertext[12..];
    let key = Key::<Aes256Gcm>::from_slice(key);
    let cipher = Aes256Gcm::new(key);
    cipher.decrypt(nonce, encrypted)
        .map_err(|e| CryptoError::DecryptFailed(e.to_string()))
}
```

### 2.4 流式加密

**位置**：`native/src/crypto/stream.rs`

```rust
pub fn encrypt_file(
    src: &Path, dst: &Path,
    key: &[u8; 32],
    progress_path: &Path,
    cancel_path: &Path,
) -> Result<(), CryptoError>;
```

**流程**：
1. 读取源文件大小
2. 计算总分块数
3. 逐块读取（1MB）→ 生成 nonce → 加密 → 写入目标文件
4. 每完成一块，更新 `progress_path`（写入 `"0.0"` ~ `"1.0"`）
5. 每块开始前检查 `cancel_path` 是否存在，存在则中断并清理

### 2.5 Dart 回退实现

**位置**：Dart 端 `pointycastle` / `cryptography` / `encrypt` 包

- Android 平台 Vault 操作被临时 stub，使用 Dart 端密码学回退
- 输出格式必须与 Rust 端完全一致（SOLO blob v2）
- 参数：AES-256-GCM，12-byte nonce，16-byte tag

## L2.3 安全内存管理

### 3.1 显式清零

**Rust**：`zeroize` crate

```rust
use zeroize::Zeroize;

// 显式清零
let mut secret = vec![1, 2, 3, 4];
secret.zeroize(); // 内存被 0 覆盖

// 自动清零（离开作用域时）
let secret = Zeroizing::new(vec![1, 2, 3, 4]);
// secret 离开作用域时自动 zeroize
```

**Go**：`SecureWipe`

```go
func SecureWipe(b []byte) {
    for i := range b {
        b[i] = 0
    }
    runtime.KeepAlive(b) // 防止编译器优化掉擦除
}
```

### 3.2 内存锁定

**Rust**：`mlock`（防止交换到磁盘）

```rust
#[cfg(unix)]
fn mlock_memory(ptr: *const u8, len: usize) -> Result<(), String> {
    let ret = unsafe { libc::mlock(ptr, len) };
    if ret == 0 { Ok(()) } else { Err("mlock failed".into()) }
}
```

**Go**：`runtime.SetFinalizer` + `SecureWipe`

### 3.3 链接时优化

`Cargo.toml`：
```toml
[profile.release]
lto = true
```

- 启用链接时优化，编译器可消除冗余副本
- 进一步降低密钥在内存中的残留风险

### 3.4 编译优化配置

`Cargo.toml` Release 配置目标：

```toml
[profile.release]
opt-level = "z"      # 优化体积
strip = true         # 剥离调试符号
lto = true           # 链接时优化
codegen-units = 1    # 单编译单元，更好优化
panic = "abort"      # 不生成展开代码，减少体积
```

## L2.4 验证与令牌

### 4.1 设计原则：不存储密码哈希

传统做法：存储 `hash(password)`，验证时比较。  
SoloSoul 做法：存储 `encrypt("SOLOSOUL_VAULT_V1", key)`，验证时尝试解密。

**优势**：
- 不存储密码的任何直接派生形式
- 即使验证令牌泄露，也无法反推密码
- 统一使用 AES-GCM，减少密码学原语种类

### 4.2 验证令牌生成

```rust
pub fn create_verification_token(key: &[u8; 32]) -> Vec<u8> {
    let plaintext = b"SOLOSOUL_VAULT_V1";
    encrypt(plaintext, key).expect("encryption should not fail")
}
```

### 4.3 密码验证

```rust
pub fn verify_password(password: &str, salt: &[u8], token: &[u8]) -> Result<bool, CryptoError> {
    let key = derive_key(password.as_bytes(), salt)?;
    let decrypted = decrypt(token, &*key)?;
    Ok(decrypted == b"SOLOSOUL_VAULT_V1")
}
```

### 4.4 常数时间比较

**Rust**：防止时序攻击

```rust
use subtle::ConstantTimeEq;

let valid = decrypted.ct_eq(b"SOLOSOUL_VAULT_V1").into();
```

**Go**：

```go
import "crypto/subtle"

valid := subtle.ConstantTimeCompare(decrypted, []byte("SOLOSOUL_VAULT_V1")) == 1
```

## L2.5 生物识别凭证安全

### 5.1 凭证生成

生物识别验证通过后，生成高熵随机凭证：

```rust
pub fn generate_biometric_credential() -> String {
    let mut bytes = [0u8; 32];
    rand::thread_rng().fill_bytes(&mut bytes);
    base64::encode(bytes)
}
```

### 5.2 凭证存储

| 平台 | 存储位置 | 键名 |
|------|---------|------|
| macOS | Keychain | `com.solosoul.biometric.{account_id}` |
| iOS | Keychain | 同左 |
| Android | EncryptedSharedPreferences | `biometric_credential_{account_id}` |
| Windows | Windows Credential | `SoloSoul_Biometric_{account_id}` |
| Linux | Secret Service | `/com/solosoul/biometric/{account_id}` |

### 5.3 凭证验证流程

```
1. 用户点击"生物识别解锁"
2. 系统生物识别验证（Touch ID / Face ID / 指纹）
3. 验证通过后，从安全存储读取 credential
4. 将 credential 发送到 Rust 后端
5. Rust 后端验证 credential 与账户绑定关系
6. 验证通过 → 解锁 Vault（无需输入密码）
```

**注意**：生物识别凭证不等同于主密码，仅作为"快捷解锁"凭证。修改主密码后，生物识别凭证需要重新绑定。

## 当前架构债务：两套重复实现

| 维度 | `flutter/native/src/crypto/` | `src/lib.rs` |
|------|------------------------------|---------------------------|
| **用途** | Flutter FRB 调用 | 已废弃 CGO 调用 |
| **接口类型** | Rust 函数（FRB 宏） | C FFI（`#[no_mangle] extern "C"`） |
| **Argon2id** | `derive_key()` / `generate_salt()` | `argon2_derive_key()` / `argon2_generate_salt()` |
| **AES-GCM** | `encrypt()` / `decrypt()` | `aes_256_gcm_encrypt()` / `aes_256_gcm_decrypt()` |
| **SOLO Blob** | v2 + v3 流式 | 无（仅 bytes 级别） |
| **Zeroize** | ✅ `Zeroizing<T>` | ❌ 无 |
| **KdfPreset** | ✅ 开发/生产参数预设 | ❌ 无 |
| **错误处理** | `Result<T, CryptoError>` | `i32` 错误码 |

**问题**：任何 Argon2id 参数调整、AES-GCM 格式变更、或内存安全策略更新，都需要**同步修改两个仓库**，否则 已废弃与 Flutter 客户端行为不一致。

## Tauri 统一后的目标架构

```
┌─────────────────────────────────────┐
│  Tauri 前端（WebView）               │
│  不持有任何密钥，不执行任何加密        │
└─────────────┬───────────────────────┘
              │ IPC (invoke)
┌─────────────▼───────────────────────┐
│  Tauri 后端（Rust）                  │
│  ┌─────────────────────────────┐   │
│  │  crypto::kdf                │   │
│  │  - derive_key()             │   │
│  │  - generate_salt()          │   │
│  │  - KdfPreset { Dev, Prod }  │   │
│  ├─────────────────────────────┤   │
│  │  crypto::cipher             │   │
│  │  - encrypt() -> SOLO v2     │   │
│  │  - decrypt() -> plaintext   │   │
│  │  - encrypt_file() -> v3     │   │
│  │  - decrypt_file() -> v3     │   │
│  ├─────────────────────────────┤   │
│  │  crypto::secure_mem         │   │
│  │  - SecureBuffer (Zeroizing) │   │
│  │  - mlock / munlock          │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**单一 Truth Source**：所有密码学操作集中在一个 Rust crate 中，前端通过 IPC 调用，已废弃不再需要 ``。

## 接口契约

### 对上（L1/L3）提供的接口

| 接口 | 输入 | 输出 | 约束 |
|------|------|------|------|
| `derive_key(password, salt) -> key` | password: `&str`, salt: `&[u8; 32]` | `Zeroizing<[u8; 32]>` | 线程安全 |
| `generate_salt() -> salt` | — | `[u8; 32]` | CSPRNG |
| `encrypt(plaintext, key) -> ciphertext` | plaintext: `&[u8]`, key: `&[u8; 32]` | `Vec<u8>` (SOLO v2) | nonce 随机生成 |
| `decrypt(ciphertext, key) -> plaintext` | ciphertext: `&[u8]`, key: `&[u8; 32]` | `Vec<u8>` | 失败返回 DecryptFailed |
| `encrypt_file(src, dst, key, progress, cancel)` | 文件路径 + key | `Result<()>` | 支持取消 |
| `decrypt_file(src, dst, key, progress, cancel)` | 文件路径 + key | `Result<()>` | 支持取消 |
| `create_verification_token(key)` | key: `&[u8; 32]` | `Vec<u8>` | 固定明文 |
| `verify_password(password, salt, token)` | password, salt, token | `Result<bool>` | 常数时间比较 |
| `generate_biometric_credential()` | — | `String` (base64) | CSPRNG |

### 安全约束

1. **密钥不出后端**：`[u8; 32]` 类型的密钥永远不通过 IPC 传递到前端
2. **密码不缓存**：用户输入的密码在验证后立即从内存中擦除
3. **Salt 公开可存储**：Salt 不需要保密，可明文存储在 `config.json` 中
4. **Nonce 永不重复**：每次加密使用新的随机 nonce

## 从零开始实现顺序

1. **创建 `crypto` crate**（Rust）
   - 定义 `CryptoError` 枚举
   - 集成 `argon2` + `aes_gcm` + `zeroize` + `subtle` + `rand`

2. **实现 KDF 模块**
   - `derive_key()` — Argon2id，返回 `Zeroizing<[u8; 32]>`
   - `generate_salt()` — 32 字节随机
   - `KdfPreset::Dev` / `KdfPreset::Prod` — 预设参数

3. **实现 Cipher 模块**
   - `encrypt()` / `decrypt()` — SOLO blob v2
   - `encrypt_file()` / `decrypt_file()` — SOLO blob v3 流式
   - nonce 生成：12 字节随机（`rand::thread_rng().gen::<[u8; 12]>()`）

4. **实现 Secure Memory 模块**
   - `SecureBuffer<T>` — `Zeroizing` 包装
   - `mlock_memory()` / `munlock_memory()` — Unix/Windows 分别实现

5. **实现 Verification 模块**
   - `create_verification_token()`
   - `verify_password()` — 使用 `subtle::ConstantTimeEq`

6. **配置 Cargo.toml**
   - `[profile.release]`：opt-level="z", strip=true, lto=true, panic="abort"

7. **单元测试**
   - KDF：不同密码/相同 Salt → 不同 key；相同密码/相同 Salt → 相同 key
   - AES：加密 → 解密 → 原文一致；篡改密文 → 解密失败
   - 流式：1MB/100MB/1GB 文件加密解密，校验 SHA-256 一致
   - 取消：中途取消，dst 文件不存在或大小为 0
   - Zeroize：验证内存确实被覆盖

8. **暴露 Tauri 命令**
   - 注意：**不暴露 `derive_key` 给前端**，仅内部使用
   - 可暴露：`verify_password`（但 password 只存在于一次 invoke 调用中）
   - 其他命令由 L1/L3 服务层间接调用

## 测试要点

| 测试目标 | 测试方法 | 预期结果 |
|---------|---------|---------|
| **KDF 确定性** | 相同密码 + 相同 Salt → 派生 10 次 | 每次结果完全相同 |
| **KDF 敏感性** | 相同密码 + 不同 Salt | 结果完全不同 |
| **KDF 参数** | Dev (8MiB/2iter) vs Prod (64MiB/3iter) | Prod 显著更慢但更安全 |
| **AES 往返** | encrypt → decrypt | 解密后与原文逐字节相同 |
| **AES 篡改检测** | 修改密文中间 1 字节 → decrypt | 返回 `DecryptFailed` |
| **AES 短密文** | 输入 10 字节密文 → decrypt | 返回 `InvalidCiphertext` |
| **流式大文件** | 加密 500MB 文件 → 解密 → SHA-256 对比 | 哈希值完全相同 |
| **流式取消** | 加密 500MB，中途创建 cancelFile | 加密中断，dst 文件不存在 |
| **Zeroize** | 创建 `Zeroizing<Vec<u8>>`，drop 后读取内存 | 内存区域全为 0 |
| **常数时间** | 测量正确密码和错误密码的验证时间 | 时间差 < 1ms（统计意义上不可区分）|
| **验证令牌** | 正确密码 → verify → true；错误密码 → false | 常数时间返回 |
| **nonce 唯一性** | 加密 10000 条消息 | 无 nonce 重复（概率可忽略）|
