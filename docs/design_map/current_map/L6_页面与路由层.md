# L6 页面与路由层

> **层级定位**：完整的用户界面页面，组装 L5 组件并绑定 L4 状态。每个页面对应一个独立的路由，是用户直接交互的载体。
>
> **核心原则**：页面只负责组装组件和绑定状态，不实现业务逻辑；页面级状态通过 URL 参数传递；敏感页面需要额外的密码验证。
>
> **Tauri 迁移方向**：重写为 Web 前端页面，使用前端路由库（React Router / Vue Router）。Tauri 后端只暴露命令，不控制路由。

## L6.1 路由系统

### 1.1 当前实现：GoRouter

**文件**：`lib/core/router/app_router.dart`

```dart
final GoRouter router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(path: '/', builder: (_, __) => const AppBootstrap()),
    GoRoute(path: '/login', builder: (_, __) => const LoginPage()),
    GoRoute(path: '/home', builder: (_, __) => const HomePage()),
    GoRoute(
      path: '/objects',
      builder: (_, __) => const ObjectWorkspacePage(),
      routes: [
        GoRoute(path: ':id', builder: (_, state) => ObjectWorkspacePage(objectId: state.pathParameters['id'])),
        GoRoute(path: 'edit', builder: (_, __) => const ObjectEditorPage()),
        GoRoute(path: 'edit/:id', builder: (_, state) => ObjectEditorPage(objectId: state.pathParameters['id'])),
      ],
    ),
    // ... 更多路由
  ],
  redirect: (context, state) {
    // 路由守卫：未解锁时重定向到登录页
    final authState = ref.read(authNotifierProvider).value?.state;
    if (authState != AuthState.unlocked && state.uri.path != '/login') {
      return '/login';
    }
    return null;
  },
);
```

### 1.2 Tauri 替代方案

**React**：`react-router-dom`
```typescript
// App.tsx
import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom';

function App() {
  const { state: authState } = useAuthStore();
  
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<BootstrapPage />} />
        <Route path="/login" element={<LoginPage />} />
        <Route path="/home" element={
          authState === 'unlocked' ? <HomePage /> : <Navigate to="/login" />
        } />
        <Route path="/objects" element={
          authState === 'unlocked' ? <ObjectWorkspacePage /> : <Navigate to="/login" />
        } />
        <Route path="/objects/:id" element={
          authState === 'unlocked' ? <ObjectWorkspacePage /> : <Navigate to="/login" />
        } />
        {/* ... 更多路由 */}
      </Routes>
    </BrowserRouter>
  );
}
```

## L6.2 启动与引导页面

### BootstrapPage

**职责**：
- 显示启动画面（Logo + 加载指示器）
- 后台执行初始化序列（见 L7）
- 初始化完成后自动跳转到 `/home` 或 `/login`

**状态**：
```typescript
interface BootstrapState {
  phase: 'initializing' | 'ready' | 'error';
  progress: number;      // 0-100
  errorMessage?: string;
}
```

**初始化阶段**：
1. Liquid Glass shader 预热（0-10%）
2. Rust FFI 初始化（10-40%）
3. 原生通道注册（40-50%）
4. 用户指南索引加载（50-60%，后台）
5. OCR 引擎预热（60-80%，后台）
6. 临时文件清理（80-90%，后台）
7. 安全设置加载（90-100%，后台）

**状态绑定**：
- `unifiedObjectCacheProvider` — 预计算缓存

## 从零开始实现顺序

1. **路由系统**
   - 定义所有路由路径
   - 实现路由守卫（解锁检查、敏感验证检查）
   - 配置懒加载（代码分割）

2. **BootstrapPage**
   - 启动画面 + 初始化序列
   - 错误处理

3. **LoginPage**
   - 密码输入 + 生物识别
   - 账户列表 + 创建账户
   - 法律文档弹窗

4. **HomePage**
   - Dashboard 布局
   - 快捷操作 + 安全提醒 + 页面树

5. **ObjectWorkspacePage + ObjectEditorPage**
   - 对象层级浏览
   - 通用编辑器（动态表单）

6. **分类页面（Profile/Travel/Financial/Professional）**
   - 复用 ObjectCategoryPage 组件

7. **功能页面（Search/Trash/OperationLog）**
   - 搜索 + 回收站 + 操作日志

8. **设置页面（Settings + 子页面）**
   - 主设置页 + Security + Sensitivity + DataManagement + ExportImport

9. **高级功能页面**
   - PluginDashboard / Sync / LlmChat / LlmConfig / LlmStats

10. **扫描流程页面**
    - Config → Progress → Preview → Result

11. **模板页面**
    - SectionTemplatePage / PageEditorPage
