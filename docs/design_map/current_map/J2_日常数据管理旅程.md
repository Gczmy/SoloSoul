# J2 日常数据管理旅程

> **旅程定位**：用户日常使用最频繁的核心流程——在首页浏览数据、进入分类查看详情、创建/编辑对象、搜索信息。这是 SoloSoul 的"主航道"。
>
> **核心目标**：让用户能够高效地查看、添加、修改自己的个人信息，支持从简单文本到复杂文档附件的完整数据管理。
>
> **涉及页面**：Home → ObjectWorkspace → ObjectEditor → Profile/Travel/Financial/Professional → Search
>
> **状态依赖**：L3 Unified Object 服务、L4 对象状态、L5 数据展示组件

### 1.3 快捷操作（Quick Actions）

**数据来源**：用户自定义的快捷入口，存储在 `UserPreferencesService`

**默认快捷操作**：
- 护照
- 银行卡
- 常用联系地址
- 税号

**交互**：
- 点击 → 直接跳转到对应对象的编辑器
- 长按/右键 → 显示操作菜单（删除、重排序）
- 点击 + → 打开 `AddQuickActionDialog`，选择要添加快捷入口的对象

### 1.4 安全提醒（Security Items）

**触发条件**：扫描所有对象，检测即将过期（≤ 90 天）的文档

**检测字段**：
- `passport.expiryDate`
- `visa.expiryDate`
- `payment_card.expiryDate`
- `identity_document.expiryDate`

**显示规则**：
- 30 天内过期：红色高亮
- 31-90 天内过期：橙色提醒
- 点击 → 跳转到对应对象编辑器

### 1.5 页面树（Page Tree）

**数据来源**：`UnifiedObjectCache.rootObjects` 中 `typeId == 'page'` 的对象

**交互**：
- 点击页面名 → 展开/折叠子分区
- 点击子分区 → 跳转到对应分类页面
- 点击编辑按钮 → 进入 `PageEditor` 内联编辑
- 拖拽排序 → 调整页面顺序

### 5.3 搜索逻辑

```typescript
function search(query: string, filter: SearchFilter): SearchResult[] {
  const allObjects = getAllObjects();
  const results = [];
  
  for (const obj of allObjects) {
    // 类型过滤
    if (filter.type && !matchesType(obj, filter.type)) continue;
    
    // 名称匹配
    const nameScore = fuzzyMatch(obj.name, query);
    
    // 属性值匹配
    let propertyScore = 0;
    for (const [key, prop] of Object.entries(obj.properties)) {
      const value = prop.value?.toString() || '';
      const score = fuzzyMatch(value, query);
      if (score > propertyScore) propertyScore = score;
    }
    
    const totalScore = nameScore * 2 + propertyScore;
    if (totalScore > 0) {
      results.push({ object: obj, score: totalScore });
    }
  }
  
  return results.sort((a, b) => b.score - a.score);
}
```

```
         │
         ├──→ 点击对象 ──→ ObjectWorkspace（子级）/ ObjectEditor
         └──→ 点击 + ──→ ObjectEditor（创建模式，parentId=当前对象）
```

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 对象保存失败（磁盘满） | 显示错误 SnackBar，保留表单数据，允许重试 |
| 附件上传过大 | 提示"文件超过 50MB，将使用流式加密"，显示进度 |
| 附件加密失败 | 提示"加密失败，请重试"，保留文件选择 |
| 删除对象时网络同步中 | 提示"正在同步，请稍后再试" |
| 搜索无结果 | 显示 SearchEmptyState，提示"尝试其他关键词" |
| 字段历史加载失败 | 提示"历史记录不可用"，隐藏历史区域 |
| OCR 识别失败 | 提示"未能识别文本，请检查图片质量" |

## 从零实现顺序

1. **ObjectEditorPage（核心，最复杂）**
   - 动态表单渲染（8 种字段类型）
   - 字段敏感度标签
   - 敏感字段掩码/揭示
   - 附件管理（上传/预览/删除）
   - 字段历史展开
   - OCR 扫描入口
   - 防抖保存

2. **ObjectWorkspacePage**
   - 对象卡片列表
   - 层级浏览（parent-child）
   - 自动返回逻辑
   - 重排序拖拽

3. **分类页面（ObjectCategoryPage）**
   - 默认分区展示
   - 自定义条目列表
   - 分区模板选择

4. **HomePage**
   - 快捷操作瓷砖
   - 安全提醒检测
   - 页面树（可编辑）

5. **SearchPage**
   - 搜索输入 + 实时结果
   - 类型过滤 Tab
   - 结果排序
   - 空状态

6. **路由与导航**
   - 对象层级路由 `/objects/:id`
   - 编辑器路由 `/objects/edit/:id`
   - 搜索结果跳转
