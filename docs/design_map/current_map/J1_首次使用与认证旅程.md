# J1 首次使用与认证旅程

> **旅程定位**：用户从安装应用到成功进入首页的完整首次体验流程。这是用户与 SoloSoul 的"第一印象"，决定了产品的可用性感知和信任建立。
>
> **核心目标**：让新用户在 2 分钟内完成首次设置，理解零知识安全模型，建立对本地加密存储的信任。
>
> **涉及页面**：Bootstrap → (法律文档) → Login → Home（首次引导）
>
> **状态依赖**：L0 平台层（初始化）、L2 加密层（KDF）、L3 账户服务、L4 认证状态

**关键分支**：
- **首次使用（无账户）**：Bootstrap → 法律文档 → Login（创建账户）→ Home
- **已有账户**：Bootstrap → 尝试生物识别解锁 → 成功则直接 Home，失败则 Login
- **账户列表展开**：Login 页面可展开显示所有本地账户，点击切换

| P1-5 | OCR 引擎预热 | 500ms | 进度条 60-80%（后台） | 首次使用时重试 |
| P2-6 | 临时文件清理 | 100ms | 进度条 80-90%（后台） | 静默忽略 |
| P2-7 | 安全设置加载 | 50ms | 进度条 90-100%（后台） | 使用默认值 |

### 1.4 路由跳转逻辑

```typescript
function onBootstrapComplete() {
  const accounts = await listAccounts();
  
  if (accounts.length === 0) {
    // 首次使用：跳转到法律文档（强制）
    navigate('/legal');
  } else if (biometricsEnabled && await isBiometricAvailable()) {
    // 尝试生物识别快捷解锁
    const success = await authenticateBiometric();
    if (success) {
      navigate('/home');
    } else {
      navigate('/login');
    }
  } else {
    // 有账户但无生物识别：跳登录
    navigate('/login');
  }
}
```

### 3.4 密码验证流程

```
用户输入密码 → 点击解锁
    │
    ▼
调用 L3.2 unlock_vault(accountId, password)
    │
    ├──→ L2.1 derive_key(password, salt) → key
    │
    ├──→ L2.4 verify_password(password, salt, token) → bool
    │       │
    │       ├──→ 失败：返回 "密码不正确"
    │       │
    │       └──→ 成功：继续
    │
    ├──→ L1.1 VaultStore::open(path, accountId, key)
    │
    ├──→ L1.3 ProfileStorageService::loadProfile(accountId)
    │       │
    │       ├──→ 有 Profile → 加载到 L4
    │       └──→ 无 Profile → 创建空 Profile
    │
    ├──→ L3.1 update_last_accessed(accountId)
    │
    └──→ 成功：navigate('/home')
```

### 3.5 创建账户流程

```
用户输入：名称、密码、确认密码、密码提示
    │
    ▼
前端验证：
    - 名称非空
    - 密码 ≥ 8 位
    - 密码 = 确认密码
    - 密码强度 ≥ "中"
    │
    ▼
调用 L3.1 create_account(name, password)
    │
    ├──→ L2.1 generate_salt() → salt
    ├──→ L2.1 derive_key(password, salt) → key
    ├──→ L2.4 create_verification_token(key) → token
    ├──→ L1.1 VaultStore::init(path, accountId)
    ├──→ L1.1 save_config(salt, token)
    └──→ 创建空 Profile
    │
    ▼
自动解锁 → navigate('/home')
```

### 3.6 生物识别解锁流程

```
用户点击生物识别按钮
    │
    ▼
调用 BiometricService.authenticate()
    │
    ├──→ 系统生物识别弹窗（Touch ID / Face ID）
    │       │
    │       ├──→ 用户取消 → 保持登录页
    │       └──→ 验证成功 → 继续
    │
    ▼
从安全存储读取 biometric_credential
    │
    ▼
调用 Rust 验证 credential（不暴露 Vault 密钥）
    │
    ├──→ 验证成功 → 解锁 Vault → navigate('/home')
    └──→ 验证失败 → 提示使用密码登录
```

## 异常处理

| 异常场景 | 页面 | 处理方式 |
|---------|------|---------|
| Rust FFI 初始化失败 | Bootstrap | 显示错误页，建议重启或重装 |
| 动态库文件缺失 | Bootstrap | 显示具体缺失文件路径，提供下载链接 |
| 密码连续错误 5 次 | Login | 显示"忘记密码？"提示（仅可删除账户重建） |
| 生物识别硬件不可用 | Login | 隐藏生物识别按钮，仅显示密码登录 |
| 生物识别验证失败 | Login | 提示"请使用密码登录"，记录到操作日志 |
| 创建账户时 Vault 已存在 | Login | 提示"该账户已存在"，引导登录 |
| 备份恢复文件损坏 | Login | 提示"备份文件损坏，请选择其他备份" |
| 法律文档网络加载失败 | 法律文档 | 显示内嵌离线版本 |

## 性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **启动到可操作** | < 3 秒 | Bootstrap 到首页可交互 |
| **启动画面显示** | ≥ 1.5 秒 | 避免闪烁，即使初始化更快也保持最小显示时间 |
| **解锁响应** | < 500ms | 密码输入到进入首页 |
| **生物识别解锁** | < 1 秒 | 点击按钮到进入首页 |
| **创建账户** | < 3 秒 | 点击创建到进入首页 |
| **密码验证反馈** | < 100ms | 点击解锁到显示错误/成功 |

## 从零实现顺序

1. **Bootstrap 页面**
   - Logo 动画（CSS/Canvas）
   - 进度指示器
   - 分阶段初始化框架
   - 错误状态页面

2. **法律文档页面**
   - TabBar（隐私政策/服务条款）
   - 长文本滚动容器
   - Checkbox + 继续按钮联动
   - 不同意确认对话框

3. **Login 页面（核心）**
   - 背景动画
   - 密码输入框（显隐切换）
   - 错误状态提示
   - 账户列表（可展开/折叠）
   - 生物识别按钮（条件渲染）
   - 创建账户表单（验证逻辑）
   - 密码强度指示器
   - 备份恢复提示（条件显示）

4. **路由守卫**
   - 首次使用检测
   - 法律同意检查
   - Vault 状态检查
   - 自动跳转逻辑

5. **Home 首次引导**
   - 空状态组件
   - 功能导览气泡（可选）
   - 安全设置提醒
