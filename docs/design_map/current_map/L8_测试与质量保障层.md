# L8 测试与质量保障层

> **层级定位**：覆盖 L0-L7 各层的自动化测试，确保功能正确性、重构安全性和回归防护。测试是架构的"安全网"，Tauri 迁移时必须先让测试通过，再修改实现。
>
> **核心原则**：每个功能必须有对应测试；测试不依赖外部状态（使用临时目录/内存数据库）；Flutter 测试分单元/Widget/集成三级；Rust 测试使用 `cargo test`。
>
> **Tauri 迁移方向**：Rust 测试保留并增强；Dart 测试迁移为前端测试（Vitest + React Testing Library + Playwright E2E）。

### 2.2 Rust 测试约定（native/）

- **仅使用标准库 `testing`**，不引入 testify、mock 框架
- **表驱动测试**：
  ```go
  func TestDeriveKey(t *testing.T) {
      tests := []struct {
          name     string
          password string
          salt     []byte
          wantErr  bool
      }{
          {"valid", "password123", makeSalt(), false},
          {"empty password", "", makeSalt(), true},
          {"short salt", "password", []byte("short"), true},
      }
      for _, tt := range tests {
          t.Run(tt.name, func(t *testing.T) {
              _, err := DeriveKey(tt.password, tt.salt)
              if (err != nil) != tt.wantErr {
                  t.Errorf("DeriveKey() error = %v, wantErr %v", err, tt.wantErr)
              }
          })
      }
  }
  ```
- **文件系统测试**：统一使用 `t.TempDir()`
- **错误比较**：使用精确错误变量比对（`err != ErrVaultLocked`），不使用字符串包含判断

### 4.2 单元测试示例（Vitest）

```typescript
// stores/authStore.test.ts
import { describe, it, expect, beforeEach } from 'vitest';
import { useAuthStore } from './authStore';

describe('AuthStore', () => {
  beforeEach(() => {
    useAuthStore.setState({ state: 'locked', selectedAccountId: null });
  });

  it('should transition from locked to unlocked', async () => {
    const store = useAuthStore.getState();
    await store.unlockVault('acc_xxx', 'password123');
    expect(useAuthStore.getState().state).toBe('unlocked');
  });

  it('should wipe sensitive state on lock', () => {
    const store = useAuthStore.getState();
    store.lockVault();
    expect(useAuthStore.getState().state).toBe('locked');
    expect(useAuthStore.getState().profile).toBeNull();
  });
});
```

### 4.4 E2E 测试示例（Playwright）

```typescript
// e2e/vault-lifecycle.spec.ts
import { test, expect } from '@playwright/test';

test('vault full lifecycle', async ({ page }) => {
  // 1. 启动应用
  await page.goto('/');
  
  // 2. 等待引导完成
  await page.waitForURL('/login');
  
  // 3. 创建账户
  await page.click('text=Create Account');
  await page.fill('[name="accountName"]', 'Test Account');
  await page.fill('[name="password"]', 'password123');
  await page.fill('[name="confirmPassword"]', 'password123');
  await page.click('text=Create');
  
  // 4. 等待解锁并进入首页
  await page.waitForURL('/home');
  expect(await page.textContent('h1')).toContain('SoloSoul');
  
  // 5. 创建一个对象
  await page.click('text=Add Object');
  await page.fill('[name="name"]', 'My Passport');
  await page.selectOption('[name="type"]', 'passport');
  await page.click('text=Save');
  
  // 6. 验证对象出现在列表中
  await expect(page.locator('text=My Passport')).toBeVisible();
  
  // 7. 锁定 Vault
  await page.click('[aria-label="Lock Vault"]');
  await page.waitForURL('/login');
  
  // 8. 重新解锁
  await page.fill('[name="password"]', 'password123');
  await page.click('text=Unlock');
  await page.waitForURL('/home');
  
  // 9. 验证对象仍然存在
  await expect(page.locator('text=My Passport')).toBeVisible();
});
```

## L8.5 CI/CD 质量门

### 5.1 当前 CI/CD 配置

#### `ci_cd.yml`（完整流水线）

| Job | Runner | 执行内容 | 触发条件 |
|-----|--------|---------|---------|
| `rust-test` | ubuntu-latest | `flutter/native` 的 `cargo test` | push/PR |
| `dart-unit-test` | ubuntu-latest | `flutter test test/unit/` | push/PR |
| `widget-test` | ubuntu-latest | `flutter test test/widget/` | push/PR |
| `integration-test` | macos-latest | 构建 Rust native lib → 集成测试 | push/PR |
| `release` | macos-latest | Release 构建 → DMG 打包 → Draft Pre-release | push master |

#### `pr_check.yml`（快速反馈）

| Job | 执行内容 | 目标 |
|-----|---------|------|
| `rust-check` | `cargo fmt --check` + `cargo clippy -- -D warnings` | Rust 代码规范 |
| `dart-check` | `dart analyze --fatal-infos --fatal-warnings` | Dart 代码规范 |
| `test` | Rust 测试 + Dart 单元测试 + Widget 测试 | 功能正确性 |

### 5.2 Tauri CI/CD 目标配置

```yaml
# .github/workflows/tauri_ci.yml
name: Tauri CI

on: [push, pull_request]

jobs:
  test-rust:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test --manifest-path src-tauri/Cargo.toml
      - run: cargo fmt --check --manifest-path src-tauri/Cargo.toml
      - run: cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings

  test-frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run lint
      - run: npm run test:unit
      - run: npm run test:component

  e2e:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: npm ci
      - run: npx playwright install
      - run: npm run test:e2e

  build:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: npm ci
      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
