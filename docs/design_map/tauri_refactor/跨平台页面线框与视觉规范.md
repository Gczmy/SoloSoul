# 跨平台页面线框与视觉规范

> 状态：设计草案  
> 适用范围：Tauri + Rust 重构后的 SoloSoul 全平台客户端  
> 配套文档：《跨平台 UI 设计系统.md》

---

## 文档说明

本文档以**文本线框 + 视觉描述**的方式，定义 SoloSoul 核心页面在五大平台（macOS / iOS / Windows / Linux / Android）上的具体呈现差异。每个页面包含：

1. **信息架构** — 元素层级与布局比例
2. **平台材质差异** — 各平台使用何种玻璃/云母/回退材质
3. **交互细节** — 悬停、按下、滚动、空状态
4. **响应式断点** — 桌面三栏 → 平板两栏 → 手机单栏

**材质映射：**

| 区域 | macOS 15+ | macOS 14- | Windows 11 | Windows 10 | Linux |
|------|-----------|-----------|------------|------------|-------|
| Title Bar | Liquid Glass | Acrylic | Mica | Solid | Solid |
| Icon Rail | Liquid Glass | Acrylic | Mica Alt | Solid+Border | Solid+Border |

**折叠行为：**
- 点击 `[↔]` 或按 `Cmd/Ctrl + \`，Object List 收起/展开
- 收起后 Icon Rail 变宽为 72px，显示图标 + 文字标签
- 窗口宽度 < 800px 时自动收起 Object List，点击 Icon Rail 弹出临时抽屉

## 2. 页面详解

### 2.1 启动页 / 解锁页

**这是用户每次打开应用的第一印象，必须传递"安全且温暖"。**

#### 桌面端（macOS / Windows / Linux）

```
┌─────────────────────────────────────────────────┐

│                    (Logo)                       │
│                SoloSoul 独灵                     │
│            独奏生命数据，重塑数字原点              │
│                                                 │
│         ┌─────────────────────────┐             │
│         │  🔒 输入主密码          │             │
│         │  ••••••••••••••        │             │
│         └─────────────────────────┘             │
│                                                 │
│              [  解锁 SoloSoul  ]                │
│                                                 │
│         或使用 Touch ID / Windows Hello        │
│              👆 轻触传感器                       │
│                                                 │
│         ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━          │
│         生物识别已启用 · 零知识加密              │
│                                                 │
└─────────────────────────────────────────────────┘
```

**各平台材质：**

| 平台 | 背景 | 密码输入框 | 解锁按钮 |
|------|------|-----------|---------|
| macOS 15+ | Liquid Glass 全屏（轻微折射，背景为品牌色渐变 `#FAFAF8` → `#F0F0EA`） | Glass blur(40px) + 高光边缘 | 主按钮，悬停时微光扩散 |
| macOS 14- | 纯色 `#FAFAF8` + 大面积投影装饰 | Acrylic blur(25px) | 标准主按钮 |
| Windows 11 | Mica（桌面壁纸透上来）| 纯白 80% + 轻度模糊 | Mica Alt 质感按钮 |
| Windows 10 | 纯色 + 几何装饰图案 | Solid | Solid |
| Linux | 纯色 + 品牌渐变装饰 | Solid + 边框 | Solid |

**动效：**
- 页面加载：Logo 从 0.8 缩放到 1.0，透明度 0→1，时长 400ms，spring 缓动
- 密码错误：输入框水平抖动（translateX ±8px，3 次），背景短暂泛红
- 解锁成功：整个界面向上滑出（translateY -100%），主界面从下方滑入，无缝衔接

**Warp 温暖感体现：**
- 密码框不使用锐利的直角边框，而是 12px 圆角 + 内阴影营造"凹陷"质感
- 错误反馈不用红色弹窗，而是输入框边框变红 + 底部温和提示"密码似乎不对，请再试一次"
- 底部生物识别图标使用暖灰色调，而非冷灰

- **照片区域**：护照照片默认低分辨率 + 轻微模糊，揭示后加载高清版本

## 5. 设计验证原型建议

为确保跨平台视觉一致性，建议按以下顺序制作原型：

1. **高保真原型（Figma）**：
   - 先完成 macOS 版本（Liquid Glass 最复杂）
   - 再完成 Windows 版本（Mica 材质差异）
   - 最后完成 iOS/Android 版本（移动端适配）

2. **交互原型**：
   - 解锁流程（密码错误、生物识别、解锁成功过渡）
   - 敏感内容揭示流程（点击 → 验证 → 模糊渐隐）
   - 对象编辑器（表单验证、拖拽上传）

3. **前端原型（Tauri）**：
   - P0：纯色回退版本（所有平台先用纯色跑通功能）
   - P1：CSS backdrop-filter 版本（验证模糊性能）
   - P2：平台特化版本（Mica、Liquid Glass）
