## Zustand 选型确认

### 为什么不是 Redux / Context API / Jotai

| 方案 | 排除原因 |
|------|---------|
| Redux | 样板代码过多；SoloSoul 不需要时间旅行调试 |
| Context API | 频繁渲染问题；Context 拆分复杂 |
| Jotai | 学习曲线较陡；团队无经验 |
| Valtio | 代理式管理在复杂场景下响应式不够精确 |
| Recoil | Meta 已放弃维护；未来不确定 |

### Zustand 核心优势

```typescript
// 极简 API
const useStore = create((set, get) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
}));

// 使用
const count = useStore((state) => state.count);
```

- **无 Provider**: 不需要包裹组件树
- **细粒度订阅**: 组件只订阅需要的字段
- **TypeScript 完美支持**: 类型推导完整
- **Immer 集成**: 可变语法，不可变数据
- **中间件丰富**: persist, devtools, subscribeWithSelector

## authStore（认证状态）

### 职责

- 管理登录/登出状态
- 管理当前账户信息
- 处理 Vault 解锁/锁定
- 监听 Vault 锁定事件（自动跳转）

### 实现

```typescript
// src/stores/authStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { listen } from '@tauri-apps/api/event';
import { commands } from '@/lib/ipc';
import type { AccountInfo } from '@/types';

interface AuthState {
  // 状态
  isAuthenticated: boolean;
  isLoading: boolean;
  currentAccount: AccountInfo | null;
  error: string | null;

  // 动作
  checkHasAccount: () => Promise<boolean>;
  bootstrap: (name: string, password: string) => Promise<void>;
  login: (accountId: string, password: string) => Promise<void>;
  logout: () => Promise<void>;
  clearError: () => void;
}

export const useAuthStore = create<AuthState>()(
  immer((set, get) => ({
    isAuthenticated: false,
    isLoading: false,
    currentAccount: null,
    error: null,

    checkHasAccount: async () => {
      return await commands.authCheckHasAccount();
    },

    bootstrap: async (name, password) => {
      set({ isLoading: true, error: null });
      try {
        const account = await commands.authBootstrap(name, password);
        set({ isAuthenticated: true, currentAccount: account });
      } catch (err) {
        set({ error: String(err) });
      } finally {
        set({ isLoading: false });
      }
    },

    login: async (accountId, password) => {
      set({ isLoading: true, error: null });
      try {
        const account = await commands.authLogin(accountId, password);
        set({ isAuthenticated: true, currentAccount: account });
      } catch (err) {
        set({ error: String(err) });
      } finally {
        set({ isLoading: false });
      }
    },

    logout: async () => {
      await commands.authLogout();
      set({ isAuthenticated: false, currentAccount: null });
    },

    clearError: () => set({ error: null }),
  }))
);

// 监听 Vault 锁定事件（全局）
let unsubLock: (() => void) | null = null;

export function initAuthEventListeners() {
  listen('vault-locked', () => {
    useAuthStore.getState().logout();
  }).then((unlisten) => {
    unsubLock = unlisten;
  });
}

export function cleanupAuthEventListeners() {
  unsubLock?.();
}
```

### 在组件中使用

```tsx
// src/pages/auth/LoginPage.tsx
import { useAuthStore } from '@/stores/authStore';

function LoginPage() {
  const { login, isLoading, error, clearError } = useAuthStore(
    (state) => ({
      login: state.login,
      isLoading: state.isLoading,
      error: state.error,
      clearError: state.clearError,
    })
  );

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    clearError();
    await login(accountId, password);
  };

  return (
    <form onSubmit={handleSubmit}>
      {error && <div className="error">{error}</div>}
      <button type="submit" disabled={isLoading}>
        {isLoading ? '登录中...' : '登录'}
      </button>
    </form>
  );
}
```

## vaultStore（Vault 状态）

### 职责

- Vault 状态查询（Locked/Unlocked）
- 账户列表管理
- 密码修改
- 账户删除

### 实现

```typescript
// src/stores/vaultStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { commands } from '@/lib/ipc';
import type { AccountSummary, VaultState } from '@/types';

interface VaultStoreState {
  vaultState: VaultState;
  accounts: AccountSummary[];
  isLoading: boolean;
  error: string | null;

  loadAccounts: () => Promise<void>;
  unlock: (accountId: string, password: string) => Promise<void>;
  lock: () => Promise<void>;
  changePassword: (oldPassword: string, newPassword: string) => Promise<void>;
  deleteAccount: (accountId: string, password: string) => Promise<void>;
  setDefaultAccount: (accountId: string) => Promise<void>;
}

export const useVaultStore = create<VaultStoreState>()(
  immer((set, get) => ({
    vaultState: 'locked',
    accounts: [],
    isLoading: false,
    error: null,

    loadAccounts: async () => {
      set({ isLoading: true });
      try {
        const accounts = await commands.vaultListAccounts();
        set({ accounts, isLoading: false });
      } catch (err) {
        set({ error: String(err), isLoading: false });
      }
    },

    unlock: async (accountId, password) => {
      set({ isLoading: true, error: null });
      try {
        await commands.vaultUnlock(accountId, password);
        set({ vaultState: 'unlocked', isLoading: false });
      } catch (err) {
        set({ error: String(err), isLoading: false });
      }
    },

    lock: async () => {
      await commands.vaultLock();
      set({ vaultState: 'locked' });
    },

    changePassword: async (oldPassword, newPassword) => {
      set({ isLoading: true, error: null });
      try {
        await commands.vaultChangePassword(oldPassword, newPassword);
        set({ isLoading: false });
      } catch (err) {
        set({ error: String(err), isLoading: false });
      }
    },

    deleteAccount: async (accountId, password) => {
      set({ isLoading: true, error: null });
      try {
        await commands.vaultDeleteAccount(accountId, password);
        await get().loadAccounts();
        set({ isLoading: false });
      } catch (err) {
        set({ error: String(err), isLoading: false });
      }
    },

    setDefaultAccount: async (accountId) => {
      await commands.vaultSetDefaultAccount(accountId);
      await get().loadAccounts();
    },
  }))
);
```

## profileStore（Profile 数据）

### 职责

- Profile 数据缓存
- CRUD 操作
- 防抖保存
- 字段历史

### 实现

```typescript
// src/stores/profileStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { commands } from '@/lib/ipc';
import type { ProfileData, SectionData, FieldValue, FieldHistoryEntry } from '@/types';

interface ProfileStoreState {
  profile: ProfileData | null;
  isLoading: boolean;
  isSaving: boolean;
  error: string | null;
  lastSavedAt: Date | null;

  loadProfile: (accountId: string) => Promise<void>;
  updateProfile: (data: Partial<ProfileData>) => Promise<void>;
  updateSection: (sectionType: string, data: SectionData) => Promise<void>;
  updateField: (sectionType: string, fieldKey: string, value: FieldValue) => Promise<void>;
  getFieldHistory: (sectionType: string, fieldKey: string) => Promise<FieldHistoryEntry[]>;
  clear: () => void;
}

export const useProfileStore = create<ProfileStoreState>()(
  immer((set, get) => ({
    profile: null,
    isLoading: false,
    isSaving: false,
    error: null,
    lastSavedAt: null,

    loadProfile: async (accountId) => {
      set({ isLoading: true });
      try {
        const profile = await commands.profileGet(accountId);
        set({ profile, isLoading: false });
      } catch (err) {
        set({ error: String(err), isLoading: false });
      }
    },

    updateProfile: async (data) => {
      const current = get().profile;
      if (!current) return;

      // 乐观更新
      set((state) => {
        state.profile = { ...state.profile!, ...data };
        state.isSaving = true;
      });

      try {
        await commands.profileUpdate({ ...current, ...data });
        set({ isSaving: false, lastSavedAt: new Date() });
      } catch (err) {
        // 回滚
        set((state) => {
          state.profile = current;
          state.isSaving = false;
          state.error = String(err);
        });
      }
    },

    updateField: async (sectionType, fieldKey, value) => {
      const current = get().profile;
      if (!current) return;

      // 乐观更新
      set((state) => {
        if (!state.profile!.sectionData) {
          state.profile!.sectionData = {};
        }
        if (!state.profile!.sectionData[sectionType]) {
          state.profile!.sectionData[sectionType] = {};
        }
        state.profile!.sectionData[sectionType][fieldKey] = value;
        state.isSaving = true;
      });

      try {
        await commands.profileUpdateField(current.accountId, sectionType, fieldKey, value);
        set({ isSaving: false, lastSavedAt: new Date() });
      } catch (err) {
        set((state) => {
          state.profile = current;
          state.isSaving = false;
          state.error = String(err);
        });
      }
    },

    getFieldHistory: async (sectionType, fieldKey) => {
      const profile = get().profile;
      if (!profile) return [];
      return await commands.profileGetFieldHistory(profile.accountId, sectionType, fieldKey);
    },

    clear: () => set({ profile: null, error: null }),
  }))
);
```

### 防抖保存 Hook

```typescript
// src/hooks/useProfileAutosave.ts
import { useEffect, useRef } from 'react';
import { useProfileStore } from '@/stores/profileStore';

const SAVE_DELAY = 500; // ms

export function useProfileAutosave(accountId: string) {
  const { profile, updateProfile } = useProfileStore();
  const timeoutRef = useRef<ReturnType<typeof setTimeout>>();
  const pendingChanges = useRef<Partial<typeof profile>>({});

  const scheduleSave = (changes: Partial<typeof profile>) => {
    pendingChanges.current = { ...pendingChanges.current, ...changes };

    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current);
    }

    timeoutRef.current = setTimeout(() => {
      if (Object.keys(pendingChanges.current).length > 0) {
        updateProfile(pendingChanges.current);
        pendingChanges.current = {};
      }
    }, SAVE_DELAY);
  };

  const saveImmediately = () => {
    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current);
    }
    if (Object.keys(pendingChanges.current).length > 0) {
      updateProfile(pendingChanges.current);
      pendingChanges.current = {};
    }
  };

  useEffect(() => {
    return () => {
      if (timeoutRef.current) {
        clearTimeout(timeoutRef.current);
      }
      // 组件卸载时立即保存
      saveImmediately();
    };
  }, []);

  return { scheduleSave, saveImmediately };
}
```

## uiStore（UI 状态）

### 职责

- 侧边栏展开/收起
- Toast 通知
- Modal 管理
- 全局 Loading
- 页面过渡状态

### 实现

```typescript
// src/stores/uiStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';

interface Toast {
  id: string;
  message: string;
  type: 'info' | 'success' | 'warning' | 'error';
  duration?: number;
}

interface Modal {
  id: string;
  component: string;      // 组件标识
  props?: Record<string, unknown>;
}

interface UiState {
  // 侧边栏
  sidebarCollapsed: boolean;
  sidebarOpenOnMobile: boolean;
  
  // Toast
  toasts: Toast[];
  
  // Modal
  modals: Modal[];
  
  // Loading
  globalLoading: boolean;
  loadingMessage: string;
  
  // 动作
  toggleSidebar: () => void;
  openSidebarMobile: () => void;
  closeSidebarMobile: () => void;
  
  showToast: (toast: Omit<Toast, 'id'>) => void;
  dismissToast: (id: string) => void;
  
  openModal: (modal: Omit<Modal, 'id'>) => void;
  closeModal: (id: string) => void;
  closeAllModals: () => void;
  
  setGlobalLoading: (loading: boolean, message?: string) => void;
}

let toastIdCounter = 0;
let modalIdCounter = 0;

export const useUiStore = create<UiState>()(
  immer((set) => ({
    sidebarCollapsed: false,
    sidebarOpenOnMobile: false,
    toasts: [],
    modals: [],
    globalLoading: false,
    loadingMessage: '',

    toggleSidebar: () => set((state) => {
      state.sidebarCollapsed = !state.sidebarCollapsed;
    }),
    
    openSidebarMobile: () => set({ sidebarOpenOnMobile: true }),
    closeSidebarMobile: () => set({ sidebarOpenOnMobile: false }),

    showToast: (toast) => set((state) => {
      const id = `toast-${++toastIdCounter}`;
      state.toasts.push({ ...toast, id });
      
      // 自动消失
      const duration = toast.duration ?? 3000;
      setTimeout(() => {
        useUiStore.getState().dismissToast(id);
      }, duration);
    }),

    dismissToast: (id) => set((state) => {
      state.toasts = state.toasts.filter((t) => t.id !== id);
    }),

    openModal: (modal) => set((state) => {
      const id = `modal-${++modalIdCounter}`;
      state.modals.push({ ...modal, id });
    }),

    closeModal: (id) => set((state) => {
      state.modals = state.modals.filter((m) => m.id !== id);
    }),

    closeAllModals: () => set({ modals: [] }),

    setGlobalLoading: (loading, message = '') => set({
      globalLoading: loading,
      loadingMessage: message,
    }),
  }))
);
```

## settingsStore（用户偏好）

### 职责

- 用户偏好读写
- 主题/语言/锁定超时等切换
- **❌ 不再负责持久化** —— 持久化由 Rust Vault 通过加密文件处理

> **重要变更**：根据「我们不管理'文档'，我们管理'你'」的核心信条，用户偏好属于用户数据，必须通过 Vault 加密存储。
>
> - ❌ 移除了 Zustand `persist` 中间件 —— 不再持久化到 localStorage（明文暴露用户偏好）
> - ✅ 改为通过 IPC 调用 Rust Vault 加密读写
> - ✅ Vault 锁定后，内存中的偏好数据被清空
>
> 详见《用户数据边界定义与用户偏好存储方案.md》。

### 实现

```typescript
// src/stores/settingsStore.ts
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
// ❌ 移除：import { persist } from 'zustand/middleware';
// 用户偏好是敏感数据，不持久化到 localStorage
import { commands } from '@/lib/ipc';
import type { AppSettings } from '@/types';

interface SettingsState {
  settings: AppSettings;
  isLoading: boolean;
  isDirty: boolean;

  loadSettings: () => Promise<void>;
  updateSetting: <K extends keyof AppSettings>(
    key: K,
    value: AppSettings[K]
  ) => Promise<void>;
  resetToDefault: () => Promise<void>;
  // ✅ 新增：Vault 锁定后清空状态
  clearOnVaultLock: () => void;
}

const DEFAULT_SETTINGS: AppSettings = {
  theme: 'system',
  locale: 'zh-CN',
  autoLockTimeoutMinutes: 5,
  biometricEnabled: false,
  hapticFeedback: true,
  confirmDelete: true,
  developerMode: false,
  accentColor: null,
  fontSize: 'medium',
  density: 'comfortable',
  dateFormat: 'YYYY-MM-DD',
  currencyFormat: 'CNY',
  timezone: 'Asia/Shanghai',
  defaultSensitivityStrategy: 'inherit',
};

// ❌ 移除 persist 包裹 —— 敏感数据不写入 localStorage
export const useSettingsStore = create<SettingsState>()(
  immer((set, get) => ({
    settings: DEFAULT_SETTINGS,
    isLoading: false,
    isDirty: false,

    loadSettings: async () => {
      set({ isLoading: true });
      try {
        // ✅ 从 Rust Vault 读取加密存储的偏好
        const settings = await commands.userDataGetPreferences();
        set({ settings: { ...DEFAULT_SETTINGS, ...settings }, isLoading: false });
      } catch (err) {
        // Vault 未解锁时可能报错，保持默认设置
        set({ isLoading: false });
      }
    },

    updateSetting: async (key, value) => {
      const oldValue = get().settings[key];
      
      // 乐观更新（仅内存）
      set((state) => {
        state.settings[key] = value;
        state.isDirty = true;
      });

      try {
        // ✅ 通过 IPC 写入 Rust Vault，加密存储
        await commands.userDataUpdatePreference(key, value);
        set((state) => { state.isDirty = false; });
        
        // 触发事件（如主题变更）
        if (key === 'theme') {
          window.dispatchEvent(new CustomEvent('theme-changed', { detail: value }));
        }
      } catch (err) {
        // 回滚（仅内存）
        set((state) => {
          state.settings[key] = oldValue;
          state.isDirty = false;
        });
        throw err;
      }
    },

    resetToDefault: async () => {
      await commands.userDataResetPreferences();
      set({ settings: DEFAULT_SETTINGS, isDirty: false });
    },

    // ✅ 新增：Vault 锁定后清空敏感状态
    clearOnVaultLock: () => {
      set({
        settings: DEFAULT_SETTINGS,
        isLoading: false,
        isDirty: false,
      });
    },
  }))
);
```

## 与 Flutter Riverpod 的映射

| Flutter (Riverpod) | Tauri (Zustand) | 说明 |
|-------------------|----------------|------|
| `StateNotifier` | `create()` + `immer` | 状态 + 动作 |
| `StateNotifierProvider` | `useStore` hook | 订阅状态 |
| `ConsumerWidget` | 直接 `useStore` | 组件消费状态 |
| `ref.read(provider)` | `useStore.getState()` | 读取状态（不在渲染中） |
| `ref.watch(provider)` | `useStore(selector)` | 订阅状态变化 |
| `ref.listen(provider, callback)` | `useEffect` + 事件监听 | 副作用 |
| `ProviderScope` | 无需包裹 | Zustand 无 Provider |
| `AutoDispose` | 手动清理 | `useEffect` return |

### 迁移示例

```dart
// Flutter
class AuthNotifier extends StateNotifier<AuthState> {
  AuthNotifier() : super(AuthState());

  Future<void> login(String accountId, String password) async {
    state = state.copyWith(isLoading: true);
    try {
      final account = await rustVaultService.unlock(accountId, password);
      state = state.copyWith(isAuthenticated: true, currentAccount: account, isLoading: false);
    } catch (e) {

    }
  }
}
```

## 持久化策略

### 哪些状态需要持久化

| Store | 持久化方式 | 说明 |
|-------|-----------|------|
| authStore | ❌ 不持久化 | 敏感状态，每次启动重新验证 |
| vaultStore | ❌ 不持久化 | Vault 始终从 Locked 开始 |
| profileStore | ❌ 不持久化 | 从后端加载 |
| **uiStore** | ✅ localStorage | sidebarCollapsed、Toast 队列 —— 纯 UI 状态，非用户数据 |
| **settingsStore** | ❌ 不持久化到 localStorage | 用户偏好是敏感数据，通过 IPC → Rust Vault 加密存储 |
| searchStore | ❌ 不持久化到 sessionStorage | 搜索历史是敏感数据，通过 IPC → Rust Vault 加密存储 |

### Zustand Persist 中间件 —— 仅限非敏感 UI 状态

> **警告**：`persist` 中间件将数据写入 `localStorage`，任何能访问浏览器的代码均可读取。
> 用户偏好、搜索历史等敏感数据**禁止使用** `persist`。

```typescript
// ✅ 允许使用 persist：uiStore（纯 UI 状态，非用户数据）
import { persist, createJSONStorage } from 'zustand/middleware';

export const useUiStore = create(
  persist(
    (set, get) => ({
      sidebarCollapsed: false,
      toasts: [],
      // ...
    }),
    {
      name: 'solosoul-ui',
      storage: createJSONStorage(() => localStorage),
      partialize: (state) => ({
        sidebarCollapsed: state.sidebarCollapsed,
        // ❌ 不持久化 toasts（临时状态）
      }),
    }
  )
);

// ❌ 禁止使用 persist：settingsStore（用户偏好 = 敏感数据）
// 用户偏好通过 IPC → Rust Vault 加密存储
```

## 从零实现顺序

1. **安装 Zustand**
   ```bash
   npm install zustand
   npm install -D @types/node
   ```

2. **创建基础 Store 骨架**
   - authStore（最简单，先验证 IPC 调用）
   - uiStore（不依赖后端，可独立测试）

3. **集成 IPC**
   - tauri-specta 生成类型
   - 封装 `src/lib/ipc.ts`

4. **实现业务 Store**
   - vaultStore
   - profileStore
   - settingsStore

5. **实现高级 Store**
   - unifiedObjectStore
   - pluginStore
   - syncStore

6. **添加中间件**
   - Immer（可变语法）
   - Persist（持久化）—— **仅限 uiStore 等非敏感状态**
   - Devtools（Redux DevTools）

7. **事件监听**
   - Vault 锁定事件 → 清理所有 Store
   - 主题变更事件 → 更新 CSS 变量
