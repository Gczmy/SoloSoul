## 3. 一键构建脚本

项目根目录提供 `docs/build_macos_release.sh`（macOS）与 `docs/build_windows_release.sh`（Windows），支持一键构建带签名的 Release 版本。完整发布流程见 `docs/release_process.md`。

### 使用方式

```bash
# 默认构建（ad-hoc 签名，无需 Apple Developer 账户）
./docs/build_macos_release.sh

# 详细输出模式
./docs/build_macos_release.sh --verbose

# 使用 Apple Development 证书签名（需本地安装对应证书）
APPLE_SIGNING_IDENTITY="Developer ID Application: Your Name" ./docs/build_macos_release.sh
```

### 脚本行为

| 步骤 | 说明 |
|------|------|
| 读取版本号 | 从 `tauri/package.json` 自动解析 |
| 前置检查 | 验证 Node.js (>=22)、npm、Rust/Cargo 已安装 |
| 清理旧产物 | 删除 `tauri/src-tauri/target/release/bundle/` |
| 安装依赖 | 在 `tauri/` 目录执行 `npm ci` |
| Tauri 构建 | 执行 `npm run tauri build -- --bundles app`，仅生成 `.app` |
| 代码签名 | 先签内部 `.dylib`/`.framework`，再签主包；默认 ad-hoc (`-`) |
| DMG 打包 | 优先使用 `create-dmg`（美观），否则 fallback 到 `hdiutil` |
| DMG 签名 | 对最终 `.dmg` 再次签名 |
| 输出报告 | 显示产物路径、大小及签名状态 |

### 产物位置

构建产物位于 `tauri/target/release/bundle/`（实际路径由脚本 `TAURI_DIR` 决定，以脚本输出为准）：

```
bundle/
├── macos/SoloSoul.app                          # 签名后的应用包
├── macos/SoloSoul_<版本>_<架构>.app.tar.gz     # updater 自动更新包（脚本 §tar 步骤生成）
└── dmg/SoloSoul_<版本>_<架构>.dmg              # 签名后的 DMG 安装包
```

### 注意事项

- **ad-hoc 签名** 允许本地运行，但首次打开时可能需要在 系统设置 > 隐私与安全性 中手动允许
- 对外公开分发时，建议使用 Apple Developer ID 证书替换 ad-hoc 签名
- 脚本仅针对 **macOS** 设计，Windows/Linux 构建需另行调整

## 4. 代码签名（无公证）

### 当前策略

由于项目**暂无 Apple Developer ID 账户**，当前版本采用以下签名策略：

- **macOS**: 使用 `codesign --sign -` 进行 **ad-hoc 签名**，或本地 Apple Development 证书
- **Windows**: 暂未实现签名（需购买代码签名证书）
- **公证 (Notarization)**: 暂不实现；对外分发前需在 Apple Developer 账户中完成

### 签名流程（脚本内实现）

```bash
# 1. 清除扩展属性
xattr -cr "SoloSoul.app"

# 2. 签名所有嵌入的 .dylib
find "SoloSoul.app/Contents" -name "*.dylib" \
  -exec codesign --force --sign "${SIGN_IDENTITY}" --timestamp=none {} \;

# 3. 签名所有 .framework
find "SoloSoul.app/Contents" -name "*.framework" -type d \
  -exec codesign --force --sign "${SIGN_IDENTITY}" --timestamp=none {} \;

# 4. 签名主程序包（deep 递归）
codesign --force --deep --sign "${SIGN_IDENTITY}" \
         --identifier "com.solosoul.app" \
         --timestamp=none "SoloSoul.app"

# 5. 对 DMG 签名
codesign --force --sign "${SIGN_IDENTITY}" --timestamp=none "SoloSoul_*.dmg"
```

### 未来扩展：Developer ID + 公证

当获得 Apple Developer ID 账户后，可在脚本中启用以下步骤：

```bash
# 提交公证（需在脚本中手动启用）
xcrun notarytool submit \
  tauri/src-tauri/target/release/bundle/dmg/SoloSoul_*.dmg \
  --apple-id "$APPLE_ID" --password "$APPLE_PASSWORD" \
  --team-id "$APPLE_TEAM_ID" --wait

#  staple 公证票证
xcrun stapler staple SoloSoul.app
```

### Windows 签名（未来）

```bash
signtool sign /f certificate.pfx /p password \
```

## 5. 自动更新

```json
// tauri.conf.json → plugins.updater
{
  "plugins": {
    "updater": {
      "active": true,
      "endpoints": ["https://api.github.com/repos/Gczmy/SoloSoul/releases/latest"],
      "dialog": true,
      "pubkey": "YOUR_PUBLIC_KEY"
    }
  }
}
```

```typescript
// src/lib/updater.ts
import { check } from '@tauri-apps/plugin-updater';

export async function checkForUpdates() {
  const update = await check();
  if (update) {
    const yes = await ask(`发现新版本 ${update.version}，是否更新？`);
    if (yes) {
      await update.downloadAndInstall();
    }
  }
}
```

## 6. GitHub Actions 发布

```yaml
# .github/workflows/release.yml
on:
  push:
    tags: ['v*']

jobs:
  build-macos:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: 'npm'
          cache-dependency-path: tauri/package-lock.json
      - run: ./build_release.sh
      - uses: actions/upload-artifact@v4
        with:
          name: macos-artifacts
          path: tauri/src-tauri/target/release/bundle/dmg/*.dmg

  build-windows:
    runs-on: windows-latest
    # 同上...

  create-release:
    needs: [build-macos, build-windows]
    runs-on: ubuntu-latest
    steps:
      - uses: softprops/action-gh-release@v2
        with:
          draft: true
          files: |
            artifacts/macos-artifacts/**/*.dmg
            artifacts/windows-artifacts/**/*.msi
```

## 7. 与 Flutter 构建的对比

| 方面 | Flutter | Tauri |
|------|---------|-------|
| 构建命令 | `flutter build macos` | `./build_release.sh` |
| 包大小 | ~50MB+ | **~5-10MB** |
| 签名 | `codesign` 手动 | 脚本自动处理 |
| 自动更新 | 需自建 | Tauri 内置 |
| 构建时间 | 5-10 min | 2-5 min |
| 依赖 | Xcode + Flutter SDK | Rust + Node.js |
