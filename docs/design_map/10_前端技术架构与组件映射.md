## 3. 路由系统（`src/App/routes.tsx`）

路由通过集中式 `protectedRoutes` 配置 + `<AuthGuard>` 统一鉴权。

### 3.1 鉴权拦截（AuthGuard）

```tsx
import { useAuthStore } from '@/stores/authStore';

export function AuthGuard({ children }: { children: React.ReactNode }) {
  const isAuthenticated = useAuthStore((s) => s.isAuthenticated);
  if (!isAuthenticated) return <Navigate to="/login" replace />;
  return <>{children}</>;
}
```

`BootstrapPage` 和 `LoginPage` 在 AuthGuard 之外渲染；其余所有页面均包裹在 AuthGuard 内。

### 3.2 完整路由表

```tsx
export const protectedRoutes: RouteConfig[] = [
```

## 4. 表单系统与防抖保存

- **表单验证**：全面采用 `React Hook Form` + `Zod` schema 校验
- **字段输入**：`TemplateFieldInput` 组件根据模板 `TemplateProperty` 定义动态渲染对应的输入控件（text/textarea/number/date/select/multiselect/url/email/phone/file）
- **防抖保存**：Profile/对象编辑页使用 500ms debounce，关键操作可通过 `flush()` 强制立即保存
- **乐观更新**：`objectStore.createObject` / `profileStore.updateField` 采用乐观更新 + IPC 失败回滚模式

## 6. 状态管理依赖映射（页面 → Store）

各页面与 16 个 Zustand Store 的强耦合依赖关系：

| Store | 职责 | 依赖页面 / 组件 |
|-------|------|----------------|
| **authStore** | 鉴权、会话、当前账户 | `BootstrapPage`、`LoginPage` — 认证流程入口；`AuthGuard` — 路由鉴权拦截；几乎所有受保护页面通过 `getCurrentAccount` 获取 accountId |
| **objectStore** | 对象 CRUD、列表缓存 | `ObjectWorkspacePage`、`ObjectEditorPage`、`OcrPage`、`ScanLocalPage` |
| **settingsStore** | 双层偏好（UI + 敏感） | `AppearanceSettingsPage`、`SecuritySettingsPage`、`TrashPage`、`OperationLogPage`、`TemplateManagerPage`、`SearchPage`、`ObjectEditorPage`、`ObjectWorkspacePage` |
| **templateStore** | 模板 CRUD、字段检查 | `ObjectWorkspacePage`、`ObjectEditorPage`、`TrashPage`、`TemplateManagerPage` |
| **trashStore** | 回收站状态与操作 | `TrashPage` |
| **llmStore** | LLM 流式对话状态 | `LlmChatPage`（通过 `useLlmChat` hook） |
| **llmStatsStore** | LLM 用量统计 | `LlmStatsPage` |
| **pluginStore** | 插件生命周期 | `PluginDashboardPage` |
| **syncStore** | 同步状态与任务 | `SyncPage` |
| **uiStore** | 全局 UI 辅助状态 | `HistoryPage`、`GlobalAttachmentManager`、`TemplateManagerPage` |
| **vaultStore** | Vault 锁定/解锁 | `LoginPage`（unlock）、`SecuritySettingsPage`（change_password）、`AppShell`（锁屏触发） |
| **profileStore** | Profile 数据 + 乐观更新 | `HomePage`、各编辑器 Profile 分区 |
| **sidebarHoverStore** | 侧边栏悬停/滚动 | `SideNavigation`、`PrimaryNavZone`（跨页面导航保持） |
| **pluginQuickStore** | 插件快捷面板 UI | `PluginGatePage` 等 |
| **ocrScanStore** | OCR 扫描历史 | `OcrPage` |
| **ocrInstallStore** | OCR 模型安装进度 | `OcrSettingsPage` |
