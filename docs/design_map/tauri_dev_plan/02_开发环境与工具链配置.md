## 2. 工具链安装

### 2.1 Rust

```bash
# 安装 Rust（使用 rustup）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# 验证
rustc --version  # rustc 1.82.0+

# 安装 clippy 和 rustfmt
rustup component add clippy rustfmt
```

### 2.2 Node.js

```bash
# 使用 nvm 安装
nvm install 20
nvm use 20

# 验证
node --version  # v20.x.x
npm --version   # 10.x.x
```

### 2.3 Tauri CLI

```bash
# 推荐使用 npx（无需全局安装）
npx tauri --version

# 或全局安装
cargo install tauri-cli
```

### 2.4 平台依赖

**macOS**:
```bash
xcode-select --install  # Xcode Command Line Tools
```

**Windows**:
```bash
# Visual Studio Build Tools（勾选 C++ 桌面开发）
# WebView2 Runtime（Windows 10/11 通常已预装）
```

**Linux (Ubuntu/Debian)**:
```bash
sudo apt update
sudo apt install libgtk-3-dev libwebkit2gtk-4.0-dev \
  libappindicator3-dev librsvg2-dev patchelf
```

## 3. 项目初始化

```bash
# 1. 克隆仓库
git clone https://github.com/Gczmy/SoloSoul.git
cd SoloSoul

# 2. 安装前端依赖
npm install
# 或 pnpm install

# 3. 安装 Rust 依赖
cd src-tauri && cargo fetch && cd ..

# 4. 验证环境
npx tauri --version
cargo --version
npm run dev  # 访问 http://localhost:1420
```

## 4. IDE 配置

### 4.1 VS Code（推荐）

**必需插件**:
- `rust-lang.rust-analyzer` — Rust 语言支持
- `dbaeumer.vscode-eslint` — ESLint
- `esbenp.prettier-vscode` — Prettier

**推荐配置** (`.vscode/settings.json`):
```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer",
    "editor.formatOnSave": true
  },
  "rust-analyzer.checkOnSave.command": "clippy",
  "rust-analyzer.cargo.features": "all",
  "typescript.preferences.importModuleSpecifier": "non-relative"
}
```

## 5. 开发工作流

### 5.1 启动开发

```bash
# 同时启动前端 dev server 和 Tauri 应用
npm run tauri dev

# 前端独立开发（不启动 Tauri 窗口）
npm run dev  # 访问 http://localhost:1420
```

### 5.2 代码检查

```bash
# Rust 格式化
cargo fmt

# Rust 静态检查
cargo clippy -- -D warnings

# TypeScript 类型检查
npx tsc --noEmit

# ESLint
npm run lint

# 全部检查（CI 前执行）
npm run check-all
```

### 5.3 测试

```bash
# Rust 测试
cargo test --workspace

# 前端单元测试
npx vitest

# E2E 测试
npx playwright test

# 全部测试
npm run test-all
```

### 5.4 构建

```bash
# 开发构建
npm run tauri build -- --debug

# Release 构建
npm run tauri build
```

## 6. 调试技巧

### 6.1 前端调试

在 Tauri 窗口中右键 → Inspect Element（或按 F12），使用 Chrome DevTools。

### 6.2 Rust 调试

VS Code 配置 `.vscode/launch.json`:
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "lldb",
      "request": "launch",
      "name": "Debug Tauri",
      "cargo": {
        "args": ["build", "--manifest-path=src-tauri/Cargo.toml"],
        "filter": { "name": "solosoul", "kind": "bin" }
      },
      "args": [],
      "cwd": "${workspaceFolder}"
    }
  ]
}
```

### 6.3 日志

**Rust**:


## 7. 常见问题

| 问题 | 解决 |
|------|------|
| `cargo tauri dev` 首次启动慢 | 首次编译 Rust 依赖需 5-10 分钟，后续使用缓存 |
| 前端热重载不工作 | 确保 `vite.config.ts` 中 `server.hmr: true` |
| Rust 代码修改后未重新编译 | `cargo tauri dev` 自动监视，或手动 `cd src-tauri && cargo build` |
| Playwright E2E 测试失败 | 确保先构建应用：`npm run tauri build -- --debug` |
