## 2. 禁止的密码学实践

| ❌ 禁止 | 正确做法 |
|--------|---------|
| 自定义加密算法 | 只用 NIST/公开审计的标准算法 |
| 未经验证的第三方加密库 | 只用 RustCrypto 或 dalek-cryptography 组织的库 |
| 硬编码密钥或 IV | 全部用 OsRng 随机生成 |
| 重复使用 nonce | 每次加密生成新 nonce（AES-GCM 的 nonce 重复会导致密钥恢复） |
| 降低 KDF 参数 | Argon2id 参数固定，不可为"优化性能"而降低 |
| 使用弱哈希（MD5/SHA1） | 只用 SHA-256 或 BLAKE3 |

## 3. Argon2id KDF 实现

```rust
// crates/solosoul-crypto/src/kdf.rs

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct KdfConfig {
    pub memory_kb: u32,      // 内存 (KB)
    pub iterations: u32,     // 迭代次数
    pub parallelism: u32,    // 并行度
}

impl KdfConfig {
    /// 开发模式：8 MiB / 2 iterations / 4 parallelism
    pub fn development() -> Self {
        Self { memory_kb: 8 * 1024, iterations: 2, parallelism: 4 }
    }

    /// 生产模式：64 MiB / 3 iterations / 4 parallelism（OWASP 推荐）
    pub fn production() -> Self {
        Self { memory_kb: 64 * 1024, iterations: 3, parallelism: 4 }
    }
}

/// 使用 Argon2id 派生 256-bit 密钥
/// 返回 Zeroizing<Vec<u8>>，确保内存自动擦除
pub fn derive_key(
    password: &str,
    salt: &[u8],          // 至少 16 字节
    config: &KdfConfig,
) -> Result<Zeroizing<Vec<u8>>, KdfError> {
    if salt.len() < 16 {
        return Err(KdfError::InvalidSaltLength(salt.len()));
    }
    let params = Params::new(config.memory_kb, config.iterations,
        config.parallelism, Some(32))?;
    let argon2 = Argon2::new(Algorithm::Argon2id, Version::V0x13, params);
    let mut output = Zeroizing::new(vec![0u8; 32]);
    argon2.hash_password_into(password.as_bytes(), salt, &mut output)?;
    Ok(output)
}

pub fn generate_salt() -> [u8; 16] {
    let mut salt = [0u8; 16];
    rand::thread_rng().fill_bytes(&mut salt);
    salt
}
```

## 4. AES-256-GCM 加密实现

```rust
// crates/solosoul-crypto/src/cipher.rs

/// 加密数据格式：nonce (12 bytes) || ciphertext || tag (16 bytes)
pub struct EncryptedData {
    pub nonce: [u8; 12],
    pub ciphertext: Vec<u8>,
}

/// AES-256-GCM 加密
pub fn encrypt(
    key: &[u8; 32],
    plaintext: &[u8],
    aad: Option<&[u8]>,     // 附加认证数据（可选）
) -> Result<EncryptedData, CipherError> {
    let cipher = Aes256Gcm::new_from_slice(key)
        .map_err(|_| CipherError::InvalidKeyLength)?;
    let nonce = Aes256Gcm::generate_nonce(&mut OsRng);
    let nonce_bytes: [u8; 12] = nonce.as_slice().try_into()
        .map_err(|_| CipherError::NonceGenerationFailed)?;

    let ciphertext = if let Some(aad_data) = aad {
        cipher.encrypt(&nonce, (aad_data, plaintext).into())
    } else {
        cipher.encrypt(&nonce, plaintext)
    }.map_err(|_| CipherError::EncryptionFailed)?;

    Ok(EncryptedData { nonce: nonce_bytes, ciphertext })
}

/// AES-256-GCM 解密
/// 如果密文被篡改，返回 DecryptionFailed（GCM 的认证标签验证失败）
pub fn decrypt(
    key: &[u8; 32],
    encrypted: &EncryptedData,
    aad: Option<&[u8]>,
) -> Result<Zeroizing<Vec<u8>>, CipherError> {
    let cipher = Aes256Gcm::new_from_slice(key)
        .map_err(|_| CipherError::InvalidKeyLength)?;
    let nonce = Nonce::from_slice(&encrypted.nonce);
    let plaintext = if let Some(aad_data) = aad {
        cipher.decrypt(nonce, (aad_data, encrypted.ciphertext.as_ref()).into())
    } else {
        cipher.decrypt(nonce, encrypted.ciphertext.as_ref())
    }.map_err(|_| CipherError::DecryptionFailed)?;
    Ok(Zeroizing::new(plaintext))
}
```

## 5. 安全内存管理

```rust
// crates/solosoul-crypto/src/secure.rs

/// 安全字节数组：离开作用域时自动清零
#[derive(Zeroize, ZeroizeOnDrop)]
pub struct SecureBytes {
    data: Vec<u8>,
}

/// 安全字符串
pub type SecureString = zeroize::Zeroizing<String>;

/// 常量时间比较（防时序攻击）
pub fn secure_compare(a: &[u8], b: &[u8]) -> bool {
    use subtle::ConstantTimeEq;
    a.ct_eq(b).into()
}
```

## 6. Vault 验证令牌机制

```rust
// 验证令牌 = "SOLOSOUL_VAULT_V1" 的 AES-256-GCM 密文
// 用于验证密码正确性，而不存储密码哈希

pub fn create_verify_token(key: &[u8; 32]) -> Result<Vec<u8>, CipherError> {
    encrypt_to_bytes(key, b"SOLOSOUL_VAULT_V1", None)
}

pub fn verify_token(key: &[u8; 32], token: &[u8]) -> Result<bool, CipherError> {
    match decrypt_from_bytes(key, token, None) {
        Ok(plaintext) => Ok(plaintext.as_slice() == b"SOLOSOUL_VAULT_V1"),
        Err(_) => Ok(false),
    }
}
```

## 8. 密钥分层架构

```
Layer 1: 用户主密码 → Argon2id → 主密钥 (32-byte)
Layer 2: 主密钥 → HKDF-SHA256 派生 → 会话密钥 → 存入 OS Keychain
Layer 3: 生物识别验证 → 从 Keychain 读取会话密钥 → 解锁 Vault

会话密钥泄露 ≠ 主密钥泄露（密码学上隔离）
```

## 10. 必须的单元测试

| 测试 | 要求 |
|------|------|
| KDF 确定性 | 相同 password + salt → 相同 key |
| KDF 差异化 | 不同 password 或不同 salt → 不同 key |
| AES-GCM 往返 | encrypt → decrypt → 原文匹配 |
| 密文篡改检测 | 修改密文 1 字节 → decrypt 返回错误 |
| 错误密钥 | 错误 key 解密 → 返回错误 |
| 错误 AAD | 不同 AAD 解密 → 返回错误 |
| Salt 长度验证 | salt < 16 字节 → 返回错误 |
| 安全比较 | `secure_compare` 常量时间正确性 |
