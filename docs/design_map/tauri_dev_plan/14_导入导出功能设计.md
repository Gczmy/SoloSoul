## 1. 设计原则

### 为什么细化到"项目层"为止，不开放字段级别？

1. **数据完整性**：护照项目包含姓名、国籍、护照号等字段，共同构成完整记录。导出"只有姓名和国籍的护照"无意义。
2. **关系完整性**：项目可能包含 RelationProperty 指向其他项目，字段级导出会产生孤立引用。
3. **用户体验**：字段级选择让导出 UI 极其复杂（每个项目展开几十个字段），违背"最少惊喜"。
4. **粒度足够**：项目级导出已满足"只导出护照"的实际需求。

### 导出范围的四层结构（不含字段层）

```
身份数据
├── 页面层 → "导出我的所有旅行数据"
├── 分区层 → "导出我的护照和签证"
├── 项目层 → "导出我的中国护照"
│   └── 附件层 → "只导出扫描件，不导出照片"

偏好数据
├── 视觉偏好（主题、颜色、字体）
├── 行为偏好（锁定超时、生物识别、删除确认）
├── 内容偏好（语言、日期格式、时区）
├── 敏感度偏好（SensitivityMap）
├── 插件偏好（已安装列表、授权记录）
└── AI 偏好（提供商、模型、API 密钥）

行为记录
├── 操作日志（CRUD、敏感度变更）
├── 搜索历史
├── 审计日志（插件访问、密码验证）
└── AI 对话历史
```

## 2. 导出包格式（v2.0）

```
{scopeName}_export.solosoul (ZIP)
├── manifest.json           # 明文：版本、导出范围、时间、平台、应用版本
│   ├── version: "2.0"
│   ├── export_scope: "partial" | "full"
│   ├── selected_pages/collections/items/attachments
│   ├── selected_preferences/behavioral
│   └── export_time/export_platform/export_app_version
├── account.enc             # 加密：password_hint + verify_token + export_salt
├── profile.enc             # 加密：筛选后的 Profile JSON
├── preferences.enc         # 加密：用户偏好（可选）
├── audit_log.enc           # 加密：审计日志（可选）
├── search_history.enc      # 加密：搜索历史（可选）
├── ai_conversation.enc     # 加密：AI 对话历史（可选）
├── sensitivity_map.enc     # 加密：敏感度映射表（仅与选中字段相关的条目）
├── attachments/
│   └── {fileId}.enc        # 只含被选中的附件
└── checksums.json          # SHA-256 校验
```

## 3. 导出密码设计

### 密码模式

| 模式 | 说明 |
|------|------|
| **使用主密码**（默认） | 复用当前 Vault 解锁密码，无需额外输入 |
| **使用自定义密码** | 允许与主密码不同，用于分享场景 |

### 密码提示词

- 可选字段，最大 200 字符
- **明文**存储于 `account.enc` 头部（不加密），方便导入时展示
- 提示词不包含密码本身，安全可控
- 任何人获得导出文件都可以读取提示词

### 校验规则

| 场景 | 规则 |
|------|------|
| 使用主密码 | 无需额外输入 |
| 使用自定义密码 | 最小 8 位，必须含字母+数字，两次输入一致 |
| 密码强度提示 | 弱/中/强，弱密码需二次确认 |

### 明文导出（三重确认）

> **审批决策（2026-06-05）**：明文 JSON 导出需经过三重确认，且文件自动设置 `chmod 600`。

```
用户选择"明文 JSON 导出"
    ↓
第一重：风险警告对话框
  "⚠️ 明文导出意味着您的数据将以未加密的 JSON 格式保存。
   任何人获得此文件都可以直接读取您的所有个人信息。
   建议：仅在必要时使用，导出后立即删除或移至安全位置。"
  [取消]  [我了解风险，继续]
    ↓
第二重：密码重新验证
  "请输入主密码以确认明文导出"
  [****************]
    ↓
第三重：审计日志记录
  明文导出操作写入 audit_log.enc：
  { action: "PlaintextExport", timestamp, scope, file_path }
    ↓
导出完成 → chmod 600（仅所有者可读写）
```

## 4. 敏感度警告

导出包含 `sensitive`/`critical` 级别数据时，显示警告：

```
⚠️ 您选择的数据包含高敏感度项目
  [受限] 中国护照 (护照号码)
  [敏感] 招商银行储蓄卡 (卡号)
  导出文件使用密码加密，请妥善保管，不要上传到云盘。
```

**LLM API 密钥导出警告**（API 密钥是 critical 级别，导出时默认不勾选，勾选时强制安全警告）。

## 5. 导入功能

### 导入流程

1. 选择 `.solosoul` 文件
2. 读取密码提示词（无需密码）并展示
3. 输入导出密码 → 解密预览
4. 查看导入范围、冲突检测、偏好策略选择
5. 确认导入（导入前自动创建静默备份）

### 偏好数据导入策略

| 策略 | 行为 |
|------|------|
| **使用当前配置** | 忽略导入包偏好，保持现有设置 |
| **使用导入配置** | 完全覆盖（新设备首次导入） |
| **合并** | 导入覆盖冲突项，保留未冲突项 |

### 行为数据导入

**只追加不覆盖**：操作日志、搜索历史、审计日志按时间合并，去重（相同 ID 跳过）。

### 跨范围引用处理

分区/项目级导出时，RelationProperty 的目标对象可能不在导出范围内 → 导入时转为 `[引用项目未导出: {id}]` 文本备注。

## 7. 与备份服务的区别

| 维度 | 备份服务 | 导出服务 |
|------|---------|---------|
| 目的 | 本地时间点恢复 | 跨设备迁移、分享给第三方 |
| 范围 | 全量 | 可选（页面/分区/项目） |
| 加密密钥 | 当前 Vault 主密钥 | 导出密码派生（可与主密码不同） |
| 存储位置 | `~/.solosoul/backups/` | 用户选择任意路径 |

## 8. 关键决策记录

| # | 决策 | 理由 |
|---|------|------|
| 1 | 导出密码允许与主密码不同 | 分享场景需要简化密码 |
| 2 | 项目级导出不自动包含关联项目 | 避免超出预期的数据泄露 |
| 3 | 操作日志/偏好/搜索历史纳入导出（可选） | 属于用户数据 |
| 4 | 不支持增量导出 | 当前阶段复杂度收益比不高 |
| 5 | 密码提示词明文存储 | 帮助用户回忆密码，不包含密码本身 |
