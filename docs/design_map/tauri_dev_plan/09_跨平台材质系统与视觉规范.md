## 1. 设计理念：温暖的数字堡垒

SoloSoul 管理用户最私密的数字资产，界面必须传递**安全感**与**温度感**的平衡：

- **安全 ≠ 冰冷**：暖白 + 低饱和蓝灰，像一本精心装帧的个人手账
- **隐私 ≠ 隐藏**：敏感信息用分级遮罩（毛玻璃模糊 + 渐变蒙层），不是粗暴黑块
- **专业 ≠ 复杂**：操作路径不超过三步

### 三个设计原则

```
1. 内容优先，材质服务于内容
   玻璃/云母效果只能增强信息层级，不能干扰阅读

2. 平台原生，体验统一
   各平台用各自的材质语言，但交互逻辑、信息架构完全一致

3. 降级优雅，从不破碎
   不支持新材质的平台自动获得精心设计的回退方案
```

## 2. 材质决策矩阵

| 平台 | 系统版本 | 首选材质 | 回退材质 | 技术实现 |
|------|---------|---------|---------|---------|
| **macOS** | 15+ (Sequoia) | Liquid Glass | Acrylic 模糊 | CSS backdrop-filter + WebGL |
| **macOS** | 14 及以下 | Acrylic 亚克力 | 纯色 + 投影 | CSS backdrop-filter: blur() |
| **iOS** | 26+ | Liquid Glass | 标准模糊 | CSS backdrop-filter |
| **iOS** | 25 及以下 | 标准模糊 | 纯色层级 | CSS 模糊或预渲染纹理 |
| **Windows** | 11 (22H2+) | Mica Alt | Mica | Tauri 原生 DWM API |
| **Windows** | 10 | Acrylic | 纯色 + 投影 | CSS backdrop-filter |
| **Linux** | 不限 | 自定义模糊 | 纯色 | CSS backdrop-filter（视 compositor） |
| **Android** | 14+ | 原生模糊 | 纯色层级 | CSS / Canvas 模糊回退 |

## 3. 材质层定义

```
┌─ Layer 3: Content Glass（内容玻璃层）─┐
│  卡片、弹窗、浮层 — 最高模糊 + 折射高光  │
│  blur(40px) + saturate(180%) + 内发光   │
├─ Layer 2: Toolbar Glass（工具栏层）────┤
│  侧边栏、顶部栏 — 中等模糊              │
│  blur(20px) + 细微边框                 │
├─ Layer 1: Base Surface（基底材质层）───┤
│  窗口背景 — 平台决定                    │
│  macOS=液态玻璃 / Windows=Mica / 回退=纯色│
└────────────────────────────────────────┘
```

## 4. 色彩系统 — "Warm Stone" 暖石调

### 明亮模式

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-base` | `#FAFAF8` | 全局画布（象牙白，比纯白更温暖） |
| `--bg-elevated` | `#FFFFFF` | 卡片、弹窗 |
| `--bg-toolbar` | `rgba(250,250,248,0.8)` | 侧边栏（半透明） |
| `--text-primary` | `#1A1A1A` | 主标题、正文 |
| `--text-secondary` | `#6B6B6B` | 辅助说明、时间戳 |
| `--text-tertiary` | `#9E9E9E` | 占位符、禁用态 |
| `--accent-primary` | `#5B7C99` | 低饱和蓝灰（信任与冷静） |
| `--accent-warm` | `#C4925C` | 温暖强调色（琥珀调） |
| `--border-subtle` | `#EBEAE6` | 分割线、卡片边框 |
| `--shadow-sm` | `rgba(0,0,0,0.04)` | 轻微投影 |
| `--shadow-md` | `rgba(0,0,0,0.08)` | 中等投影 |
| `--shadow-lg` | `rgba(0,0,0,0.12)` | 弹窗投影 |

### 暗色模式

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-base` | `#1C1C1E` | 全局画布（深灰，非纯黑，减少 OLED 频闪） |
| `--bg-elevated` | `#2C2C2E` | 卡片、弹窗 |
| `--text-primary` | `#F5F5F5` | 主文字 |
| `--accent-primary` | `#7BA3C4` | 暗色下稍亮的蓝灰 |

## 5. 敏感度色彩编码（4 级）

| 级别 | 图标 | 遮罩强度 | 验证要求 |
|------|------|---------|---------|
| `public` | `IconSensitivityPublic`（空心圆环，暖绿色描边） | 无遮罩 | 无需验证 |
| `internal` | `IconSensitivityInternal`（单点圆点，蓝灰色填充） | blur(2px)，点击展开 | 无需验证 |
| `sensitive` | `IconSensitivitySensitive`（实心圆点，琥珀色填充） | blur(8px) + 渐变蒙层 | 需生物识别/密码 |
| `critical` | `IconSensitivityCritical`（锁形图标，深红色填充） | blur(16px) + 深色蒙层 + 锁图标 | 需密码 + 操作确认 |

## 6. CSS 实现示例

```css
.liquid-glass {

  mask-composite: exclude;
  pointer-events: none;
}
```

## 7. 图标与图像规范

### 7.1 核心规则

1. **禁止使用 Emoji 表情**  
   任何界面元素、图标占位、状态标记、空状态插图等，均不得使用 Unicode Emoji 字符（如 `🔔`、`🔒`、`🟢`、`✅` 等）。Emoji 在不同平台渲染不一致，且与 SoloSoul 专业、安全、温暖的品牌调性不符。

2. **所有需要图像表达的位置，使用高清自定义绘制图像**  
   替代 Emoji 的必须是符合 SoloSoul 品牌定位的、高清的、风格统一的绘制图像/图标：
   - **风格关键词**：安全、严谨、温暖、私密、精致
   - **视觉语言**：低饱和暖色、圆润几何、柔和投影、无尖锐边缘
   - **技术规格**：
     - 图标：SVG 矢量，统一 24×24dp 视图框，提供 1×/1.5×/2× 密度适配
     - 插图：SVG 或 2×/3× PNG，核心空状态插图宽度 ≥ 320px
     - 色彩：使用 Warm Stone 色板，禁止 Emoji 自带高饱和色

### 7.2 实现方法（业界主流）

| 场景 | 推荐方案 | 存放路径 |
|------|---------|---------|
| 功能图标 | 自定义 SVG Icon 组件库 | `src/components/icons/` |
| 敏感度标记 | 4 级专属 SVG 图标 | `src/components/icons/sensitivity/` |
| 空状态 / 引导插图 | 设计师输出 SVG/PNG | `public/illustrations/` |
| 状态徽章 | 带图标的 Badge 组件 | `src/components/ui/Badge.tsx` |
| 临时占位 | 使用 Lucide 图标并统一二次设计 | `lucide-react` + 本地封装 |

### 7.3 敏感度图标映射（示例）

Emoji 禁止 → 替换为对应 SVG 图标：

| 级别 | 原 Emoji | 替换图标名 | 说明 |
|------|---------|-----------|------|
| `public` | 🟢 | `IconSensitivityPublic` | 空心圆环，暖绿色描边 |
| `internal` | 🔵 | `IconSensitivityInternal` | 单点圆点，蓝灰色填充 |
| `sensitive` | 🟠 | `IconSensitivitySensitive` | 实心圆点，琥珀色填充 |
| `critical` | 🔴 / 🔒 | `IconSensitivityCritical` | 锁形图标，深红色填充 |

### 7.4 正例与反例

```tsx
// 错误：使用 Emoji 作为图标
<span>🔒</span>
<div>🟢 公开</div>

// 正确：使用自定义 SVG 图标
import { IconSensitivityCritical } from '@/components/icons/sensitivity';
<IconSensitivityCritical size={16} />
<Badge icon={<IconSensitivityPublic size={12} />}>公开</Badge>
```

```css
/* 错误：在 CSS 伪元素中使用 Emoji */
.sensitivity-critical::after {
  content: '🔒';
}

/* 正确：使用 SVG 背景或图标字体 */
.sensitivity-critical::after {
  content: '';
  background: url('/icons/sensitivity-critical.svg') no-repeat center;
}
```

## 10. 可访问性

| 要求 | 实现 |
|------|------|
| 键盘完全可操作 | Tab 导航、Enter/Space 激活、Esc 关闭 |
| 屏幕阅读器 | ARIA label、`role="dialog"`、live region |
| 对比度 | 正文 ≥ 4.5:1，大号文字 ≥ 3:1 |
| 焦点可见 | 2px `--accent-primary` 焦点环 |
| 动画降级 | `prefers-reduced-motion` → 0ms |
| 透明降级 | `prefers-reduced-transparency` → 纯色 |
| 触控目标 | 移动端 ≥ 44×44px，桌面端 ≥ 32×32px |

```css
@media (prefers-reduced-transparency: reduce) {
  .liquid-glass, .acrylic, .mica-overlay {
    background: var(--bg-elevated) !important;
    backdrop-filter: none !important;
  }
}
```
