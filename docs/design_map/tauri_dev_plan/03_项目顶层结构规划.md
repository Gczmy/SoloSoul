## 2. 前后端边界定义

### 2.1 前端职责（`src/`）

| 职责 | 说明 |
|------|------|
| **UI 渲染** | React 组件树、页面布局、动画 |
| **用户交互** | 点击、输入、表单验证、导航 |
| **状态缓存** | Zustand 存储前端状态，减少 IPC 调用 |
| **IPC 调用** | 通过 `invoke()` 调用 Rust 命令 |
| **事件监听** | 通过 `listen()` 接收 Rust 事件 |
| **路由管理** | React Router 处理页面导航 |
| **本地化** | i18n 资源加载、语言切换 |

### 2.2 后端职责（`src-tauri/` + `crates/`）

| 职责 | 说明 |
|------|------|
| **业务逻辑** | 所有 CRUD、搜索、排序、过滤 |
| **数据持久化** | SQLite 读写、文件系统操作 |
| **密码学** | Argon2id、AES-GCM、密钥派生、安全内存 |
| **原生 API** | Keychain、生物识别、文件选择、系统通知 |
| **插件沙盒** | Wasmtime 执行环境 |
| **同步协议** | mDNS、Noise、CRDT |
| **日志记录** | 结构化日志、文件轮转 |

### 2.3 禁止越界

| ❌ 前端禁止 | ❌ 后端禁止 |
|-----------|-----------|
| 直接访问文件系统 | 操作 DOM |
| 直接访问数据库 | 渲染 UI |
| 持有密钥 | 处理路由导航 |
| 密码学运算（推导除外） | 管理前端状态 |
| 插件执行 | 本地化字符串处理 |

## 3. Crate 拆分策略

### 3.1 Workspace 定义

```toml
# Cargo.toml（根）
[workspace]
members = [
    "src-tauri",
    "crates/solosoul-crypto",
    "crates/solosoul-vault",
    "crates/solosoul-sync",
]
resolver = "2"

[workspace.dependencies]
# 密码学
argon2 = "0.5"
aes-gcm = "0.10"
zeroize = { version = "1.8", features = ["derive"] }
rand = "0.8"

# 数据库
rusqlite = { version = "0.32", features = ["bundled", "backup"] }

# 序列化
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"

# 错误处理
thiserror = "1.0"
anyhow = "1.0"

# 异步
tokio = { version = "1.40", features = ["full"] }

# 日志
tracing = "0.1"
tracing-subscriber = "0.3"
```

### 3.2 拆分原则

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个 crate 只做一件事 |
| **无 Tauri 依赖** | `crates/` 下的 crate 不依赖 `tauri`，确保独立可测试 |
| **可复用** | 核心逻辑可由 CLI 工具或其他 Go 工具复用 |
| **渐进拆分** | 初期所有代码在 `src-tauri/src/`，稳定后提取到独立 crate |

### 3.3 依赖关系

```
src-tauri (Tauri App)
├── solosoul-crypto
├── solosoul-vault
│   └── solosoul-crypto
├── solosoul-sync
│   ├── solosoul-crypto
│   └── solosoul-vault
└── tauri（官方 crate）
```

## 4. 样式组织原则

```
✅ CSS Modules + 全局 CSS
   - 组件级样式：Button.module.css（局部作用域）
   - 全局样式：styles/*.css（Tokens、主题、动画）
   - Liquid Glass：styles/liquid-glass.css（统一管理玻璃效果参数）

❌ 不使用 CSS-in-JS（styled-components/emotion）
   理由：运行时开销、与 Liquid Glass 复杂效果不兼容

❌ 不使用 Tailwind CSS
   理由：团队无经验、与 Liquid Glass 不兼容
```

## 5. 与 Flutter 项目的对应关系

| 当前 Flutter | Tauri 重构 | 说明 |
|-------------|-----------|------|
| `lib/` (Dart) | `src/` (React) | UI 层迁移 |
| `lib/core/services/` | `src-tauri/src/services/` | 服务层下沉 Rust |
| `lib/core/repositories/` | `src-tauri/src/db/repositories/` | 仓库层迁移 |
| `lib/core/models/` | `src-tauri/src/core/` + `src/types/` | 模型双写 |
| `lib/presentation/pages/` | `src/pages/` | 页面对应 |
| `lib/presentation/providers/` | `src/stores/` (Zustand) | 状态管理替换 |
| `lib/presentation/widgets/` | `src/components/` | 组件对应 |
| `native/src/` (Rust FFI) | `src-tauri/src/core/` + `crates/` | 核心代码直接复用 |
| `go/` (已废弃) | 删除 | 功能由 Rust 替代 |
| `web/` (Next.js) | 部分复用到 `src/` | React 组件可复用 |
