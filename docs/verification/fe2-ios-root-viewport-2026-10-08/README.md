# iOS 键盘视口与固定顶栏修复

2026-10-08，专用 SoloSoul RF201 / iPhone17 / iOS26.3.1 模拟器。此前对象操作测试虽然完成保存与返回，截图却证实键盘聚焦把 AppBar 推至屏幕上方；旧操作通过不代表视觉通过。

## 当前改动与来源

启动时仅在 iOS 安装 visualViewport 监听，以实际可视高度约束根容器，并抵消 WKWebView 聚焦后的可视视口偏移；正文仍独立滚动，不重设焦点、输入值或内部滚动。AppBar 跟随同一偏移，底部导航和展开菜单避让键盘。iOS 原生层通过公开 WKWebView.scrollView API 关闭自动 content inset 调整，不更换 delegate、不改原生 frame、不使用私有 API。

最终无签名 ARM64 Simulator Debug 生产包二进制为 `98280597fff53310efb49a8849556b5820d0a218a5262a429ae5c4d85f7f277f`，构建前冻结103份来源，构建命令和保护驱动退出0，八组平台输入恢复。完整包和私有备份只保留在 `/tmp`；公开目录保留来源、日志、结果及选定 PNG / AX 文本，不复制账户目录、凭据或屏幕录像。

## 保留的失败

- `native-first/`：仅固定根和可视高度，真实输入焦点失败，且编辑页出现底部空白；原生0通过1失败、退出65。
- `native-insets-build-first/`：构建命令退出0，但新增直接依赖使 Cargo.lock 在构建后变化，来源保护驱动失败。随后锁定解析结果重新冻结构建，旧失败不计成功。
- `native-second/`：关闭原生自动 inset 后，真实键盘聚焦仍把根与顶栏推至 y=-175pt，姓名字段不可达；原生0通过1失败、退出65。
- `native-third/`：加入可视视口偏移补偿，实际对象名称聚焦截图中顶栏恢复 y=0，主要正文 y=110、高270pt，底栏 y=414；姓名滚动测试仍失败，不能据这一帧接受完整场景。
- `native-fourth/`：按正文范围实际触控滑动仍持续越过姓名字段，最终该字段 y=-487pt，断言拒绝。失败截图中顶栏和导航仍在屏幕内，保存 / 取消可见。原生0通过1失败、退出65。独立复核99项内容、权限与链接与当次和最初原始备份相同，设备实际读回 Shutdown。

最终助手仅修改实际滑动方式：以字段真实 AX 几何小步滑动，越过后反向校正，并保留实际触控、系统键盘输入、字段值、顶部安全区、保存和弹层取消断言。最终该轮 **1通过、0失败、0跳过、原生命令及保护驱动退出0**，103份源码执行后没有变化。实际键盘输入 Public Person、保存并打开详情、关闭详情回到身份页面、展开导航和添加页面真实取消均完成。独立复核99项数据及最初备份一致，light外观、助手卸载、Shutdown恢复。

## 检查范围与限制

当前语义改动的浏览器回归15通过、0失败、退出0，包含 iOS / Android 编辑操作、添加页面键盘视口及 macOS 顶栏；模拟 visualViewport 只证明浏览器几何，不证明真实系统键盘。最终仅对 helper 作格式调整后重建生产包。类型检查、定向 ESLint、Rust fmt 与最终格式检查通过；旧生产启动回归1通过保持其当时来源。
