## 发现与修复

1. 初次和诊断仪器测试在对象操作菜单失败。实际记录显示提醒底边 402.12501525878906、编辑按钮顶边 402.125，相邻正常流仅有 0.0000152587890625 CSS px 数值交集，无动画，按钮可点击。仪器判据容忍 0.001 CSS px 舍入并记录交集尺寸，仍检查可见 / 命中。执行测试源码原表达式的 5 项检查证明 0.01 与 0.5 CSS px 实际重叠仍被拒绝，生产布局未为该误判修改。
2. 原判据两组通过后，横屏 PNG 目测发现通知表面进入右侧系统导航区，原判据只采顶部 / 底部导航与登录控件，不能证明通知安全。ShellNotifications 给已登录 Android 壳增加左右安全区，包含更新横幅与通知；认证壳已有安全区不重复加，大屏 main 已避让左侧导航轨道不重复加。正文材质、主题和通知计时未改。
3. 原生安全区样本新增通知操作 / 关闭按钮，横屏必须包含真实 8 秒备份提醒，不能靠到期通过。Python 当前 insets 调用强制新增门槛，历史报告仅在旧门槛有效。
4. 浏览器复验遇到隐藏祖先下零布局框按钮及真实 / 人工提醒同名冲突。只修正测试可见节点筛选与浏览器可控提醒夹具；原生仍使用真实限时提醒，没有延长、关闭或重置计时。
