# FE2 Android 软键盘原生验收

本目录仅收录公开临时账户产生的合成帧、报告、构建日志及源码快照。私有目录备份 tar 留在本机 `/tmp`，不入库。专用设备为 `emulator-5586` / `SoloSoul_RF201`、API34 ARM64；不操作正式 macOS 客户端或其他模拟器。

## 验收边界

先通过真实触屏打开输入法，在原有备份提醒尚未过期时分别抓取输入框和保存按钮帧；提醒必须唯一、可见且不覆盖操作。之后通过实际 Android 键盘事件输入公开 ` XYZ`，按真实系统返回关闭输入法，核对草稿、Router 历史和 WebView 高度恢复。没有生成提醒、关闭提醒、延长计时或替换生产 IPC / 状态。

文字输入不再成为前两张提醒布局帧的等待条件；后续阶段独立要求实际输入成功及返回前后草稿一致。四条边的内部命中、真实原生 IME 高度、控件屏幕底沿和最终合成截图仍是硬性要求。

通过报告只覆盖这台设备的全屏深色编辑场景，以及流程中的浅深色首页和对象返回。旧 Android、真实多窗口 / 分屏、键盘动画逐帧平滑、登录输入、其他键盘、账户切换、iOS 和实体设备性能没有由此证明。macOS 完整客户端隔离验收仍待完成。

最终两组均恢复全部 242 项私有数据的内容 / 链接 / 权限、私有根权限、系统 blur 和通知授权 / 用户标记。仍各发生一次初始化重试与一次解锁维护忙后的 UI 重试，未将其称为已修复。Python 驱动 8 项检查通过，包括从真实报告构造的提醒缺失、控件边缘遮挡、草稿丢失、历史变化与高度恢复缺失的拒绝条件。
