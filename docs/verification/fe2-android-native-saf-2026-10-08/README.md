## 发现与修复

真实DocumentsUI搜索/文件行点击后，公开TXT没有进入附件列表。首次未证明是搜索标题误点；随后收紧文件行定位仍失败。第三次只读通知时序捕获实际错误“Upload failed…附件落盘加密失败: 打开源文件失败”。实际文件行资源android:id/title、屏幕边界及选择器截图保留。不能把前两轮失败归因为已确认的定位问题。

Kotlin原先以ContentResolver真实名称改变复制文件路径；Rust worker仍按调用时destPath（URI文档编号）就地加密，造成路径不一致。现在Kotlin始终复制到Rust指定destPath，displayName单独返回给附件元数据。Rust worker、加密算法、操作许可和路径访问规则未更改，修复也避免该差异留下未加密副本。
