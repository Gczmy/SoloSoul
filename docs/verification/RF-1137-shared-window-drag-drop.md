`windowDragDrop.ts` 共享原生句柄，使用独立本地接收者所有权。部分卡片卸载不影响其余卡片，最后卸载才清理；注册未完成时即时重挂载复用同一待定注册，无接收者时释放迟到句柄。一个接收者异常不会阻断其他卡片。卡片仍按顶层与边界命中判断接收目标，原上传队列、对象归属和去重规则保持。
