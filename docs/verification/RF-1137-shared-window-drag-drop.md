# RF-1137 共享窗口拖放订阅

当前代码将对象卡片的窗口拖放订阅合并为每 WebView 一组；前端回归已通过，任务仍待原生验证。

当前安装的 Tauri SDK `webview.js:onDragDropEvent` 每调用注册 enter、over、drop、leave 四种事件。工作区卡片、附件对象组和对象弹层都调用 `useDragToAttach`，旧实现逐实例注册。新增回归按实际追加卡片顺序挂载两张卡片，期望一次注册、实际两次，旧实现退出 1。此前并发挂载的 mock 未稳定观察到全部动态注册，后续上传断言失败；这些失败日志也保留。

`windowDragDrop.ts` 共享原生句柄，使用独立本地接收者所有权。部分卡片卸载不影响其余卡片，最后卸载才清理；注册未完成时即时重挂载复用同一待定注册，无接收者时释放迟到句柄。一个接收者异常不会阻断其他卡片。卡片仍按顶层与边界命中判断接收目标，原上传队列、对象归属和去重规则保持。

定向 10 项通过，覆盖 50 个接收者共享注册、四种事件、部分/最后卸载、迟到句柄、重挂载、异常、相同回调的独立所有权、卡片覆盖及剩余卡片上传。TypeScript 首次因测试数组只读推导失败，类型修正后退出 0。Prettier 与 diff 检查通过。ESLint 退出 0，存在 `syncStore.ts:838` 的一条既有警告。

完整 `npm run test` 实际退出 1：Node 阶段 245 项通过、1 项既有 Windows symlink 权限跳过；Vitest 2354 项通过，但错误收集独立 `android_native_perf/observer.node.test.mjs`，该 suite 报 `The URL must be of scheme file`。此入口问题需独立修复；不能将总检查记为通过。最初沙箱运行因临时缓存 rename 的 EPERM 执行了 0 项测试，后续检查使用 D 盘临时目录。
