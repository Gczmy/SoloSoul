# RF-1098 认证迟到结果验证

密码登录等待账户列表时，锁定或退出之后的旧结果曾重新写入已登录状态。实际红测复现 `isAuthenticated=true/currentAccount=old`，1 failed、exit 1。修复后密码登录和创建账户捕获认证代次；新认证操作、锁定、退出和 `completeUnlock` 使旧代次失效。每个等待点之后复核，再提交认证、最近账户和提醒；旧失败也不能覆盖当前错误或 loading。锁定和退出立即清除 loading。

17 个回归覆盖两个登录等待点、迟到成功/失败、锁定/退出、新密码登录、新 `completeUnlock`、乱序账户刷新，以及创建账户与密码登录互相替换。完整 Vitest 257 文件/2261 项通过，0 失败；Node 215 passed/0 failed/1 既有跳过。TypeScript、Lint、改动文件格式和文档边界检查 exit 0；Lint 保留未改动 `syncStore.ts` 的 1 条既有 unused-event 警告。
