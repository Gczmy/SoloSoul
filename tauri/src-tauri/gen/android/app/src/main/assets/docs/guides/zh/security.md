# 安全设置

安全设置管理您账户的核心安全功能，包括密码、生物识别和自动锁定。

## 修改密码

1. 进入「设置 → 安全设置」
2. 输入当前密码
3. 输入新密码并确认
4. 点击「修改密码」

<!--WARNING-->
修改密码后，所有生物识别凭证将失效，需要重新启用。
<!--/WARNING-->

## 密码提示词

密码提示词是在登录界面显示的辅助记忆信息：

- 不应包含密码本身或过于明显的线索
- 修改密码时可以同步更新提示词
- 留空则不在登录界面显示

## 生物识别解锁

如果您的设备支持生物识别（如 Touch ID / Face ID）：

1. 进入「设置 → 安全设置」
2. 在「生物识别解锁」区域查看可用性
3. 点击「启用 Touch ID」
4. 输入主密码进行验证
5. 按提示完成生物识别注册

<!--TIP-->
生物识别凭证与主密码绑定。修改主密码后，生物识别需要重新设置。
<!--/TIP-->

## 测试生物识别

启用后，您可以点击「测试 Touch ID」按钮验证功能是否正常。

## PIN 码解锁

如果您的设备支持，可以设置 **6 位数字 PIN 码**，用于替代生物识别的快捷解锁：

1. 进入「设置 → 安全设置」
2. 在「PIN 码」区域点击「设置 PIN」
3. 输入主密码验证身份
4. 设置 6 位 PIN 码并再次确认

设置完成后，锁定状态下可以直接输入 PIN 码解锁。可随时修改或关闭 PIN 码（关闭时同样需要主密码验证）。

<!--TIP-->
连续输错 PIN 会被临时锁定一段时间，以阻止暴力尝试。
<!--/TIP-->

## 自动锁定

SoloSoul 会在以下情况自动锁定保险库：

- 无操作超过设定的自动锁定时长（1 / 5 / 15 / 30 分钟，或选择「从不」）
- 应用切到后台（可关闭该开关）
- 手动点击侧边栏「锁定保险库」

锁定后，所有敏感状态将被清除，需要重新输入密码、PIN 码或使用生物识别解锁。
