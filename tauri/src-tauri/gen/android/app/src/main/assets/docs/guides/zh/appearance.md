# 主题与外观

外观设置让您可以自定义 SoloSoul 的视觉风格。进入「设置 → 主题与外观」进行配置。

## 主题模式

提供三种主题模式：

| 选项 | 说明 |
|------|------|
| 浅色 | 明亮色调界面，可在右侧选择具体浅色配色方案 |
| 深色 | 暗色调界面，可在右侧选择具体深色配色方案 |
| 跟随系统 | 自动匹配操作系统明暗模式 |

## 配色方案

SoloSoul 内置 **20 套配色方案**（浅色 10 套 + 深色 10 套），点击「更多外观」面板即可浏览和选择。每套方案定义了背景、文字、边框等整套色调，例如：

- **浅色**：暖石、洁净、奶油、薄荷、樱花粉、薰衣草、阳光柠檬、蜜桃珊瑚、北极冰、纸白
- **深色**：暖石暗、深海、午夜、森林夜、暮紫、炭灰、浓缩咖啡、酒红、青碧、曜石黑

选择某套方案后，它会成为对应明暗模式下的默认配色；下次切换模式时会自动应用你为该模式选择的那套方案。

<!--TIP-->
浅色与深色可以分别指定不同的配色方案，例如白天用「纸白」、夜晚用「曜石黑」。
<!--/TIP-->

## 主题色

提供五种预设主题色，应用于按钮、徽章、高亮等强调元素：

- **Ocean（海洋蓝）**
- **Amber（琥珀金）**
- **Forest（森林绿）**
- **Rose（玫瑰红）**
- **Purple（紫罗兰）**

主题色与配色方案相互独立：无论选择哪套配色方案，主题色都保持一致，可自由组合。

## 语言

支持切换界面语言：

- 中文（简体）
- English

切换后立即生效，无需重启应用。

## 侧边栏（桌面端）

桌面端还可以设置：

- **侧边栏位置**：左侧 / 右侧 / 顶部 / 底部
- **侧边栏按钮模式**：OCR、插件、AI 对话、搜索等入口可分别选择「卡片」或「页面」展示方式

<!--TIP-->
移动端侧边栏为固定布局，不提供位置与按钮模式设置。
<!--/TIP-->

## 实时预览

所有外观更改都是即时生效的，您可以实时看到效果。
