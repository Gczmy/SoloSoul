# 快速开始

欢迎使用 SoloSoul —— 您的本地优先个人数字孪生引擎。

## 第一步：创建账户

1. 首次启动 SoloSoul，点击「创建账户」
2. 设置**主密码**（建议至少 12 位，包含大小写字母和数字）
3. （可选）设置密码提示词，帮助记忆
4. 点击「创建保险库」，等待初始化完成

<!--WARNING-->
主密码是加密保险库的唯一钥匙，**无法重置**。请务必牢记或安全备份。
<!--/WARNING-->

## 第二步：创建第一个对象

1. 在首页选择「身份」分区
2. 点击「+ 创建」按钮
3. 选择模板，例如「Identity（身份信息）」
4. 填写姓名、出生日期、国籍等信息
5. 点击「保存」

<!--STEPPER 创建身份信息对象-->
1. 进入首页 → 点击「身份」卡片
2. 点击右上角「+ 创建」
3. 选择「Identity」模板
4. 填写字段信息
5. 点击「保存」
<!--/STEPPER-->

## 第三步：理解工作区

SoloSoul 将您的数据组织为**对象**，并按类型归入四个分区：

| 分区 | 用途 |
|------|------|
| 身份 | 个人基本信息、证件 |
| 旅行 | 护照、签证、行程 |
| 财务 | 银行账户、信用卡 |
| 职业 | 教育背景、工作经历 |

您还可以创建**自定义页面**，将任意对象组织到自己的分类中。

## 第四步：保护您的数据

- 敏感字段（如身份证号、银行卡号）会自动**模糊显示**
- 点击模糊字段可临时查看（部分高敏感度字段需要密码验证）
- 离开电脑时点击侧边栏「锁定保险库」按钮

<!--INFO-->
SoloSoul 采用零知识架构：所有数据仅存储在本地，开发者和服务端**无法访问**您的任何信息。
<!--/INFO-->
