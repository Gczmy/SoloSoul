# 生物识别

SoloSoul 支持使用设备生物识别（Touch ID / Face ID）快速解锁保险库和验证敏感操作。

## 支持的平台

| 平台 | 支持类型 |
|------|---------|
| macOS | Touch ID |
| iOS | Face ID / Touch ID |
| Windows | Windows Hello（规划中）|
| Android | 指纹（规划中）|

## 启用生物识别

1. 进入「设置 → 安全设置」
2. 查看「生物识别解锁」区域的状态
3. 如果显示「可用」，点击「启用」
4. 输入主密码验证身份
5. 按系统提示完成生物识别注册

<!--STEPPER 启用 Touch ID-->
1. 进入「设置 → 安全设置」
2. 在生物识别区域点击「启用 Touch ID」
3. 输入主密码
4. 将手指放在 Touch ID 传感器上
5. 启用成功，返回设置页面
<!--/STEPPER-->

## 使用场景

启用后，生物识别可用于：

- 解锁保险库（替代输入密码）
- 查看 `critical` 级别敏感字段
- 执行敏感度降级操作

## 禁用生物识别

1. 进入「设置 → 安全设置」
2. 点击「禁用 Touch ID」
3. 输入主密码确认

<!--WARNING-->
修改主密码后，生物识别凭证会自动失效，需要重新启用。
<!--/WARNING-->

## 故障排除

| 问题 | 解决方案 |
|------|---------|
| 生物识别不可用 | 检查系统偏好设置中是否已注册指纹/面容 |
| 验证失败次数过多 | 系统会临时禁用生物识别，请使用密码解锁 |
| 密码已变更 | 重新进入安全设置启用生物识别 |
