# 工作区与自定义页面

工作区是您管理和浏览对象的主要界面。SoloSoul 提供分区工作区和自定义页面两种组织方式。

## 分区工作区

四个固定分区：身份、旅行、财务、职业。

- 点击侧边栏图标或首页卡片进入对应分区
- 分区工作区显示该类型下的所有对象
- 支持顶部搜索框按名称过滤

## 自定义页面

除了固定分区，您可以创建自己的页面来组织对象：

1. 点击侧边栏底部的「+」按钮
2. 输入页面名称，选择图标
3. 创建后，该页面出现在侧边栏固定分区下方
4. 进入页面后创建的对象将归属此页面

<!--STEPPER 创建「我的项目」自定义页面-->
1. 点击侧边栏底部「+」按钮
2. 输入页面名称，例如「我的项目」
3. 选择一个图标（如文件夹或星星）
4. 点击确认创建
5. 新页面出现在侧边栏，点击进入即可添加对象
<!--/STEPPER-->

## 管理自定义页面

- **重命名**：双击侧边栏中的自定义页面名称
- **删除**：进入该页面工作区，点击右上角「删除」按钮

<!--WARNING-->
删除自定义页面不会删除页面中的对象，对象仍会保留在对应分区中。
<!--/WARNING-->
