# 回收站

回收站存放被删除的对象和附件，提供 30 天的缓冲期用于恢复。

## 删除的对象

- 从工作区删除的对象会进入回收站
- 对象的所有属性、附件和快照一并保留
- 30 天后系统自动永久清理

## 恢复对象

1. 进入「设置 → 回收站」
2. 找到要恢复的对象
3. 勾选后点击「恢复」按钮
4. 对象将回到原来的分区

## 永久删除

如需在 30 天到期前彻底删除：

1. 在回收站中勾选目标对象
2. 点击「永久删除」
3. 确认操作

<!--WARNING-->
永久删除后数据无法恢复。请谨慎操作。
<!--/WARNING-->

## 回收站过滤

回收站支持按类型和时间段筛选：

| 筛选条件 | 说明 |
|---------|------|
| 全部 | 显示所有已删除项目 |
| 页面 | 仅显示自定义页面 |
| 集合 | 仅显示集合 |
| 对象 | 仅显示普通对象 |

时间段筛选：1 天内、3 天内、7 天内、30 天内、半年内。

## 附件回收站

每个对象内部也有独立的附件回收站：

- 软删除的附件可在对象的附件列表中恢复
- 永久删除的附件将从保险库中彻底移除
