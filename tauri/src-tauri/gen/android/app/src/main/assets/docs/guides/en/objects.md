# Object Management

Objects are the core data unit in SoloSoul. Each object represents a structured record — a passport, a bank card, or an education entry.

## Object Structure

Every object contains:

- **Name**: The display title of the object
- **Collection Type**: Determines the section (Identity / Travel / Financial / Professional / Document), see [Object Types & Sections](collections.md)
- **Properties**: Field data defined by the template; each field can have a sensitivity level
- **Attachments**: Associated files (images, PDFs, etc.)

## Creating Objects

1. Enter any section workspace
2. Click **+ Create** in the top-right
3. Choose a template or **Blank Object**
4. Fill in the property fields
5. Click **Save**

<!--TIP-->
Templates automatically populate common fields so you don't miss important information.
<!--/TIP-->

## Editing and Deleting

- **Edit**: Click an object card in the workspace for details, or click the edit button to enter the editor
- **Delete**: Click the trash icon on an object card. The object moves to the **Trash** (recoverable within 30 days)

## Searching Objects

Type keywords in the search box at the top of the workspace. Results are filtered by name and property values in real time.

<!--WARNING-->
Deleted objects remain in the Trash for 30 days, after which they are **permanently deleted** and cannot be recovered.
<!--/WARNING-->
