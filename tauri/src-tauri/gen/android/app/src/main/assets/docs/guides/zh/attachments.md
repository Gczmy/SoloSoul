# 附件管理

附件是关联到对象的文件，如护照照片、合同 PDF、扫描件等。

## 添加附件

1. 打开对象的编辑页面
2. 点击「添加附件」按钮
3. 从文件系统选择文件
4. 文件将加密存储在保险库中

## 查看附件

- 在工作区中，带有附件的对象会显示回形针图标和数量徽章
- 点击回形针图标打开附件列表
- 支持的预览格式：图片（PNG/JPG/WEBP/GIF/BMP）、PDF、文本文件

<!--TIP-->
附件采用与对象数据相同的加密级别存储，安全性等同于对象本身。
<!--/TIP-->

## 附件操作

| 操作 | 说明 |
|------|------|
| 重命名 | 点击附件名称即可编辑 |
| 软删除 | 点击删除按钮，附件进入回收状态（可恢复） |
| 永久删除 | 在附件列表的「回收站」标签中执行永久删除 |
| 预览 | 点击图片/PDF 附件即可全屏预览 |

<!--WARNING-->
永久删除的附件无法恢复。软删除的附件保留在对象中，仅在回收站标签下隐藏。
<!--/WARNING-->
