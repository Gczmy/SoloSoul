# Theme & Appearance

Appearance settings let you customize SoloSoul's visual style. Go to **Settings → Theme & Appearance** to configure.

## Theme Mode

Three theme modes are available:

| Option | Description |
|--------|-------------|
| Light | Bright interface; pick a specific light scheme from the panel |
| Dark | Dark interface; pick a specific dark scheme from the panel |
| System | Automatically match the OS light/dark mode |

## Color Schemes

SoloSoul ships with **20 built-in color schemes** (10 light + 10 dark). Open the **More Appearances** panel to browse and select one. Each scheme defines a complete palette of background, text, and border colors, for example:

- **Light**: Warm Stone, Clean Slate, Soft Cream, Fresh Mint, Blush Pink, Lavender Mist, Sunny Lemon, Peach Coral, Arctic Ice, Paper White
- **Dark**: Warm Stone Dark, Deep Ocean, Midnight, Forest Night, Dusk Purple, Charcoal Slate, Espresso Bean, Burgundy Wine, Teal Depth, Obsidian Black

Once selected, a scheme becomes the default for that light/dark mode; the next time you switch modes it is applied automatically.

<!--TIP-->
Light and dark modes can use different schemes — for example Paper White during the day and Obsidian Black at night.
<!--/TIP-->

## Accent Color

Five preset accent colors are available for emphasized elements such as buttons, badges, and highlights:

- **Ocean**
- **Amber**
- **Forest**
- **Rose**
- **Purple**

Accent color is independent of the color scheme: whichever scheme you pick, the accent stays consistent and can be freely combined.

## Language

Switch the interface language between:

- 中文（简体）
- English

Changes take effect immediately without restarting the app.

## Sidebar (Desktop)

On desktop you can also set:

- **Sidebar position**: Left / Right / Top / Bottom
- **Sidebar button mode**: each entry (OCR, Plugins, AI Chat, Search, …) can be shown as a **Card** or a **Page**

<!--TIP-->
Mobile uses a fixed sidebar layout and does not offer position or button-mode settings.
<!--/TIP-->

## Live Preview

All appearance changes are applied instantly so you can see the effect in real time.
