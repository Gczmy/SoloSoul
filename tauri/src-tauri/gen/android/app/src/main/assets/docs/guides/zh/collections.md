# 对象类型与分区

SoloSoul 中的对象按**类型（Collection Type）**归类，类型决定对象所属的分区（Collection）。

## 类型分区

内置类型包括：

| 类型 | 所属分区 |
|------|---------|
| identity（身份信息） | 身份 |
| id_card（身份证）、address（地址）、contact（联系人） | 身份 |
| passport（护照）、visa（签证） | 旅行 |
| bank（银行账户）、card（银行卡） | 财务 |
| education（教育经历）、employment（工作经历） | 职业 |
| document（文档，如 OCR 导入的对象） | 文档 |

- 每个对象在创建时选择一个类型，并归入对应分区
- 首页与侧边栏按分区展示卡片，进入分区即可浏览该类型下的所有对象
- 自定义页面上的对象同样保留其原始类型归属

<!--TIP-->
对象的类型标签显示在对象卡片与详情页上，方便快速识别其所属分区。
<!--/TIP-->

## 对象类型与模板

- **模板**定义类型的字段结构（属性、敏感度等），见[对象模板](templates.md)
- 创建对象时选择模板，即可获得该类型预设的字段表单
- 同一类型下的对象共享模板字段，但每个对象的数据相互独立
