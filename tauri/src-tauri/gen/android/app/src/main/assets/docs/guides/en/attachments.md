# Attachment Management

Attachments are files associated with objects — passport photos, contract PDFs, scans, etc.

## Adding Attachments

1. Open an object's edit page
2. Click **Add Attachment**
3. Select a file from your system
4. The file is encrypted and stored in the vault

## Viewing Attachments

- Objects with attachments display a paperclip icon with a count badge in the workspace
- Click the paperclip icon to open the attachment list
- Supported preview formats: images (PNG/JPG/WEBP/GIF/BMP), PDF, text files

<!--TIP-->
Attachments are stored with the same encryption level as object data. Their security equals that of the objects themselves.
<!--/TIP-->

## Attachment Actions

| Action | Description |
|--------|-------------|
| Rename | Click the attachment name to edit |
| Soft Delete | Click the delete button. The attachment enters recovery state |
| Permanent Delete | Perform in the **Trash** tab of the attachment list |
| Preview | Click an image or PDF attachment for fullscreen preview |

<!--WARNING-->
Permanently deleted attachments cannot be recovered. Soft-deleted attachments remain in the object but are hidden under the Trash tab.
<!--/WARNING-->
