# 对象管理

对象是 SoloSoul 的核心数据单元。每个对象代表一条结构化记录，如一份护照、一张银行卡或一段教育经历。

## 对象结构

每个对象包含：

- **名称**：对象的显示标题
- **类型（Collection Type）**：决定对象所属分区（身份/旅行/财务/职业/文档），见[对象类型与分区](collections.md)
- **属性（Properties）**：由模板定义的字段数据，每个字段可设置敏感度级别
- **附件（Attachments）**：关联的文件（图片、PDF 等）

## 创建对象

1. 进入任意分区工作区
2. 点击右上角「+ 创建」
3. 选择模板或「空白对象」
4. 填写属性字段
5. 点击「保存」

<!--TIP-->
使用模板可以自动填充常用字段，避免遗漏重要信息。
<!--/TIP-->

## 编辑与删除

- **编辑**：在工作区点击对象卡片进入详情，或点击编辑按钮进入编辑器
- **删除**：点击对象卡片上的垃圾桶图标，对象将被移入**回收站**（30 天内可恢复）

## 搜索对象

在工作区顶部的搜索框输入关键词，支持按名称与属性值实时过滤。

<!--WARNING-->
删除的对象会进入回收站保留 30 天，之后将被**永久删除**，无法恢复。
<!--/WARNING-->
