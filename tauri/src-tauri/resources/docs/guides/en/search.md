# Global Search

Global Search lets you quickly find objects across all sections.

## Using Search

1. Click the **Search** icon in the sidebar or use the keyboard shortcut
2. Type keywords in the search box
3. Results display matching objects in real time

Search results include:

- Object name
- Section it belongs to
- Matched property field name and value
- Relevance ranking

## Search Scope

The search scans the following fields:

- Object name
- All property values
- Tags

<!--TIP-->
Search only looks at object-level information, not attachment contents. To find attachments, go to the object's attachment list.
<!--/TIP-->

## Opening from Results

Click an object card in the search results to enter the workspace and locate that object.

## Search Privacy

- Search runs entirely locally with no network requests
- Sensitive field matches follow the same sensitivity rules (blurred display)
