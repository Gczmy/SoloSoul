# Theme & Appearance

Appearance settings let you customize SoloSoul's visual style.

## Theme Mode

Three theme options are available:

| Option | Description |
|--------|-------------|
| System | Automatically match the OS light/dark mode |
| Light | Bright tone interface |
| Dark | Dark tone interface |

## Accent Color

Four preset accent colors are available:

- **Ocean**: Calm and professional
- **Amber**: Warm and soft
- **Forest**: Natural and fresh
- **Rose**: Elegant and refined

Once selected, the accent color applies to buttons, badges, highlights, and other elements.

## Background

Custom background types are supported:

- **Solid**: Choose a single color as the background
- **Gradient**: Use a gradient color background
- **Image**: Use a local image as the background

<!--TIP-->
Background settings affect the main interface area. The sidebar and toolbar maintain fixed styles to ensure readability.
<!--/TIP-->

## Language

Switch the interface language between:

- 中文（简体）
- English

Changes take effect immediately without restarting the app.

## Live Preview

All appearance changes are applied instantly so you can see the effect in real time.
