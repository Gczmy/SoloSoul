# How to Import Data

SoloSoul supports importing data from an encrypted package to restore your backup.

## Steps

1. Open the **Settings** page
2. Select **Export/Import** from the left menu
3. In the import area, click **Select File** and locate your `.solosoul` export package
4. If the export was password-protected, enter the password to decrypt
5. Preview the import contents, then click **Start Import**

## Import Modes

- **Merge**: Merge imported data with existing data
- **Overwrite**: Replace existing data entirely with imported data

## Notes

- Import is done entirely locally
- It is recommended to export current data as a backup before importing
- Large imports may take some time, please be patient
