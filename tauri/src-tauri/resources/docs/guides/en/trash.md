# Trash

The Trash holds deleted objects and attachments, providing a 30-day buffer for recovery.

## Deleted Objects

- Objects deleted from the workspace move to the Trash
- All properties, attachments, and snapshots are retained
- Automatic permanent cleanup occurs after 30 days

## Restoring Objects

1. Go to **Settings → Trash**
2. Find the object to restore
3. Check it and click **Restore**
4. The object returns to its original section

## Permanent Deletion

To delete before the 30-day expiration:

1. In the Trash, check the target objects
2. Click **Permanently Delete**
3. Confirm the action

<!--WARNING-->
Permanently deleted data cannot be recovered. Please proceed with caution.
<!--/WARNING-->

## Trash Filters

The Trash supports filtering by type and time period:

| Filter | Description |
|--------|-------------|
| All | Show all deleted items |
| Page | Custom pages only |
| Collection | Collections only |
| Object | Regular objects only |

Time period filters: 1 day, 3 days, 7 days, 30 days, 6 months.

## Attachment Trash

Each object also has its own attachment trash:

- Soft-deleted attachments can be restored from the object's attachment list
- Permanently deleted attachments are fully removed from the vault
