# Using AI Chat

SoloSoul's AI Chat feature lets you communicate with an AI assistant directly within the app.

## Enabling AI Chat

1. Open **Settings** → **AI & Smart Assistant**
2. Read and acknowledge the risk notice
3. Configure an AI Provider:
   - Choose a built-in provider (OpenAI, Anthropic, DeepSeek, etc.)
   - Or add a custom provider
   - Enter your API key
4. Turn on the **AI Chat** switch

## How to Use

1. Navigate to **AI Chat** from the sidebar or settings
2. Type your question in the input box and press Enter
3. The AI assistant responds based on your publicly shared info and software docs

## Privacy Notes

- System prompt only includes info you actively share (public level)
- Sensitive/restricted/critical data is never sent to AI
- You can disable system prompt injection in settings
