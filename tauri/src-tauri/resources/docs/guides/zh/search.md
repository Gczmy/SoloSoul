# 全局搜索

全局搜索让您可以跨所有分区快速查找对象。

## 使用搜索

1. 点击侧边栏「搜索」图标或按快捷键
2. 在搜索框输入关键词
3. 结果实时显示匹配的对象

搜索结果包含：

- 对象名称
- 所属分区
- 匹配的属性字段名和值
- 相关度排序

## 搜索范围

搜索会扫描以下字段：

- 对象名称
- 所有属性值
- 标签

<!--TIP-->
搜索仅查找对象级别的信息，不搜索附件内容。如需查找附件，请进入对应对象的附件列表。
<!--/TIP-->

## 从搜索结果打开

点击搜索结果中的对象卡片即可进入工作区并定位到该对象。

## 搜索隐私

- 搜索完全在本地执行，不涉及网络请求
- 敏感字段的匹配结果同样遵循敏感度规则（模糊显示）
