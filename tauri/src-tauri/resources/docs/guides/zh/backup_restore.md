# 备份与恢复

备份功能创建保险库的完整加密快照，用于灾难恢复。

## 创建备份

1. 进入「设置 → 备份与恢复」
2. 点击「创建备份」
3. 输入备份名称（如「更新前备份」）
4. 等待备份完成

备份文件存储在保险库目录中，包含：

- 所有对象和档案数据
- 附件文件
- 偏好设置
- 操作日志

<!--TIP-->
建议在重大操作前（如批量导入、版本升级）创建备份。
<!--/TIP-->

## 恢复备份

1. 进入「设置 → 备份与恢复」
2. 在备份列表中找到目标备份
3. 点击「恢复」
4. 确认恢复操作

<!--WARNING-->
恢复备份将**覆盖**当前保险库中的所有数据。请确保当前数据已另行保存。
<!--/WARNING-->

## 删除备份

备份列表中的每个备份都可以单独删除，释放存储空间。

## 备份 vs 导出

| 功能 | 备份 | 导出 |
|------|------|------|
| 范围 | 整个保险库 | 可选对象 |
| 格式 | 内部快照 | `.solosoul` 文件 |
| 用途 | 本地灾难恢复 | 跨设备迁移、外部存档 |
| 位置 | 保险库目录 | 用户指定路径 |
