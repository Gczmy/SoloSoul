# 敏感度与隐私

SoloSoul 采用四级敏感度分级系统，为每个字段提供精细化的数据保护。

## 敏感度级别

| 级别 | 说明 | 显示行为 |
|------|------|---------|
| 公开 | 公众可见 | 明文显示 |
| 内部 | 仅内部使用 | 明文显示，带标签提示 |
| 敏感 | 需谨慎处理 | 默认模糊，点击可查看 |
| 关键 | 高度敏感 | 默认模糊，查看需密码验证 |

## 字段级保护

每个对象模板的字段都有预设的敏感度级别。例如：

- 护照号码 → 关键
- 姓名 → 公开
- 银行账号 → 敏感

## 查看敏感字段

- **敏感**：点击「显示」按钮即可临时查看
- **关键**：点击后弹出主密码验证对话框，输入主密码方可查看；查看行为会写入审计日志

<!--TIP-->
每次查看「关键」字段都会被记录在操作日志中，方便追踪访问历史。
<!--/TIP-->

## 调整敏感度

字段的敏感度级别在**对象模板编辑器**中定义，可随时调整：

1. 进入「模板」→ 编辑目标模板
2. 找到目标字段所在的行
3. 在「敏感度」下拉框中选择新的级别
4. 保存模板

调整后，基于该模板创建的对象都会使用新的保护级别。

## 与 AI 的隐私边界

- 只有公开级别的字段信息会被注入 AI 系统提示词
- 敏感 / 关键数据**绝不会**发送给 AI
- 您可以在「LLM 配置」中关闭系统提示词注入
