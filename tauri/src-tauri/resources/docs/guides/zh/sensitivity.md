# 敏感度与隐私

SoloSoul 采用四级敏感度分级系统，为每个字段提供精细化的数据保护。

## 敏感度级别

| 级别 | 说明 | 显示行为 |
|------|------|---------|
| `public` | 公开 | 明文显示 |
| `internal` | 内部 | 明文显示，带标签提示 |
| `sensitive` | 敏感 | 默认模糊，点击可查看 |
| `critical` | 关键 | 默认模糊，查看需密码验证 |

## 字段级保护

每个对象模板的字段都有预设的敏感度级别。例如：

- 护照号码 → `critical`
- 姓名 → `public`
- 银行账号 → `sensitive`

## 查看敏感字段

- **`sensitive`**：点击模糊区域即可临时显示
- **`critical`**：点击后弹出密码验证对话框，输入主密码方可查看

<!--TIP-->
生物识别解锁（如 Touch ID）可用于替代密码查看 critical 字段，前提已在设置中启用。
<!--/TIP-->

## 调整敏感度

如需修改字段的保护级别：

1. 进入「设置 → 敏感度设置」
2. 找到目标字段
3. 选择新的敏感度级别
4. 输入主密码并填写原因，仅在降级保护时需要
5. 确认修改

<!--WARNING-->
降低字段保护级别需要密码验证并记录审计日志。变更无法无痕撤销。
<!--/WARNING-->

## 与 AI 的隐私边界

- 只有 `public` 级别的字段信息会被注入 AI 系统提示词
- `sensitive` / `critical` 数据**绝不会**发送给 AI
- 您可以在「LLM 配置」中关闭系统提示词注入
