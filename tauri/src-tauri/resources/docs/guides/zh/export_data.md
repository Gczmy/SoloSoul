# 如何导出数据

SoloSoul 支持将您的数据导出为加密包，方便备份和迁移。

## 操作步骤

1. 打开**设置**页面
2. 选择左侧菜单中的**导入导出**
3. 在导出区域选择要导出的内容：
   - 选中页面和对象
   - 包含附件（可选）
   - 包含偏好设置（可选）
   - 包含行为数据（可选）
4. 设置导出密码（可选，用于额外加密）
5. 点击**开始导出**，选择保存位置

## 导出格式

导出文件为 `.solosoul` 格式，采用 AES-256-GCM 加密，确保数据安全。

## 注意事项

- 导出过程完全在本地完成，不会上传任何数据到云端
- 建议定期导出备份，防止数据丢失
- 导出文件可跨平台使用（macOS、Windows、Linux）
