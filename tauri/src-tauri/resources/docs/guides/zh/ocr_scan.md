# OCR 与扫描

OCR（光学字符识别）功能让您可以从图片中提取文字并创建对象。

## 使用 OCR

1. 从侧边栏或首页进入「OCR 扫描」
2. 点击「选择图片」，上传包含文字的图片
3. 系统识别后显示提取的文本和置信度
4. 检查识别结果，必要时手动修正
5. 点击「导入为对象」，选择目标分区

## 支持的图片格式

- PNG、JPG、JPEG、WEBP、BMP、TIFF

## 识别字段

OCR 引擎会尝试自动识别常见字段：

- 姓名、日期、号码类字段
- 识别结果以键值对形式呈现
- 置信度低于 80% 的字段会特别标注

<!--TIP-->
为获得最佳识别效果，请确保图片清晰、文字区域占画面主要部分、光线均匀。
<!--/TIP-->

## 本地文件导入

除了 OCR，您还可以直接将本地文件导入为对象：

1. 进入「本地导入」页面
2. 选择文件或文件夹
3. 系统扫描支持的文件类型
4. 勾选要导入的文件
5. 选择导入方式（创建对象或附件）

## 隐私说明

- OCR 处理在本地完成，图片不会上传到外部服务
- 识别结果仅保存在您的保险库中
