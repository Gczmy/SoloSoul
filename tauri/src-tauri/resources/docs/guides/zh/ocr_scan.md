# OCR 与扫描

OCR（光学字符识别）功能让您可以从图片或 PDF 中提取文字并导入为对象。所有识别都在**本地**完成，图片不会上传到任何外部服务。

## 使用 OCR

1. 从侧边栏或首页进入「OCR 扫描」
2. 选择输入方式：
   - **选择文件**：从本机选择图片或 PDF
   - **拍照**：移动端可直接调用相机拍摄
3. 选择扫描模式与模型档位（见下文）
4. 系统识别后显示提取的文本
5. 检查识别结果，必要时手动修正
6. 点击「导入为对象」，为对象命名后保存

## 扫描模式

- **通用识别**：提取图片或 PDF 中的全部文字
- **MRZ 识别**：针对护照、签证、身份证等机读码区域（Machine Readable Zone）做结构化识别，直接提取证件类型、签发国、证件号、国籍、出生日期、性别、有效期等字段

<!--STEPPER 扫描护照信息页-->
1. 进入「OCR 扫描」页面，扫描模式选「MRZ 识别」
2. 点击「选择文件」，上传护照信息页照片
3. 等待识别完成
4. 检查识别出的证件字段
5. 点击「导入为对象」→ 保存为对象
<!--/STEPPER-->

<!--TIP-->
MRZ 未识别到时（例如拍摄的是普通文档），会自动回退为通用文字识别，不会丢失结果。
<!--/TIP-->

## 支持的输入格式

- 通用识别：PNG、JPG、JPEG、WEBP、BMP、TIFF、PDF
- MRZ 识别：PNG、JPG、JPEG、WEBP、BMP、TIFF（证件照片）

## 模型档位

在「设置 → OCR」或扫描页顶部可切换模型档位。更大的模型识别更准，但更慢、占用更多存储：

| 档位 | 说明 |
|------|------|
| tiny | 轻量模型（约 1.5MB），速度快，适合简单文本 |
| small | 平衡档（约 30MB），默认推荐 |
| medium | 高精度（约 132MB），适合复杂版式 |
| vision | 系统内置引擎（macOS Vision，不可删除），使用系统能力识别 |

模型按需下载安装；随应用分发的档位（bundled）可直接安装，无需联网下载。

<!--TIP-->
为获得最佳识别效果，请确保图片清晰、文字区域占画面主要部分、光线均匀。
<!--/TIP-->

## 识别结果

- 识别结果以文本形式呈现，可复制或编辑后导入
- 导入时自动生成对象（`document` 类型），识别文本保存为「OCR 文本」字段（internal 级别）
