# 操作日志

操作日志记录了对保险库的所有重要操作，用于审计和安全追溯。

## 查看日志

1. 进入「设置 → 操作日志」
2. 日志按时间倒序排列
3. 每条记录包含：时间、操作类型、操作对象、操作人、详情

## 筛选日志

支持按以下条件筛选：

- **操作类型**：创建、更新、删除、恢复、永久删除、回滚等
- **实体类型**：对象、页面、档案、生物识别、导出、导入等
- **操作人**：用户操作 / 系统自动

## 日志内容

常见操作记录示例：

| 操作 | 详情说明 |
|------|---------|
| 创建对象 | 显示所属分区 |
| 更新对象 | 记录字段变更摘要 |
| 删除对象 | 标记为移入回收站 |
| 恢复对象 | 标记为恢复到原位置 |
| 永久删除 | 记录删除的对象名称 |
| 启用生物识别 | 记录启用位置 |

## 导出日志

点击「导出日志」按钮，可以将当前筛选范围内的日志导出为文本文件。

<!--TIP-->
操作日志是只读的，用户无法修改或删除日志条目。这确保了审计的完整性。
<!--/TIP-->

## 日志保留

操作日志长期保留在本地。如需清理历史日志，请使用「调试日志」页面的相关功能。
