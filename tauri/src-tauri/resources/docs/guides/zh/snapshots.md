# 快照与历史

SoloSoul 自动为对象的每次修改创建快照，让您可以随时回溯历史版本。

## 自动快照

系统会在以下情况自动创建快照：

- 对象被修改并保存时
- 对象字段发生变更时

快照包含对象的完整状态（名称、属性、附件关联等）。

## 查看历史

1. 在工作区中找到目标对象
2. 点击对象卡片上的时钟图标（历史）
3. 弹出翻页式历史浏览器
4. 使用左右箭头在不同版本间切换

<!--STEPPER 查看对象历史版本-->
1. 在工作区找到对象
2. 点击时钟图标（显示快照数量徽章）
3. 在历史浏览器中浏览不同版本
4. 点击左箭头查看更早版本，右箭头查看更新版本
5. 点击「关闭」退出历史浏览器
<!--/STEPPER-->

## 历史版本中的敏感数据

历史浏览器中同样遵循敏感度规则：

- `sensitive` / `critical` 级别的字段会被模糊处理
- 查看 `critical` 字段需要密码验证

## 从快照恢复

如需将对象回滚到某个历史版本：

1. 打开对象详情 → 点击历史图标进入历史浏览器
2. 选择目标快照版本
3. 点击「恢复」并确认

<!--TIP-->
快照存储大小可在「设置 → 数据管理」中查看，并可按上限设置快照保留数量。
<!--/TIP-->

<!--TIP-->
快照不会占用过多空间，系统会自动管理。您可以在「数据管理」中查看快照占用的存储大小。
<!--/TIP-->
