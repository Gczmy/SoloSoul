# 服务条款

**最后更新日期：2026-06-08**

## 软件许可

SoloSoul 是一款开源的本地优先个人数据管理软件。使用本软件即表示您同意以下条款。

## 用户责任

- 您对自己的主密码安全负全部责任。SoloSoul 无法重置或恢复您的主密码
- 您应妥善保管导出的 `.solosoul` 文件和密码
- 使用 AI 功能时，您应遵守所配置的第三方 AI 服务商的服务条款

## 数据安全

- SoloSoul 采用行业标准的加密技术保护您的数据
- 由于本地优先架构，数据备份和同步由用户自行负责
- 建议定期使用「备份与恢复」功能创建本地加密备份

## AI 功能免责声明

- AI 对话功能依赖第三方服务商，其可用性和响应质量不受 SoloSoul 控制
- AI 生成的内容仅供参考，不构成专业建议
- 请勿通过 AI 功能传输法律、医疗或财务敏感信息

## 开源与贡献

- SoloSoul 的源代码遵循开源许可协议发布
- 欢迎通过 GitHub 提交问题反馈和功能建议

## 条款变更

我们保留更新本服务条款的权利。重大变更将通过软件内通知或 GitHub 发布说明告知用户。
