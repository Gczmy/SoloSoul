# AI 对话

SoloSoul 的 AI 对话功能让您可以直接在软件中与 AI 助手交流，同时保持对数据的完全控制。

## 开启 AI 对话

1. 打开「设置 → AI 与 LLM 配置」
2. 阅读风险告知并勾选「我已了解风险」
3. 配置 AI 服务商：
   - 选择内置 Provider（OpenAI、Anthropic、DeepSeek 等）
   - 或添加自定义 Provider
   - 填写 API 密钥
4. 开启「AI 对话」功能开关

## 使用方式

1. 从侧边栏点击「AI 对话」图标进入
2. 在底部输入框中输入问题，按 Enter 发送
3. AI 助手会基于您主动公开的信息和软件文档回答

## 系统提示词

系统提示词（System Prompt）是每次对话时自动注入的上下文信息，包括：

- 软件基本信息
- 您设置为「公开」级别的对象数据
- 软件使用统计（对话次数、Token 使用量等）

您可以在 LLM 配置中关闭系统提示词注入。

<!--TIP-->
系统提示词仅包含您主动公开的信息。敏感/关键数据绝不会发送给 AI。
<!--/TIP-->

## 对话管理

- **新对话**：点击「新对话」按钮开始新的聊天线程
- **删除对话**：点击对话列表中的删除图标，对话将移入回收站
- **回收站**：在对话页面点击「回收站」查看和恢复已删除的对话

## 隐私说明

- 对话内容通过 SSE（Server-Sent Events）流式传输
- 所有对话历史仅存储在本地
- AI 服务商可能根据其隐私政策处理您的数据

<!--WARNING-->
AI 功能会将数据发送到外部 LLM 服务商。请勿通过 AI 对话分享敏感或关键级别的数据。
<!--/WARNING-->
