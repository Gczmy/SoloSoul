# 使用 AI 对话功能

SoloSoul 的 AI 对话功能让您可以直接在软件中与 AI 助手交流。

## 开启 AI 对话

1. 打开**设置** → **AI 与智能助手**
2. 阅读风险告知并确认
3. 配置 AI 服务商（Provider）：
   - 选择内置 Provider（OpenAI、Anthropic、DeepSeek 等）
   - 或添加自定义 Provider
   - 填写 API 密钥
4. 开启**AI 对话**开关

## 使用方式

1. 从侧边栏或设置页进入**AI 对话**
2. 在输入框中输入问题，按 Enter 发送
3. AI 助手会基于您主动公开的信息和软件文档回答

## 隐私说明

- 系统提示词仅包含您主动公开的信息（public 级别）
- 敏感/受限/关键数据不会发送给 AI
- 您可以在设置中关闭系统提示词注入
