# 集合

集合是将对象按条件分组的功能，分为内置集合和自定义集合两种。

## 内置集合

SoloSoul 预置了一些常用集合视图：

- 最近创建的对象
- 最近修改的对象
- 包含附件的对象
- 高敏感度对象

## 自定义集合

您可以创建自己的集合来组织对象：

1. 进入「设置 → 数据管理」
2. 在「集合」区域点击「添加」
3. 输入集合名称
4. 配置筛选条件（如对象类型、标签、创建时间等）
5. 保存

## 智能集合

智能集合是动态视图，会根据筛选条件自动更新内容：

- 匹配条件的对象会自动出现在集合中
- 无需手动添加或移除
- 条件可以随时修改

<!--TIP-->
智能集合非常适合创建「即将到期的证件」或「未归档的项目」等动态视图。
<!--/TIP-->

## 管理集合

- **编辑**：点击集合名称旁的编辑图标修改筛选条件
- **删除**：点击删除图标移除集合（不会删除集合中的对象）

<!--WARNING-->
删除集合仅移除视图配置，不会影响集合中的任何对象数据。
<!--/WARNING-->
