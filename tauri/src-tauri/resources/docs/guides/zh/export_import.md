# 导出与导入

导出与导入功能让您可以将保险库数据以 `.solosoul` 格式进行加密交换。

## 导出数据

1. 进入「设置 → 导出与导入」
2. 选择要导出的页面、对象、模板
3. 选择导出选项：
   - **包含附件**：同时导出关联的文件
   - **包含偏好设置**：导出主题、语言等个人设置
   - **包含行为记录**：导出操作日志等审计数据
4. 设置导出密码（至少 8 位）
5. 点击「导出选中」

<!--STEPPER 导出旅行分区数据-->
1. 进入「设置 → 导出与导入」
2. 在导出区域勾选「旅行」页面
3. 勾选「包含附件」（如需导出护照照片等）
4. 设置导出密码并确认
5. 点击「导出选中」，选择保存路径
<!--/STEPPER-->

## 导入数据

1. 进入「设置 → 导出与导入」
2. 切换到「导入」标签
3. 选择 `.solosoul` 文件
4. 输入导出密码
5. 预览导入内容，选择导入策略：
   - **跳过已有**：保留现有数据，跳过重复项
   - **覆盖**：用导入数据替换所有现有数据
   - **合并**：覆盖冲突项，保留非冲突项
6. 确认导入

<!--TIP-->
导入前使用「预览」功能查看包内对象列表，避免意外覆盖重要数据。
<!--/TIP-->

## 导出文件安全

- `.solosoul` 文件使用 AES-256-GCM 加密
- 加密密码是打开文件的唯一钥匙
- 文件可以安全地通过任何渠道传输或存储

<!--WARNING-->
如果包含高敏感度字段，导出密码必须足够强壮。建议使用 12 位以上混合字符密码。
<!--/WARNING-->
