# 对象模板

模板是预设的对象结构，帮助您快速创建标准格式的记录。SoloSoul 内置了多种常用模板。

## 内置模板一览

| 模板 | 所属分区 | 适用场景 |
|------|---------|---------|
| Identity | 身份 | 个人基础身份信息 |
| Passport | 旅行 | 护照信息 |
| Visa | 旅行 | 签证信息 |
| Bank Account | 财务 | 银行账户 |
| Card | 财务 | 信用卡/借记卡 |
| Education | 职业 | 教育经历 |
| Employment | 职业 | 工作经历 |

## 使用模板

1. 进入对象编辑器（新建对象时）
2. 在顶部选择模板类型
3. 系统自动展开对应的字段表单
4. 填写后保存

<!--STEPPER 使用护照模板-->
1. 进入「旅行」分区工作区
2. 点击「+ 创建」
3. 选择「Passport」模板
4. 填写护照号码、国籍、签发日期、有效期
5. 点击「保存」
<!--/STEPPER-->

## 保存自定义模板

如果您创建了一个常用结构的对象，可以将其保存为模板：

1. 打开该对象的编辑页面
2. 点击「保存为模板」按钮
3. 输入模板名称
4. 确认保存

<!--TIP-->
自定义模板仅保存在本地，不会上传到任何服务器。
<!--/TIP-->
