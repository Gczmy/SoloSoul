# 对象模板

模板是预设的对象结构，帮助您快速创建标准格式的记录。SoloSoul 内置了多种常用模板，同时支持将任意对象保存为自定义模板。

## 模板来源

- **系统模板**：内置在应用中的标准模板，随版本更新而扩展，无法修改。
- **用户模板**：由您自己创建的模板，仅存储在本地，可随时编辑或删除。

## 内置模板一览

SoloSoul 内置 10 个系统模板：

| 模板 | 所属分区 | 适用场景 |
|------|---------|---------|
| 身份信息（identity） | 身份 | 个人基础身份信息 |
| 身份证（id_card） | 身份 | 身份证件信息 |
| 地址（address） | 身份 | 常用地址 |
| 联系人（contact） | 身份 | 联系人信息 |
| 护照（passport） | 旅行 | 护照信息 |
| 签证（visa） | 旅行 | 签证信息 |
| 银行账户（bank） | 财务 | 银行账户 |
| 银行卡（card） | 财务 | 银行卡 |
| 教育经历（education） | 职业 | 教育经历 |
| 工作经历（employment） | 职业 | 工作经历 |

## 使用模板

1. 进入对象编辑器（新建对象时）
2. 在顶部选择模板类型
3. 系统自动展开对应的字段表单，并在下方显示模板预览（字段类型、是否必填、是否敏感）
4. 填写后保存

## 创建与编辑模板

您可以在「模板管理」页面创建自己的模板：

1. 进入「设置 → 模板管理」
2. 点击「新建模板」
3. 设置模板名称与所属类型（分区）
4. 添加字段，并为每个字段设置类型与敏感度级别
5. 保存模板

创建后，可以随时编辑模板字段或删除模板。

<!--TIP-->
自定义模板仅保存在本地，不会上传到任何服务器。
<!--/TIP-->

## 模板与对象的关联

每个对象在创建时可以选择关联一个模板（系统模板或用户模板）。关联信息会记录在对象数据中，方便后续追溯该对象基于哪个模板创建。即使模板后来被修改或删除，对象自身的数据与字段定义（`__fields`）仍然保留。
