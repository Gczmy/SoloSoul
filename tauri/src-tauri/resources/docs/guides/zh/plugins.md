# 插件

插件系统允许扩展 SoloSoul 的功能。当前插件系统处于开发阶段。

## 插件市场

SoloSoul 的插件通过独立的插件市场分发：

- 插件以 WebAssembly（WASM）格式运行
- 每个插件在沙盒环境中执行
- 插件需要显式授权才能访问数据字段

## 安装插件

1. 进入「插件」页面
2. 浏览可用插件列表
3. 点击「安装」下载插件
4. 安装后启用插件

## 插件授权

每个插件在使用前需要您的授权：

- 字段级授权：选择允许插件访问的具体字段
- 会话授权：每次使用时的临时许可
- 授权可随时在设置中撤销

<!--WARNING-->
插件由第三方开发，安装前请审查其权限请求。只安装来自可信来源的插件。
<!--/WARNING-->
