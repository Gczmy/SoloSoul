# 插件

插件系统允许扩展 SoloSoul 的功能。插件以 **WebAssembly（WASM）** 格式运行，在沙盒环境中执行，并通过**显式授权**访问数据。

## 插件市场

SoloSoul 的插件通过独立的插件市场分发：

- 「插件」页面展示市场插件列表与已安装插件
- 每个插件包含名称、版本、作者与权限说明
- 插件在安装后才可用

## 安装与卸载插件

1. 进入「插件」页面
2. 浏览可用插件列表，点击「安装」
3. 安装后插件出现在「已安装」列表中
4. 不再需要时，点击「卸载」移除插件

## 插件授权

每个插件在使用前需要您的授权：

- **字段级授权**：选择允许插件访问的具体字段（Consent）
- **会话授权**：插件运行时按会话请求临时许可，可随时撤销
- **授权状态**：可在插件详情中查看与撤销

<!--WARNING-->
插件由第三方开发，安装前请审查其权限请求。只安装来自可信来源的插件。
<!--/WARNING-->

## 插件会话与日志

- 插件执行时创建独立会话，运行记录可查看
- 插件访问附件等数据时遵循权限边界，未授权的资源无法读取

## 开发插件

开发者可参考 `docs/wasm-plugin-development-guide.md`（帮助文档目录外）与插件 SDK 文档编写 WASM 插件，包含宿主函数、错误码与字段映射规范。
