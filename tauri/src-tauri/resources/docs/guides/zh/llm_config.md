# LLM 配置与统计

LLM 配置管理 AI 服务商和功能的开关。统计页面展示您的 AI 使用数据。

## 配置服务商

### 内置服务商

SoloSoul 内置以下 Provider：

- OpenAI（GPT 系列）
- Anthropic（Claude 系列）
- DeepSeek

配置步骤：

1. 进入「设置 → AI 与 LLM 配置」
2. 选择一个内置 Provider
3. 输入您的 API 密钥
4. 点击「测试连接」验证
5. 选择该 Provider 为当前激活服务商

### 自定义服务商

如需使用其他兼容 OpenAI API 的服务：

1. 点击「添加自定义提供商」
2. 输入名称、基础 URL、模型名称
3. 选择 API 类型（OpenAI / Anthropic）
4. 输入 API 密钥
5. 保存并测试连接

<!--TIP-->
使用本地模型（如 Ollama）时，基础 URL 通常为 `http://localhost:11434/v1`。
<!--/TIP-->

## AI 功能开关

在 LLM 配置页面可以单独控制各项 AI 功能：

| 功能 | 说明 |
|------|------|
| AI 对话 | 与 AI 助手聊天 |
| 智能填充 | 自动补全对象字段（开发中）|
| 命令生成 | 自然语言生成操作命令（开发中）|
| 自然语言搜索 | 用自然语言描述搜索意图（开发中）|

## 系统提示词

系统提示词开关控制是否将软件信息注入 AI 上下文：

- **开启**：AI 了解您的公开数据和软件状态，回答更精准
- **关闭**：仅发送用户输入，隐私性最高

## 使用统计

点击 LLM 配置页面右上角的「统计」图标，查看：

- 总对话次数和 Token 使用量
- 各模型的使用占比
- Prompt / Completion Token 分布
- 最近 14 天的每日使用趋势
- 在线状态检测

<!--TIP-->
Token 统计通过解析 AI 服务商的真实返回数据获得，OpenAI 和 Anthropic 均支持精确的用量报告。
<!--/TIP-->
