# 主题与外观

外观设置让您可以自定义 SoloSoul 的视觉风格。

## 主题模式

提供三种主题选项：

| 选项 | 说明 |
|------|------|
| 跟随系统 | 自动匹配操作系统明暗模式 |
| 浅色 | 明亮色调界面 |
| 深色 | 暗色调界面 |

## 主题色

提供四种预设主题色：

- **海洋蓝**：沉稳专业
- **琥珀金**：温暖柔和
- **森林绿**：自然清新
- **玫瑰红**：优雅精致

选择后，主题色将应用于按钮、徽章、高亮等元素。

## 背景

支持自定义背景类型：

- **纯色**：选择单一颜色作为背景
- **渐变**：使用渐变色背景
- **图片**：使用本地图片作为背景

<!--TIP-->
背景设置会影响整个应用的主界面区域。侧边栏和工具栏保持固定样式以确保可读性。
<!--/TIP-->

## 语言

支持切换界面语言：

- 中文（简体）
- English

切换后立即生效，无需重启应用。

## 实时预览

所有外观更改都是即时生效的，您可以实时看到效果。
