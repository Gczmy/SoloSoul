# 同步

同步功能帮助您在多台设备间发现彼此并交换数据。

## 设备发现

SoloSoul 使用 mDNS（Bonjour/Avahi）在同一局域网内发现其他设备：

1. 进入「同步」页面
2. 点击「扫描设备」
3. 系统将在局域网内搜索其他运行 SoloSoul 的设备
4. 发现的设备将显示在列表中

<!--TIP-->
设备发现需要在同一局域网（Wi-Fi）内。不同网络环境下的设备无法自动发现。
<!--/TIP-->

## 启用同步

1. 在同步页面打开「启用同步」开关
2. 选择要连接的设备
3. 确认配对

## 同步内容

同步将交换以下数据：

- 对象数据（加密传输）
- 档案信息
- 附件（可选）

<!--WARNING-->
同步功能目前处于早期阶段。建议在同步前创建本地备份，以防数据冲突。
<!--/WARNING-->

## 离线使用

SoloSoul 完全支持离线使用。同步是可选功能，不影响本地数据的完整性和可用性。
