# 安全设置

安全设置管理您账户的核心安全功能，包括密码、生物识别和自动锁定。

## 修改密码

1. 进入「设置 → 安全设置」
2. 输入当前密码
3. 输入新密码并确认
4. 点击「修改密码」

<!--WARNING-->
修改密码后，所有生物识别凭证将失效，需要重新启用。
<!--/WARNING-->

## 密码提示词

密码提示词是在登录界面显示的辅助记忆信息：

- 不应包含密码本身或过于明显的线索
- 修改密码时可以同步更新提示词
- 留空则不在登录界面显示

## 生物识别解锁

如果您的设备支持生物识别（如 Touch ID / Face ID）：

1. 进入「设置 → 安全设置」
2. 在「生物识别解锁」区域查看可用性
3. 点击「启用 Touch ID」
4. 输入主密码进行验证
5. 按提示完成生物识别注册

<!--TIP-->
生物识别凭证与主密码绑定。修改主密码后，生物识别需要重新设置。
<!--/TIP-->

## 测试生物识别

启用后，您可以点击「测试 Touch ID」按钮验证功能是否正常。

## 自动锁定

SoloSoul 会在以下情况自动锁定保险库：

- 应用进入后台超过设定时间
- 检测到系统屏幕锁定
- 手动点击侧边栏「锁定保险库」

锁定后，所有敏感状态将被清除，需要重新输入密码或生物识别解锁。
